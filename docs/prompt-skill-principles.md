# Prompt Skill 设计原则

## 共同原则

### 用分层模型组织 prompt

一张图或一段视频按解剖层级拆开，每层回答一个问题。prompt 的任务是让每一层都有确定的取值。分层取代了旧版的“交付物判断 → 检索术语 → 组织描述”流程。

- **信息只放在一层。** 同一信息跨层重复，会让模型对同一事物得到两份不一致的描述。
- **笼统词拆到具体层。** “电影感”“史诗”“高级”不直接写进 prompt，而是拆成比例、视角、反差、剪辑密度等可见取值。
- **补齐空层并服从主次。** 用户没指定的层由 skill 补一个明确选择，空着的层由模型随机决定。补出的环境、光影与材质必须衬托第一视觉焦点（通过失焦、压暗、低饱和或留白让位），不添加抢戏的次要细节。
- **补层只填空位。** 用户已给的设定不得被补层改写。这条来自视频测试，子 agent 为了光源连续给“只剩门外车灯”加了一盏路灯。
- **风格锚点必须落地。** 作者、作品、流派名只起压缩作用，必须先拆成下层的可见特征，不能代替下层约束。
- **素材按层分工。** 每份参考图或素材写明它锁定哪一层，风格素材不得替换主体身份。
- **编辑只写变化。** 不变的内容逐项写进「保留」。

### 输出是分 section 的自然语言

- 每个 section 标题单独一行，内容写成完整短句，不堆标签。
- 标题不带 ①② 序号，不加【】括号。序号只是 skill 内部的分类工具，不进入 prompt。
- 只输出一种形式。不再附“合并成一段”的连续文本。
- 画幅、尺寸、张数、时长、分辨率由 API 参数控制，不写进 prompt。不写 `--ar` 这类模型专用语法。
- 入口有单独负向字段时，负面提示放进该字段。

### General 指导原则，不绑定模型

skill 只写跨模型成立的写法。绑定某个模型的公式、语法和信息顺序不进 skill。视频的三份模型 reference（Seedance 2.0、Seedance 2.5、MiniMax H3）因此整体删除，其中不依赖模型的内容并入正文。

模型差异只留下通用的降级规则。例如入口不支持秒级时间戳时，时间片改写为“起初、随后、最后”，结构不变。

### 不做术语检索

image-prompt 旧版要求按任务检索范例、术语定义和模型文档，并附来源链接。这一整套已删除。保留的是一条交付检查，即每个专业术语都要能说出它改变了什么可见结果。这条管的是用词有没有用处，与检索无关。

### 不照抄资料里的例子

用户给的资料里有 60:30:10、丁达尔光、莫兰迪色这类具体例子。skill 只保留每层的类别，不把例子固化成规则。这与 `AGENTS.md` 的“删除非必要示例”一致。

## image-prompt：五层

| 层 | 决定什么 |
| --- | --- |
| ① 主体与内容 | 画里有什么、决定性瞬间与画外故事 |
| ② 构图与空间 | 透视性格、三层纵深、焦点景深与剪影分离 |
| ③ 色彩与光影 | 光比雕塑、受限光源动机与主次色彩对抗 |
| ④ 材质与肌理 | 材质反差、破除塑料感与焦点处的细节预算 |
| ⑤ 风格与美学 | 顶层艺术语言与审美哲学 |

### 先锁媒介

⑤ 的媒介形式决定 ③④ 用哪套语言。摄影写焦段、布光和胶片颗粒。绘画写色块和笔触。像素画写像素尺度和调色板。扁平画面不补物理微纹理，摄影不补笔触。

### 词序决定权重

越靠前的内容，模型分配的注意力越多。所以 ⑤ 在交付时拆成两处，媒介定性放最前，流派、氛围与渲染引擎放最后。

交付顺序：

```text
媒介定性 → 主体与内容 → 构图与空间 → 色彩与光影 → 材质与肌理 → 风格与美学
→ 参考 → 保留 → 文字 → 负面提示
```

后四个 section 用不到就整段删除。

## video-prompt：六层加时间轴

图片是空间的艺术，视频是空间、时间与运动的艺术。引入时间轴后，每一层都从“某一刻的取值”升维为“沿时间的变化”，即起始状态、变化过程与结束状态。

| 层 | 从图片升维为 |
| --- | --- |
| ① 主体动作与演变 | 静态姿态变成带先后微时序、重心缓冲与微表演的动作链 |
| ② 运镜与调度 | 构图变成机位路径、三维场面调度与焦点转移 |
| ③ 光影色彩流转 | 布光变成光源变化与人物穿梭明暗区的交互 |
| ④ 物理流体与交互 | 材质变成受力后的反应与次级运动 |
| ⑤ 视觉风格与时间节奏 | 风格锁定全片，另加动静疏密留白与变速 |
| ⑥ 声音与多模态视听 | 图片没有的新层，绑定画面动作并支持画外音先行与静默反差 |

### 时间轴三原则

- **因果。** 每个变化都有画面内可见的原因，且原因出现在更早或同一时间片。无因的变化会被模型随机生成或忽略。外部突发事件（停电、来车）本身可作起因，写出它的可见形态或前兆。
- **连续。** 上一时间片的终态就是下一时间片的起始态。切镜不越轴，尾帧保留惯性。
- **无歧义。** 每个主体一个称呼贯穿全片，方向用画面坐标，程度写成可见量，数量写死。比喻会被字面执行。

### 先写动作链，再排调度与时间片

先用 `X → 所以 Y` 写完整条事件链，每一步的起因是上一步的结果。再为每镜定好前中后景纵深层次、机位视点与唯一视觉焦点，最后把链切成 0.5 到 3 秒的时间片，每片围绕当前焦点只写这一刻变化的层，次要区域失焦或静止让位。这个顺序保证因果先于结果出现，且每拍都有明确的画面主次与调度。

### 输出必须带时间轴

输出结构参考 `fight-prompt`：

```text
主体 → 基准（媒介、空间、光色、声音）→ 动作链 → 时间轴 → 最后一帧 → 保留 → 负面提示
```

时间轴内每个 SHOT 写拍名与区间、时间片、CAMERA（起幅 → 运动 → 终幅），多镜时加 HANDOFF。时间片内按因果先后写句，层号只提示要覆盖的内容，不决定语序。

### 每次都做冷读

自检之后派一个只拿到 prompt 全文与素材职责的子 agent，逐句列出因果缺口、前后不接和有两种读法的句子。原规则只在多镜时冷读，测试中 12 秒单镜也暴露了问题，所以改为每次都做。冷读机制同样来自 `fight-prompt`。

## 验证状态

- image-prompt 的两份示例（雨夜弄堂、金毛改吉卜力）是按 SKILL.md 手写的，没有独立运行过。
- video-prompt 用“雨夜便利店，女孩接找零时停电”跑过一次子 agent 测试。根据反馈改了 5 处（突发事件起因、补层不改原话、时间片语序、单镜不查 HANDOFF、冷读每次都做），改后没有再跑第二次。
