# Prompt Skill 设计原则

## 共同原则

### 用分层模型组织 prompt

一张图或一段视频按解剖层级拆开，每层回答一个问题。prompt 的任务是让每一层都有确定的取值。分层取代了旧版的“交付物判断 → 检索术语 → 组织描述”流程。

- **信息只放在一层。** 同一信息跨层重复，会让模型对同一事物得到两份不一致的描述。
- **笼统词拆到具体层。** “电影感”“史诗”“高级”不直接写进 prompt，而是拆成比例、视角、反差、剪辑密度等可见取值。
- **只补会推偏的层并服从主次。** 模型会从媒介、风格与题材推出其余层的协调取值。用户没指定的层，只在模型默认会与意图冲突、取值要跨镜或跨张保持一致、或交付物本身要求时补一个明确选择，其余留给模型推理。补得越细，越容易被放大成夸张版本或稀释焦点：MJ 测试里写明“扇贝形云边”“岩石排线”，结果云边成了装饰花边、排线铺满整面悬崖，而只写“日式动画背景美术”时这些层反而推对了。补出的环境、光影与材质必须衬托第一视觉焦点（通过失焦、压暗、低饱和或留白让位），不添加抢戏的次要细节。
- **补层只填空位。** 用户已给的设定不得被补层改写。这条来自视频测试，子 agent 为了光源连续给“只剩门外车灯”加了一盏路灯。
- **锚点按带出的取值取舍。** 作者、作品、流派名会带出一整套取值。带出的都符合意图时直接用；与意图冲突的部分拆成下层的可见特征写出，或换掉锚点。MJ 测试里“cinematic”带出了黑边与字幕式小字，`--no` 压不住，删掉它改写具体调色后消失。
- **R2V 优先与状态在像素里。** 已绑参考图的实体不再在正文里重复抄写外观特征，只写视觉指代锚词、参考图看不出的补充和本段新发生的变化。身份图上已有的部件在片中被毁或卸下后，视频模型在后续镜头往往会把它画回来；这条只限制永久毁损绑图部件，不限制击退、踉跄、砸进掩体等不毁造型的直接受击，必须毁损绑图部件时分段改绑受损后的图。
- **编辑只写变化。** 不变的内容逐项写进「保留」。
- **少写禁令，给正面原理。** 过多防御性禁令、细分表格与繁琐门禁会把 agent 逼进保守合规模式、压死表现力（如过度执行「不毁绑图部件」导致整场战斗零受击）。skill 只守住模型真实会翻车的少数底层规律，用正面表述讲清原因，其余创作空间放开。

### 输出是分 section 的自然语言

- 每个 section 标题单独一行，内容写成完整短句，不堆标签。
- 标题不带 ①② 序号，不加【】括号。序号只是 skill 内部的分类工具，不进入 prompt。
- 只输出一种形式。不再附“合并成一段”的连续文本。
- 画幅、尺寸、张数、时长、分辨率由入口参数控制，不写进 prompt。不写 `--ar` 这类模型专用语法。
- **负向提示不混进正向粘贴块。** 单框模型会把粘进去的负向词当正向内容画出来。单框入口省略负面提示；仅在入口有独立负向字段时，在主代码块外另附负向块。

### General 指导原则，不绑定模型

skill 只写跨模型成立的写法。绑定某个模型的公式、语法和信息顺序不进 skill。视频的三份模型 reference（Seedance 2.0、Seedance 2.5、MiniMax H3）因此整体删除，其中不依赖模型的内容并入正文。

模型差异只留下通用的降级规则。例如入口不支持秒级时间戳时，时间片改写为“起初、随后、最后”，结构不变。

### 不做术语检索

image-prompt 旧版要求按任务检索范例、术语定义和模型文档，并附来源链接。这一整套已删除。保留的是一条交付检查，即每个专业术语都要能说出它改变了什么可见结果。这条管的是用词有没有用处，与检索无关。

### 不照抄资料里的例子

用户给的资料里有 60:30:10、丁达尔光、莫兰迪色这类具体例子。skill 只保留每层的类别，不把例子固化成规则。这与 `AGENTS.md` 的“删除非必要示例”一致。

## image-prompt：五层

| 层 | 决定什么 |
| --- | --- |
| ① 主体与内容 | 画里有什么、决定性瞬间与画外故事 |
| ② 构图与空间 | 透视性格、三层纵深、焦点景深与剪影分离 |
| ③ 色彩与光影 | 光比雕塑、受限光源动机与主次色彩对抗 |
| ④ 材质与肌理 | 材质反差、破除塑料感与焦点处的细节预算 |
| ⑤ 风格与美学 | 顶层艺术语言与审美哲学 |

### 先锁媒介

⑤ 的媒介形式决定 ③④ 用哪套语言。摄影写焦段、布光和胶片颗粒。绘画写色块和笔触。像素画写像素尺度和调色板。扁平画面不补物理微纹理，摄影不补笔触。

### 词序决定权重

越靠前的内容，模型分配的注意力越多。所以 ⑤ 在交付时拆成两处，媒介定性放最前，流派、氛围与渲染引擎放最后。

交付顺序：

```text
媒介定性 → 主体与内容 → 构图与空间 → 色彩与光影 → 材质与肌理 → 风格与美学
→ 参考 → 保留 → 文字
```

后三个 section 用不到就整段删除；入口有独立负向字段时，在主代码块外另附负面提示。

## video-prompt 与 fight-prompt：模型粒度加时间轴

图片是空间的艺术，视频是空间、时间与运动的艺术。引入时间轴后，每一层都从“某一刻的取值”升维为“沿时间的变化”，即起始状态、变化过程与结束状态。

| 层 | 从图片升维为 |
| --- | --- |
| ① 主体动作与演变 | 静态姿态变成带重心与节奏的可见动作链 |
| ② 运镜与调度 | 构图变成机位路径、三维场面调度与焦点转移 |
| ③ 光影色彩流转 | 布光变成光源变化与人物穿梭明暗区的交互 |
| ④ 物理流体与交互 | 材质变成受力后的可见反应与次级运动 |
| ⑤ 视觉风格与时间节奏 | 风格锁定全片，另加动静疏密留白与变速 |
| ⑥ 声音与多模态视听 | 图片没有的新层，绑定画面动作并支持画外音先行与静默反差 |

### 视频核心原则

- **粒度对齐。** 时间片按模型能兑现的拍划分（通常 1.5–4 秒一拍，完成一次可见动作加结果）；拍内快慢与先后用自然语言表达，不强切碎拍。
- **只选不搭。** 写观众看到的结果，不替模型逐关节拆发力链或物理成像过程。
- **接缝与全局段。** 每道切镜、变速或风格切换都是接缝，必须由戏里的转折换取。主体与基准里只放每一帧都成立的常驻事实，临时变化写在发生的那一拍。
- **因果、连续与无歧义。** 每个变化都有画内可见起因；同一因果的「出手 → 接触 → 首个可见反馈」必须留在同一拍、同一镜内同框完成，不被切镜、白场或大幅甩／摇镜切断。打击与破坏用「施力实体 + 碰撞动词 + 接触点」主动起句，不跳写成被动终态；核心碰撞优先实体碰实体，少靠纯光效隔空破坏。每个主体使用唯一带视觉锚词的称呼；近身对抗拉开外观极性防止串身；比喻改写成可见状态。
- **分段按接法分两类。** 连续动作接力停在蓄力顶点或微停顿等清晰帧，用尾帧锁开场；切镜、尺度跳变或部件受损换图时直接用 R2V 资产图开新镜，上段尾帧仅作环境与战损参考。

### 统一输出结构

草稿里的动作链只用于推导，不进入交付。每个镜头把 `CAMERA` 放在最前，让模型先定构图与机位路径再读各拍；不再输出 `HANDOFF` 等元数据行。

```text
素材绑定 → 主体 → 基准（媒介、空间、光色、声音）→ 时间轴（SHOT / CAMERA / 拍）→ 保留
```

### 每次都做冷读

自检之后派一个只拿到 prompt 全文与素材职责的子 agent，逐句列出因果缺口、前后不接和有两种读法的句子。原规则只在多镜时冷读，测试中 12 秒单镜也暴露了问题，所以改为每次都做。

## 验证状态

- image-prompt 的两份示例（雨夜弄堂、金毛改吉卜力）是按 SKILL.md 手写的，没有独立运行过。
- video-prompt 曾用“雨夜便利店，女孩接找零时停电”跑过一次子 agent 测试；本次统一按模型粒度、R2V 优先与负向分离重构后，尚未重跑端到端测试。
- fight-prompt 经多轮实拍迭代收束为模型粒度写法；根据实拍翻车复盘，补充了因果不跨接缝（含甩／摇镜与白场）、主动接触句式、实体碰撞优先、拍内接触时长预算以及不毁造型的直接受击规则。
