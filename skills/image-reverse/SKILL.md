# Image Reverse

从参考图反推可生成的规则。先定输出哪一种：图里的内容要被逐项重现，还是只保留风格、内容换掉。

## 先定模式

- **复刻**：要还原或复刻原图，或要求生成结果与原图逐项对得上。
- **锚点**：要抽取风格、迁移到新主体，或锁定系列的视觉一致；样本的具体物品、人物与情节不进入结果。
- 意图不明时按复刻输出。

## 共用原则

- **一条信息只放一个键。** 同一事物跨键重复，生成模型会得到两份不一致的描述。
- **媒介决定用词。** 摄影写画幅、胶片与镜片的成像特性；3D 写着色方式、渲染器与反射；绘画写画材、笔触与纸面；扁平图形写线宽、色块与输出规格，不写相机参数。混合媒介时，在媒介键写明每种媒介负责哪部分效果。
- **光学效果写成可见结果。** 二维绘画借用的景深、光晕、焦外光斑写成看得见的状态，如“背景虚化成色块”，不写焦段、光圈等镜头参数；镜头词会把画面拉向照片。
- **术语可解释。** 每个专业术语都能说出它改变了什么可见结果。

## 复刻

目标是用输出重新生成一张与原图逐项对得上的图。图里看得见的都要写，看不见的不补。

### 复刻写法

- **元素清单穷尽**：先列出画面里每个可见元素，包括主体、道具、环境物件、光源与天气介质，再逐个写进对应的键。清单里每一项都要在输出中出现。
- **写看到的状态**：被遮挡、隐入阴影或失焦的部分照原样写成“面部隐于阴影”“背景人物失焦成色块”，不补全看不见的细节，不写画面外的故事。情绪只写成可见的姿态、表情与视线。
- **锁定写实档位**：`medium` 用可见证据定死写实程度，例如有无线稿、五官比例是否动漫化、皮肤有无毛孔与真实褶皱；不用“动漫写实”“半写实”这类两头都能读的标签。`negative` 写相反方向的档位，插画排除照片级、3D 渲染与真实皮肤纹理，照片排除插画感。
- **锁住克制程度**：`lighting_color` 开头先写全图的明度档位与饱和度档位，再给每个发光、高饱和元素写相对强度与面积；只列出鲜艳元素而不给强度，生成模型会把它们全部放大。`medium` 写明各区域的细节完成度与笔触，例如焦点精细刻画、背景只是松散拖笔色块。
- **身份写成可见特征**：人物与角色写年龄段、体型、发型、服装、配色与标志性细节；品牌与作品写外形、配色与图案。
- **结构先于坐标**：先写清主体的结构链与物件间的连接，例如头朝向与躯干的关系、手臂从哪侧伸出、哪段被画框或遮挡截去、悬浮或手持之物由什么连着或托着。只罗列部件坐标而不写连接，生成模型会把部件当独立物件各自摆放，出现断开的肢体。
- **位置可复现**：左右一律以观者视角。主体与最大的几个元素写九宫格位置、占画面宽或高的比例、朝向与前后遮挡关系；小元素以这些锚点为参照写位置和尺寸，如“耳垂正下方”“直径约为手掌宽度的一半”。不用“拳头大小”这类实物类比，否则生成时会被放大。多个同类元素写数量。
- **参数推到可复现**：`technical_specs` 写能复现画面的设备与工艺参数，按媒介选用词。

### 复刻键

只输出一个 JSON 对象，按下表顺序使用这些英文键，值写成完整短句；语言跟随用户指定，未指定时用对话语言。键序即权重，越靠前越被优先满足。

| 键 | 写什么 |
| --- | --- |
| `medium` | 媒介形式、艺术流派与风格类型，各区域的细节完成度与笔触 |
| `subject` | 主体的识别特征、外观、服装与道具状态、姿态、表情与视线 |
| `scene` | 环境元素、天气与空气介质，以及它们的位置 |
| `composition` | 画幅方向、景别、视点高度、主体位置与占比、前中后景、引导线、焦平面与景深 |
| `lighting_color` | 每个光源的位置、方向与软硬，光比，配色比例，各元素的固有色 |
| `texture` | 各元素的材质与光学响应，媒介痕迹 |
| `technical_specs` | 复现参数 |
| `text` | 图中逐字出现的文本、字体气质与位置；没有文字时删除此键 |
| `negative` | 原图明显没有、生成时容易冒出的元素或瑕疵，以及与原图质感相反、生成模型默认会滑向的风格（原图克制时如过饱和、HDR、过度锐化、背景细节堆砌） |

### 复刻检查

1. **回生对照**：设想按输出重新生成，逐项对照原图的元素清单、位置占比、光源方向与配色，每一项都能对上，每个肢体和物件都能沿结构链连回身体或支撑物；全图明度、饱和度与细节密度和原图同档。
2. 同一信息只出现在一个键里。

## 锚点

风格锚点是换任何主体、景别与场景都不变的视觉规则。样本画的是什么，不进入结果。

### 锚点写法

- **换题换景测试**：主体换成任意无关事物、景别从特写换到全景后，每条规则仍然成立且可执行。构图、景别、主体占比、留白率、视点、焦段、景深与运镜随每个镜头的内容变化，属于镜头决策，不写入。
- **依附内容的特征改写成规则**：“红色雨衣”写成“小面积高饱和红作为唯一点缀色，只落在主体上”；“背景是一面灰墙”写成“背景只用单一中性灰面，不出现可辨识的环境细节”。结果里只出现视觉属性词，物品名、人物身份、地点与事件全部改写或删除。角色或物件的标志性视觉特征（特殊瞳纹、伤疤、发型、徽记）也属于身份：只保留它承担的视觉功能，如“画面唯一的自发光焦点”，形状与载体不写入。
- **规则写成可判定的边界**：用上限、比例、数量、允许与排除的范围表达，例如饱和度上限、点缀色个数、暗部占比、光比区间。拿到一张新画面，能据此判断它合不合规。“高级”“电影感”这类笼统词先拆成边界再写入。
- **多张样本分锁与放**：所有样本共有的特征进锁；在样本间变化的维度写明变化范围，作为允许的自由度。只有一张样本时，按它最强的特征外推成规则。
- **一条特征只放一个键。** 可见效果归它所属的键，泛光归 `lighting_order`，颗粒归 `texture_system`，偏色归 `color_system`；`technical_specs` 只写成因参数；`mood` 只写情绪，制造情绪的光色手段留在各自的键。

### 锚点键

只输出一个 JSON 对象，按下表顺序使用这些英文键，每个值是一到三句规则；语言跟随用户指定，未指定时用对话语言。

| 键 | 写什么 |
| --- | --- |
| `medium_style` | 媒介形式、艺术流派与风格类型 |
| `space` | 世界定义（低信息密度的抽象空间还是高细节叙事环境）、开放度与压迫感、元素密度上限、背景的简化程度；画面有文字或图形时写字体与处理方式 |
| `color_system` | 主色、辅色、点缀色的比例与饱和度上限，冷暖倾向，暗部与高光的偏色 |
| `lighting_order` | 光的性格（无主光的均匀柔光还是高反差硬质雕刻光）、光源方向与软硬、物理可信还是超现实、光比区间 |
| `texture_system` | 物理表面规则与微观质感，媒介痕迹（噪声、颗粒、笔触）的有无与强度 |
| `technical_specs` | 能复现以上效果的设备与工艺参数 |
| `mood` | 核心情绪与精神内核 |

### 锚点检查

1. 每个值都通过换题换景测试。
2. 每条规则都能用来判定一张新画面是否合规。
