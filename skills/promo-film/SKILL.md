# Promo Film

宣传片不展示能力，它让观众**亲历**能力带来的差异。直白的方案把卖点拍成画面的样子：分辨率拍成一片清晰风景，续航拍成满格电量。成立的方案让卖点成为剧情的**原因**：没有这个能力，片里的事就不会发生，或者根本看不见。这叫**内在戏剧性**，它本来就藏在卖点里。工作是把它找出来，而不是给卖点配图。

动手前收齐会改变方案的事实：总时长、目标生成模型及其单次时长上限、是否生成声音、品牌落款。每一步的产出都写下来，后一步以前一步为硬约束。

## 1. 差异

- 一支片只讲一个卖点。用户给了多个时，选差异最大、最能被感官直接感知的一个，其余列为落选并写理由。
- 把卖点改写成**差异句**：`之前，观众不能［看见／做到／感到］……；之后，能……`。用观众的感官和行动写，不用参数。
- 列出**彼岸**：跨过差异之后才存在、之前绝不可能出现在画面里的具体事物，至少 3 样。它们是兑现的原料。

完成标准：差异句不含产品名与参数，不懂技术的人读完能说出自己多得到了什么；彼岸 3 样以上，每样都画得出来。

## 2. 五步语法

每个方案都是同一条语法的一次实例：

| 步 | 动作 | 要回答的问题 |
| --- | --- | --- |
| 差异 | 第 1 步已写定 | 跨过去之后多了什么 |
| 门槛 | 把「决定跨过去」具象成一个物件或仪式 | 观众看到什么动作，就知道有人要跨过去了 |
| 蜕变 | 把跨越的过程拍成奇观，并给它一个**刻度** | 变化长什么样；观众凭什么相信它在一级一级地变 |
| 兑现 | 拿出彼岸的一样东西，最强的形态是它自带一个**秘密** | 新能力揭开的那一层世界里，正在发生什么没人见过的小事 |
| 签名 | 最后一个画面的物件或纹理直接承载品牌名 | 最后一帧能不能直接当字卡的底 |

**秘密**是幽默的来源，也是证据：笑点只有靠新能力才看得见，观众笑的同时就信了。把秘密写成一个有动作的日常小事，不写成静物。

让每一步脱离直白的**算子**，每步至少用一个：

- **具象化**：把参数变成能拿、能吞、能拧、能打开的物件。
- **借原型**：借全人类共享的仪式，比如抉择、饮下、开门、调焦、拆封、点火。具体作品的物件、角色、构图与台词不借。
- **尺度跳跃**：从宏观一路推到微观，或者反过来。
- **拟人日常**：彼岸世界里的生物或物件在过自己的日子。
- **反面先行**：先让观众困在差异的此岸，再给出门槛。
- **闭环**：结尾的物件回到开头，或者变成落款。

**校准**：一支宣传「4K 模式」的片子是这样实例化的，这里只取结构。

| 步 | 实例 |
| --- | --- |
| 门槛 | 两只手分别托着标了版本号与「4K」的药丸，等人选 |
| 蜕变 | 吞下后进入万花筒式的碎裂空间，角落的分辨率计数一路上涨 |
| 兑现与秘密 | 微距下的叶片上，一只螳螂正用小毛巾擦身上的水珠 |
| 签名 | 毛巾的绒面纹理铺满画面，成为标题的底 |

## 3. 发散

1. 先写出 3 个你最先想到的方案，标为**基线**。它们就是直白方案的样本。
2. 再写至少 8 个正式方案，每个一行：方案名、五步各一短句、用到的算子。
3. 正式方案之间门槛物件与世界两两不同，且不与任何基线共享门槛物件或世界。至少一半方案的世界与产品所在行业无关。

完成标准：8 个以上正式方案，每个五步齐全，算子写明。

## 4. 闸门

每个正式方案逐条过闸，每条写通过或不通过，加一句理由：

- **属性测试**：卖点在片里是画面的样子，还是剧情的原因？是样子就不通过。
- **删除测试**：拿掉这个能力，门槛到签名这条链还能照常发生吗？能，说明卖点没有承重。
- **秘密测试**：兑现那一刻，没有新能力的观众看得见它吗？看得见，兑现就不成立。
- **一眼测试**：静音、无字幕时，开场 3 秒能不能让人想看下去？
- **原创测试**：只借了原型才算通过。用了具体作品里可辨认的物件、角色或构图，换掉再测。
- **可生成测试**：主要角色与关键道具加起来不超过 3 个，关键动作不依赖可读文字或精确计数。

全部通过的方案里选 2 个核心隐喻不同的，作 A/B 两版，推荐其一并写理由。全过的不足 2 个时，回到第 3 步补发散。

完成标准：每个正式方案 6 条结论齐全；A/B 两版选定。

## 5. 节拍表

按五步分配时长，比例随方案浮动：

| 段 | 约占总时长 |
| --- | --- |
| 门槛（含开场钩子） | 25–35% |
| 蜕变 | 20–30% |
| 兑现与秘密 | 20–25% |
| 签名 | 10–15% |
| 品牌卡 | 5–10%，可在后期做 |

每个节拍写四项：画面里可见的动作与结果、刻度落在哪里、声音、给后期留的位置。

- 刻度至少走两个通道：画面里的物理变化逐级发生，声音逐级叠加。数字计数只在后期叠加。
- 秘密是全片最慢的一段，给观众时间去发现。
- 签名段接近静止，画面里留出大面积干净区域给标题。
- 每个角色和道具至少在两个节拍里承重。只出现一次的删掉。

完成标准：时间轴无缝覆盖总时长；每个节拍四项齐全；签名段写明留白区域的位置。

## 6. 生成 prompt 与后期说明

A/B 各写一份 prompt：

- 开头一段定媒介与画风：摄影写焦段、布光、颗粒，动画写线条与色块。
- 按节拍分段，写上起止秒数。入口不支持秒级时间时，改写成「起初、随后、最后」，结构不变。
- 每段写可见的动作和结果，不写「震撼」「高级」这类评价词。
- 关键道具第一次出现时写清它的几何（形状、尺寸、材质、位置），之后各段用同一个名称复现它。
- 画面里不生成任何文字、数字、标志与界面元素，在 prompt 里明确写出。文字一律在后期叠加：生成出来的字容易糊，超分之后再叠也更锐利。
- 结尾写一段声音：刻度的每一级对应一个声音事件，音乐的起伏跟着五步走。
- 目标模型有 prompt 指南时，长度、语法与参数以指南为准。

后期说明写三项：刻度叠加的起止秒和对齐的声音事件，标题的位置、配色与文案，品牌卡的时长。

完成标准：每段 prompt 都能对应回节拍表的某个节拍；后期说明三项齐全。

## 7. 看片验收

环境里能生成时，提交 A/B 后等待成片，抽帧逐个节拍对照：

- 门槛一眼可读。
- 刻度一级一级地变。
- 兑现物和秘密的动作都出现了。
- 签名段的留白干净。

不通过时定位到具体节拍，只改那一段 prompt 重跑。同一个元素两次没生成出来，就换成更好画的物件，不靠加形容词硬推。
