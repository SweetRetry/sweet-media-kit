# Image Replicate

目标是用输出重新生成一张与原图逐项对得上的图。图里看得见的都要写，看不见的不补。

## 写法

- **元素清单穷尽**：先列出画面里每个可见元素，包括主体、道具、环境物件、光源与天气介质，再逐个写进对应的键。清单里每一项都要在输出中出现。
- **写看到的状态**：被遮挡、隐入阴影或失焦的部分照原样写成“面部隐于阴影”“背景人物失焦成色块”，不补全看不见的细节，不写画面外的故事。情绪只写成可见的姿态、表情与视线。
- **锁定写实档位**：`medium` 用可见证据定死写实程度，例如有无线稿、五官比例是否动漫化、皮肤有无毛孔与真实褶皱；不用“动漫写实”“半写实”这类两头都能读的标签。`negative` 写相反方向的档位，插画排除照片级、3D 渲染与真实皮肤纹理，照片排除插画感。
- **锁住克制程度**：`lighting_color` 开头先写全图的明度档位与饱和度档位，再给每个发光、高饱和元素写相对强度与面积；只列出鲜艳元素而不给强度，生成模型会把它们全部放大。`medium` 写明各区域的细节完成度与笔触，例如焦点精细刻画、背景只是松散拖笔色块。
- **身份写成可见特征**：人物与角色写年龄段、体型、发型、服装、配色与标志性细节；品牌与作品写外形、配色与图案。
- **结构先于坐标**：先写清主体的结构链与物件间的连接，例如头朝向与躯干的关系、手臂从哪侧伸出、哪段被画框或遮挡截去、悬浮或手持之物由什么连着或托着。只罗列部件坐标而不写连接，生成模型会把部件当独立物件各自摆放，出现断开的肢体。
- **位置可复现**：左右一律以观者视角。主体与最大的几个元素写九宫格位置、占画面宽或高的比例、朝向与前后遮挡关系；小元素以这些锚点为参照写位置和尺寸，如“耳垂正下方”“直径约为手掌宽度的一半”。不用“拳头大小”这类实物类比，否则生成时会被放大。多个同类元素写数量。
- **参数推到可复现**：`technical_specs` 写能复现画面的设备与工艺参数（画幅、焦段、光圈、胶片或渲染器、调色），按 `medium` 的媒介选用词。二维绘画借用的光学效果（景深、光晕、焦外光斑）写成可见结果，如“背景虚化成色块”，不写焦段、光圈等镜头参数；镜头词会把画面拉向照片。

## 键

只输出一个 JSON 对象，按下表顺序使用这些英文键，值写成完整短句；语言跟随用户指定，未指定时用对话语言。键序即权重，越靠前越被优先满足。

| 键 | 写什么 |
| --- | --- |
| `medium` | 媒介形式、艺术流派与风格类型，各区域的细节完成度与笔触 |
| `subject` | 主体的识别特征、外观、服装与道具状态、姿态、表情与视线 |
| `scene` | 环境元素、天气与空气介质，以及它们的位置 |
| `composition` | 画幅方向、景别、视点高度、主体位置与占比、前中后景、引导线、焦平面与景深 |
| `lighting_color` | 每个光源的位置、方向与软硬，光比，配色比例，各元素的固有色 |
| `texture` | 各元素的材质与光学响应，媒介痕迹 |
| `technical_specs` | 复现参数 |
| `text` | 图中逐字出现的文本、字体气质与位置；没有文字时删除此键 |
| `negative` | 原图明显没有、生成时容易冒出的元素或瑕疵，以及与原图质感相反、生成模型默认会滑向的风格（原图克制时如过饱和、HDR、过度锐化、背景细节堆砌） |

## 交付前检查

1. **回生对照**：设想按输出重新生成，逐项对照原图的元素清单、位置占比、光源方向与配色，每一项都能对上，每个肢体和物件都能沿结构链连回身体或支撑物；全图明度、饱和度与细节密度和原图同档。
2. 同一信息只出现在一个键里。
3. 每个专业术语都能说出它改变了什么可见结果。
