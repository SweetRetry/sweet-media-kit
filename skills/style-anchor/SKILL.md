# Style Anchor

风格锚点是换任何主体、景别与场景都不变的视觉规则。样本画的是什么，不进入结果。

## 从观察升到规则

- **换题换景测试**：主体换成任意无关事物、景别从特写换到全景后，每条规则仍然成立且可执行。主体占比、留白率这类随景别变化的取值，注明适用景别。
- **依附内容的特征改写成规则**：“红色雨衣”写成“小面积高饱和红作为唯一点缀色，只落在主体上”；“背景是一面灰墙”写成“背景只用单一中性灰面，不出现可辨识的环境细节”。结果里只出现视觉属性词，物品名、人物身份、地点与事件全部改写或删除。
- **规则写成可判定的边界**：用上限、比例、数量、允许与排除的范围表达，例如饱和度上限、点缀色个数、留白占比、光比区间。拿到一张新画面，能据此判断它合不合规。“高级”“电影感”这类笼统词先拆成边界再写入。
- **多张样本分锁与放**：所有样本共有的特征进锁；在样本间变化的维度写明变化范围，作为允许的自由度。只有一张样本时，按它最强的特征外推成规则。

## 键

只输出一个 JSON 对象，按下表顺序使用这些英文键，每个值是一到三句规则；语言跟随用户指定，未指定时用对话语言。

| 键 | 写什么 |
| --- | --- |
| `medium_style` | 媒介形式、艺术流派与风格类型 |
| `space` | 世界定义（低信息密度的抽象空间还是高细节叙事环境）、开放度与压迫感、留白率、几何秩序（对称、黄金分割、网格）、元素数量上限、主体占比、视点与景深；画面有文字或图形时写排版逻辑 |
| `color_system` | 主色、辅色、点缀色的比例与饱和度上限，冷暖倾向，暗部与高光的偏色 |
| `lighting_order` | 光的性格（无主光的均匀柔光还是高反差硬质雕刻光）、光源方向与软硬、物理可信还是超现实、光比区间 |
| `texture_system` | 物理表面规则与微观质感，媒介痕迹（噪声、颗粒、笔触）的有无与强度 |
| `technical_specs` | 能复现以上效果的设备与工艺参数 |
| `mood` | 核心情绪与精神内核 |
| `cinematic_preset` | 仅当目标是视频时输出：机位高度与焦段、运动方式与速度、镜头时长与剪辑节奏、观看姿态 |

- **媒介决定用词**：`medium_style` 判定的媒介决定 `texture_system` 与 `technical_specs` 的语言。摄影写画幅、焦段、光圈、胶片；3D 写着色方式、渲染器与反射；绘画写画材、笔触与纸面；扁平图形写线宽、色块与输出规格，不写相机参数。混合媒介（如绘画叠加镜头光晕与景深）时，在 `medium_style` 写明每种媒介负责哪部分效果。
- **一条特征只放一个键**：可见效果归它所属的键，景深归 `space`，颗粒归 `texture_system`，偏色归 `color_system`；`technical_specs` 只写成因参数；`mood` 只写情绪，制造情绪的光色手段留在各自的键。
- **镜头从静帧线索反推**：绝对对称、深景深与静止主体指向固定机位或极慢推移；浅景深贴近主体指向微距推移或慢速跟焦；倾斜构图与运动模糊指向手持或快速运动。

## 交付前检查

1. 每个值都通过换题换景测试。
2. 每条规则都能用来判定一张新画面是否合规。
3. 每个专业术语都能说出它改变了什么可见结果，且用词属于 `medium_style` 的媒介。
