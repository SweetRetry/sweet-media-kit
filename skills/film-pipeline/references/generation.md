# 生成装配阶段

默认采用**两轮 R2V 装配**。第一轮试拍 1–3 个最关键或最难单元验图验模型，第二轮批量出齐其余并行 R2V 单元；仅对少数有接力或首帧依赖的单元按依赖补轮。

`4-generation.md` 包含三块：顶部的**试拍结论**（已验证的定妆／光效锚点帧、模型稳定偏差与有效写法）、各轮**生成单**、底部的**镜头落位表**。进入生成装配后，**落位表是唯一事实源**。

## 执行节奏

1. **输入检查**：只给输入已齐的单元出生成单。输入已齐指：多镜资产均有真实参考图（非「占位」，除非用户明确放行）；有接力或首帧依赖时对应文件已选定。缺图单元标为「待图阻塞」并列清单。
2. **第一轮试拍**：挑最能检验资产锁定与动作上限的 1–3 个单元出生成单（若全片只有极少并行 R2V 单元，可直接一轮出完）。等待用户返回选定文件，把最稳的光效锚点帧与模型偏差写入「试拍结论」。
3. **批量出片**：按「试拍结论」修正写法，一次性写出所有输入已齐的并行 R2V 单元生成单。等待结果时，可先做后期阶段不依赖画面的文案与脚本结构。
4. **落位与纠偏**：
   - **落位表**：记录每个 Shot 的选定文件、起止帧与帧率。单单元含多个 Shot 时按帧区间拆行；黑屏字卡等非生成 Shot 标「后期生成」与时长。
   - **轻微漂移不回改分镜**：站位、持物或时长的小幅偏差直接记在落位表供后续接力或后期裁短处理，不反复改写 `3-shots.md`。
   - **局部可用裁短接力**：片段前段达标、后段崩坏时，直接按可用帧区间落位，仅把剩余内容拆新单元接力，不必整段重抽。
   - **锚点复用**：试拍中光照与质感最稳的帧，在参考图预算允许且模型支持时，可作为同场 R2V 单元的氛围／光效参考。
   - **结构性退回**：同一动作或构图失败两次，退回镜头阶段改拆分、机位或补首帧；某张资产参考图在多单元持续导致漂移或串色，退回资产阶段记缺口换图。

所有单元落位后，把落位表交给后期阶段。

## R2V 生成单写法

生成单只引用上游档案、试拍结论和已落位文件。不要重复抄写参考图已清晰表达的外观细节。

- **prompt**（用目标模型语言，按以下顺序）：
  1. 参考图绑定：写清每张参考图对应画面里的角色、场景或道具。
  2. 镜头与动作：景别机位运镜、动作起止与时间顺序（多镜头单元写明切换时点与时长分配）。
  3. 增量与纠偏：只写当前状态变化、参考图看不出的细节、「试拍结论」里的纠偏项，以及（如有）特效段落与强度级。
  4. 音频与对白（按立项音频方式）：原生音频模型写明画内台词（含情绪）、关键音效与环境音，无台词时明确人物不说话；外部配音模式只写说话口型动作。
  5. 画面留净：后期承担的字幕、文字说明与界面不写入画面，画内屏写成发光空屏。
- **参考输入**：只列本单元使用的资产参考图（及参考音频、可选试拍光效锚点帧），写明绑定对象与锁定维度；防止参考图姿势改变长相、背景改变固有色。若为例外接力或带首帧单元，同时写明具体清晰帧号或首帧文件（需先出首帧时，先给出该帧的参考图与构图要求，等选图后再出视频生成单）。
- **入口参数**：画幅、档位时长（标明有效时长与余量／尾缓冲）、分辨率。

## 关卡

1. 本轮所有生成单的输入都是真实文件，未依赖未放行的「占位」资产。
2. 试拍结论与已落位素材的帧区间均已记录完整。
