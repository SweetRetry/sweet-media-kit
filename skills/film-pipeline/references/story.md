# 故事阶段

故事阶段回答「发生了什么」，不回答「看起来怎样」「怎么拍」。剧本的读者是下游各阶段与生成模型，所以行为要具体到可拍、可听、可演，外观与镜头留白给下游。

## 世界规则

世界规则是支撑冲突、动机与因果的最小规则网，每条都承担动机、约束、代价、冲突或伏笔之一，不承担的删掉。按需沿以下方向推导，不逐项填满：

- **前提与边界**：核心假定、基调、故事发生的主舞台。
- **力量与代价**：超常力量或技术的获取门槛、消耗、上限与反噬。
- **资源与地理**：稀缺资源与空间阻隔如何塑造势力分布。
- **权力与秩序**：谁掌握力量或资源，合法性从哪来。
- **历史与矛盾**：过去的事件如何沉淀成当下的阵营与引爆点。
- **日常行为**：人们怎么生活、劳作、交易、祭祀。只写行为与习俗，器物与服饰的样子不写。

下层设定必须能追溯到上层规则；推不出来的补足因果或删除。用户已锁定的设定是硬约束，设定之间出现破坏剧情的矛盾时，列出来源与影响交用户裁决。关键设定标注故事功能，如 `[冲突根源]`、`[核心代价]`、`[伏笔]`。

## 大纲因果链

1. **想要与需要**：主角追求具体的外在目标，受制于内在缺陷或未满足的需要。
2. **激励事件**：打破原有平衡，迫使主角行动。
3. **赌注升级**：失败有实质损失；对手、阻碍或倒计时不断加码，封死退路。
4. **两难抉择**：在不可兼得的两者间做出不可逆选择，付出真实代价。
5. **高潮与状态差**：主副线在此交汇；结局时人物、关系或世界发生不可逆变化。

## 场次

删掉不影响后续理解、关系或情绪递进的场次，或与相邻场次合并。每场按四步写：

1. **进场意图**：人物带着明确、急迫的具体目标进场。
2. **阻碍与攻防**：对方有相反目标或环境阻碍，多轮行动与对白交锋。
3. **翻转**：离场时的价值状态与进场时极性相反（希望进场、被背叛离场）。
4. **离场驱动**：本场结果直接触发下一场。

## 剧本写法

- **外化**：心理写成身体动作（`反复揉搓口袋里的旧纽扣`），关系写成距离、视线与站位，信息写成道具交互（`撕碎信件`）。
- **动作段**：现在时、主谓宾、强动词。复杂接触、战斗或连续动作按「起点、接触与反馈、终点」三段拆开。
- **特效事件**：只写触发者、作用对象与结果（`她按住地面，裂缝沿街道追上马车，车轮陷进去`），不写颜色、光效与形态。
- **对白即行动**：每句对白承担一个战术（试探、施压、回避、伪装、切断），不直接说出心理，不生硬交代设定。
- **声音事件**：只写推动剧情的声音（`门外传来第二声枪响`），配乐与音效设计留给镜头阶段。

场次头只写剧情需要的事实：

```text
SC01 - 场景名 - 内景/外景 - 时段 - 天气（剧情需要时）

动作段。

角色A
（动作或语气）
台词。

[离场状态]
```

## 实体与状态账本

剧本定稿后整理：

- **角色**（`C01`）、**场景**（`S01`）、**关键道具**（`P01`）、**特效事件**（`FX01`）：编号、名称、出场场次。
- **剧情状态**：按时间线列出每个实体在哪一场进入什么状态（`C01 自 SC05 起失去左臂`、`S02 自 SC07 起东墙倒塌`）。只写发生了什么，不写长什么样。
- **分级**：主资产全片高频出现，次要资产阶段性出现，一次性的路人与杂物不入账本。

## 自审

1. 推进全由人物选择驱动；每个选择所依据的信息此前都在画面或声音里出现过。
2. 每场都有极性翻转。
3. 没有不可拍的心理描写，对白有潜台词。
4. 没有颜色、光线、材质、外观、机位与特效外观的描述。
5. 账本覆盖剧本中每个反复出现的实体与每次状态变化。
