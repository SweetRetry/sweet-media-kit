# 特效阶段

特效阶段回答「特效如何发生、长什么样、怎样消失、碰到东西会怎样」。输入是故事账本里的特效事件、视觉阶段的美术规则与资产档案；输出是可在多个镜头复用的特效档案。它不定机位，不改资产外观，不改剧情结果。

## 建档范围

- **建档**：账本里的特效事件；全片反复出现或推动剧情的环境动态（持续的暴雨、贯穿全片的灰烬）。
- **不建档**：一次性的烟尘、水花、火星，留给镜头阶段在单镜里直接描述。

同一能力的不同强度（试探、全力、失控）写成同一档案的分级，不拆成多个档案。

## 特效档案（`FX01`）

- **来源**：由谁或什么触发，从哪个部位或哪个物体发出，借什么介质（`C01 左手掌心`、`P02 剑刃裂缝`）。
- **实体形态**：把特效写成有形的物质，说清它是火、液体、气体、碎片、光、电弧还是别的，以及形状、密度、边缘、尺度（相对人物身高）。「能量」「力量」「魔力」不是形态，必须落到具体物质。
- **颜色**：从美术规则的特效色相中取，写明核心与边缘的颜色和亮度差。
- **时间曲线**：起势、爆发、持续、消散四段，各段写明形态怎么变、各占整个过程的多少比例。只写相对比例，绝对秒数由镜头阶段按剪辑节奏定。起势给观众预判，消散写清最后留下什么（焦痕、残烟、结霜）。
- **物理作用**：作用到环境与角色时发生什么。受力方向与位移、破坏方式、对周围的照明（投在地面和脸上的光色）、二次粒子（溅起的碎石、被吹动的头发和衣摆）。造成的持久破坏必须对应账本里的剧情状态，外观结果按视觉档案的状态变体呈现。
- **声音特征**：起势、爆发、消散各自的声音质感与空间感。
- **分级**（如有）：各强度级别在尺度、亮度与破坏上的差别。

## 写法

- 先物理，后美化。特效的说服力来自它和世界的相互作用，作用写对了，外形可以克制。
- 特效亮度不压过画面主体的脸与动作焦点，除非这个镜头的主体就是特效。
- 同一特效在不同镜头里复用同一档案，只按需取其中的阶段与分级。

## 自审

1. 每个档案都能从来源讲到消散。
2. 颜色都取自特效色相。
3. 持久破坏都对应账本状态，没有新增剧情结果。
4. 没有写景别、机位与运镜。
