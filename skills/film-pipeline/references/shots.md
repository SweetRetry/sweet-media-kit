# 镜头阶段

镜头阶段回答「观众在什么时候、从哪里、看到什么」。输入是剧本、视觉档案与特效档案，输出是 Scene／Beat／Shot 分镜与生成单元划分。镜头只用编号引用资产状态与特效阶段，不新增外观与特效形态。

推进顺序：场次（Scene）→ 节拍（Beat）→ 镜头（Shot）→ 生成单元（Gen）。

## 视听语言

按叙事需要选，每个选择都要说得出它的观看任务：

- **景别**：大远景与全景交代环境与势力对峙；中景交代互动与站位；近景交代表情与情绪爆发；特写交代道具、伤口与线索。
- **机位**：客观视角保持观察距离；主观视角让观众成为角色；仰拍给主体压迫感，俯拍显出渺小受困；倾斜构图表示失衡。
- **看点进画**：本镜看点是谁的反应，机位就放在看得见那张脸的一侧；用背面、侧面或越肩机位时，确认看点仍在画内。
- **运镜**：运镜控制观众何时得到答案（先空景，再局部，再辨认主体，最后拉开揭示危机）。固定强调画内动作；推进加紧张；拉出揭示环境与孤独；摇镜建立空间或制造惊吓；跟随带来现场感。运镜与人物动作一起设计，不在剧情完成后补装饰。

## 连续性

- **轴线**：对话与对打的双方之间有一条轴线，机位留在同侧半圆。要越轴时先给一个正对轴线的中性镜头，或用运镜连续划过去。越肩镜头写明是哪侧肩，环绕写明绕哪一侧。
- **视线与运动方向**：前镜向右看，后镜被看者在左侧向左看；从右出画，下一镜从左入画。同一段旅程的去程与回程各定一个画面方向，全片沿用。
- **光向**：同一场景里的主光方向固定，按视觉档案的光线基调定具体方向。
- **状态**：持物的手、伤口、污损与服装状态按账本时间线继承上一镜的终态。

## 声音

剧本里的对白与声音事件按镜头落位；在此基础上设计配乐的进出、音效与环境音，以及它们的相对音量。特效的声音沿用特效档案的声音特征。声音交代重量、空间与动作节拍。J-Cut 与 L-Cut 让声音先于或晚于画面切换。

## 生成单元

- 一个单元承载多少动作、时长与场景跨度，以目标模型的官方能力说明或实测为准。模型可靠时，连续动作链、多镜头与一镜到底放进同一单元；超出可靠范围时，在动作暂停或场景切换处拆开。
- **剪辑点**：动作中途切镜让动势跨镜连贯；人影或前景遮挡擦过镜头时切换，拼接前后两段生成。
- **接力**：跨单元时写明前段尾帧即后段首帧。后段是连续动作时，前段尾帧保留向前的运动惯性，不提前减速定格。复用其他单元的帧时，光线、道具与人物状态随之继承。

## 分镜格式

```text
### Scene 01 - 场景编号 S01 - 时段/天气
本场戏剧目标

#### Beat 1：节拍名与信息转移

- Shot 1.1
  - 观看任务：建立环境 / 施加压迫 / 揭示线索 / 动作反馈
  - 景别、机位、运镜
  - 构图：主体位置、前景遮挡、焦点
  - 出场：C01（SC05 后状态）、P02（激活）、FX01（爆发段，全力级）
  - 动作：起始状态、过程、结束状态
  - 光向与环境动态：主光方向，一次性的烟尘水花在此直接描述
  - 声音：对白、音效、环境音、音乐
  - 时长与生成单元：3s，Gen 01，承接 Shot 1.0 尾帧站位
```

## 自审

1. 每个 Shot 的出场状态与账本时间线一致。
2. 轴线、视线、运动方向与光向跨镜连续。
3. 没有新外观与新特效形态；需要时退回视觉或特效阶段。
4. 每个生成单元都在目标模型的可靠范围内。
