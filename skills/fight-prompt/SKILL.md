# Fight Prompt

好战斗 prompt 的核心只有一件事：**给足戏剧张力和视觉想象力，同时把画面写成视频模型能连贯兑现的物理因果**。

下面的原则帮你避开视频模型的真实短板，除此之外放开写，把戏写活、把节奏写爽。

## 1. 五条底层原则

视频模型自带丰富的动作、物理和镜头先验，顺着它写比卡死细节效果好得多：

1. **因果同框，写出接触**。一次关键撞击的「出手 → 接触 → 首个可见反馈」留在同一镜、同一拍内同框完成，让镜头稳稳看清撞击，再考虑切镜或运镜追余波。写打击与破坏时，以主动碰撞起句（谁的什么撞上哪儿、从落点炸开什么反馈与终态），让画面从接触点长出来，而不是跳过撞击直接画结果。
2. **按「拍」写，只选结果不拆过程**。视频模型最舒服的时间粒度是一拍约 2–4 秒，刚好装下一次看得清的核心交锋与反馈。拍内的轻重快慢用自然语言点出来即可，发力链、微动作和特效成像交给模型先验去补。
3. **真打到人，实体优先**。实体碰实体（兵刃、拳脚、躯干、重物直接撞人或砸物）在视频里最容易出重量感和真实因果；光效顺着挥击拖尾和命中爆发走，配合实体放大冲击。让角色真正受击（击退、踉跄、掀翻、砸进掩体、单膝跪地），只要不永久损毁参考图上固定的盔甲或配饰（模型后镜容易画回来），身体受力完全可以放开写。
4. **状态在像素里，图有则不重抄**。身份、造型、战损和站位交给参考图与尾帧。已绑图的实体只需写清指代称呼和图中看不出的补充（如相对体量、新变化），把篇幅和模型注意力留给动作与运镜。未给图时写足辨识特征，使 prompt 裸跑也成立。
5. **只写拍得到、听得到的画面**。每个主体用带视觉辨识度的称呼贯穿全片（近身混战拉开双方配色或轮廓反差防串身）；特效写成可见的色形物象；每帧常驻的设定放全局段，临时变化写在发生的那一拍。

## 2. 先想清楚这场戏（草稿，不进 prompt）

动笔前用几句话想透，不照抄进正文：

- **戏眼与翻转**：主角此刻是什么状态、观众该感受到什么、战局在哪一下翻转，以及决胜高潮留下什么只属于这场戏的记忆画面（不必只是更大的爆炸）。
- **攻防与节奏**：按双方体量、射程和人数定打法，快慢疏密、声静张弛拉开反差，每一步由上一步的受力或环境变化自然逼出。
- **分段策略**（仅超单次时长时）：连续动作接力停在蓄力顶点或微停顿等清晰帧，用尾帧锁下段开场；尺度跳变、遮挡切镜或需要换受损新图时，直接用参考图开新镜，上段尾帧仅作环境与战损参考。

需求未给出的设定（画风、对手体量、胜负、结尾等）直接按最出彩的方案定下，交付时顺带列成代选。

## 3. 输出结构

输出纯文本，用不到的行整行删去。画幅、时长、分辨率由入口参数控制；不支持秒级时间戳的入口改用「起初、随后、最后」；不出声音的入口删去声音描写。

```text
素材绑定（有图时写）
「[图名]」对应[视觉称呼]，锁定[外观／画风]；动作、站位与构图由下文决定。
（续段按接法写明「承接图」锁开场画面，或仅参考环境与战损现状）

主体
（已绑图时只写称呼与图中看不出的补充；未绑图时写足辨识特征）
[视觉称呼]：[特征或补充]。

基准
媒介：[画面媒介与质感]。
空间：[场景、地面材质与远景]。
光色：[开场天光、主光与双方形成反差的主色]。
声音：[配乐与环境基调]。

时间轴
SHOT 01｜0–[N]s
CAMERA：[起幅景别与角度] → [连续运镜路径] → [终幅构图]。
0–[a]s：[主动接触、直接受力反馈与终态]。声音：[新声源或配乐转向]。
[a]–[b]s：[下一拍]。
```

单框入口省略负面提示，不混入正向代码块；仅在入口有独立负向字段时，在主代码块外另附负向块。

## 4. 交付前轻核与冷读

写完只查三件最容易翻车的事，发现问题直接改顺原句：

1. **因果与接触**：每次关键打击和破坏，出手、接触与首个反馈都在同一镜、同一拍内同框发生，且写出了主动接触，没有被切镜、白场或大幅甩镜吞掉。
2. **清晰与不重述**：时间片衔接合理，全局段只放常驻事实，已绑图的外观没重复抄写，无歧义称呼和拍不到的抽象词。
3. **好看**：画面有真正的身体受击、节奏反差和让人记住的高潮瞬间。

随后做一轮**冷读**（有子 agent 时派发一个，只给 prompt 与素材清单；没有则自己读）：按时间复述每拍看到了什么，标出看不到接触的破坏、断链的因果或有两种读法的句子，修顺后交付。

交付时正向 prompt 放进单独代码块可直接整块粘贴；有独立负向字段时另附负向块；缺图或有代选设定时在代码块外简附清单。分段时标明每段对应时间区间与上传素材。
