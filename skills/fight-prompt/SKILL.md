# Fight Prompt

好战斗 prompt 守住两件事：**视频模型能连贯兑现的物理因果**，以及**有快切张力、有特效奇观、有呼吸重量与记忆点的视听表现力**。

前一部分避开视频模型的真实短板，后一部分把剪辑密度、武器技能 VFX、运镜惯性与高潮美感落成可拍的画面。

## 1. 五条底层原则

视频模型自带丰富的动作、物理与镜头先验，顺着它写比卡死微细节效果好得多：

1. **接触留同镜，主动写碰撞**。关键打击的「接触 → 首个可见反馈」必须留在同一镜内拍实，让镜头看清落点受力，再切下一镜接余波或换角度放大；切点踩在起势交接或受击余波上，不切在半空吞掉撞击。打击与破坏以主动碰撞起句（谁的什么撞上哪儿、从落点炸开什么反馈与终态），让破坏从接触点长出来。
2. **长拍短切配节奏，只选结果不拆过程**。需要看清完整走位或蓄势余韵时用 2–4 秒稳镜长拍；高速对拼、蓄势叠切与重击放大果断用 0.5–1.5 秒快切短镜串联，靠长短镜交替拉出节奏。不替模型逐关节拆发力链，只写观众一眼看懂的动作、接触与结果。
3. **真打到人，命中落点要实**。实体兵刃拳脚直接碰人最易出重量感；武器附魔、斩击光弧与超凡技能特效同样大胆放开写，但每道特效必须有清晰几何轨迹与实体落点——看得见它撞上对方躯体、护盾或掩体并打出击退、踉跄、掀翻或崩裂，而不是糊成一团光雾跳过受击。只要不永久损毁参考图上的固定盔甲或配饰（模型后镜容易画回来），身体受力完全可以放开写。
4. **状态在像素里，图有则不重抄**。身份、造型、战损和站位交给参考图与尾帧。已绑图的实体只写视觉称呼与图中看不出的补充（如相对体量、新变化），把注意力留给动作与镜头；未给图时写足辨识特征，使 prompt 裸跑也成立。
5. **只写拍得到、听得到的画面**。每个主体用带视觉锚词的称呼贯穿全片，快切或近身混战时拉开双方明暗配色与轮廓反差防串身；特效写成可见的材质与几何物象；每帧常驻的设定放全局段，临时变化写在发生的那一镜或那一拍。

## 2. 先设计这场戏（草稿，不进 prompt）

动笔前用几句话想透，不照抄进正文：

- **戏眼、态度与翻转**：主角此刻是什么状态、靠哪一镜的眼神或姿态让观众读出态度；双方都构成真实威胁，10 秒以上完整段落安排至少一次受挫或险境再凭自身动作翻转，5 秒左右短段聚焦「蓄压对峙 → 快切爆发一击」的强反差，不硬塞多轮反转。
- **攻防语法与升级**：每一步由上一步的受力或环境改变自然逼出，逐拍推高空间或局势维度，按对抗形态取打法与重量兑现：
  - **悬殊体量**：小方借卸力、侧滑、蹬踏与绕背周旋，硬接必付滑退或裂地代价；巨物起手沉、落势猛，靠落空砸毁掩体与局部崩甲失衡兑现重量。
  - **同体量近身**：重在距离切入、兵刃粘架弹滑与重心破坏，每次交锋改写身位或攻守主导权，靠击退、滑行与撞碎掩体出重量。
  - **远程与重火力**：写清发射后坐、弹道跨空间推进与拦截／规避，靠护盾碎裂、掩体被打穿与地面灼痕出压迫。
  - **一打多**：主角沿清晰动线切入，每拍只与最近一两个目标实体碰撞，受击者倒飞撞翻后排，在阵型里犁出缺口。
- **结局落点**：按整片位置选定收口——后续要接戏取**悬停**（停在张力最高的接触或揭示）；完整段落取**收势**（胜负落定，留足落败反应与安静余韵）；大招清场取**白场**（爆心过曝洗白后落空景或碎物飘落）。
- **分段策略**（仅超单次时长时）：连续动作接力停在蓄力顶点或微停顿等清晰帧，用尾帧锁下段开场；尺度跳变、遮挡切镜或需要换受损新图时，直接用参考图开新镜，上段尾帧仅作环境与战损参考。

需求未给出的设定（画风、物理／特效档位、对手体量、胜负、结尾等）直接按最出彩的方案写定，交付时顺带列成代选。

## 3. 把节奏与表现力写进画面

写每一镜与每一拍时，用下面这些可拍的手法拉开层次，避免从头到尾等速平铺的互砍：

### 节奏四招

1. **疏密快切（蓄—急切—顿）**：战斗的爽感来自剪辑密度反差。用 1.5–2.5 秒稳镜做屏息蓄压或残心收势，把高速对拼、蓄势叠切与决胜冲刺切成一组 **0.5–1.5 秒的快切短镜串**，爆发后立刻切回稳镜放呼吸。快切守两条要点：相邻镜头**大幅拉开景别或角度**（手眼极特写 ↔ 低仰全景 ↔ 越肩近景 ↔ 受击正脸），避免同景别抽搐跳切；保持双方运动方向与配色反差一致，切点踩在动作交接或受力余波上，每记重击的接触与首个反馈完整留在同一短镜内。
2. **活静帧与拍内顿挫**：蓄压、对峙、相持与收势这类稳镜／无位移拍，写出此刻仍在动的活物与变化量（衣发被气流吸紧、刃口在咬合处颤抖推进、雨滴火星缓飘、镜头极慢压近），让停顿充满势能而不是画面冻住。长镜内的连击用自然语言排出轻重快慢（两记快刺逼退、半拍拧腰沉蓄后重劈破防），按兵器重量拉开速度曲线——重兵沉蓄慢起带惯性过冲，轻兵寸劲骤发急停。
3. **变速高光**：全片以全速为底，只在毫厘擦身、破局出刃或生死交错等一两处转折骤压入极慢动作：写主体逐寸推进与常速看不见的悬浮微物（劈开的水珠、自转火星碎屑、衣褶波纹、瞳孔倒影），并在明确的物理门控点（切过、崩甲、入鞘、踏地）骤回全速释放动能。
4. **声场反差与咬切**：声音与画面共同切分节奏。快切串配密集鼓点、金属高频交击或急促呼吸咬死每个切点；大招爆发或致命一击前骤然抽空配乐与杂音（只留呼吸、刃鸣、心跳或一滴水声），命中瞬间再由音爆与重鼓轰然落锤，或让画面先无声掠过、半拍后由崩解与巨响延迟兑现。

### 表现力五招

1. **武器与技能特效（VFX 观赏性）**：特效是拉高画面观赏性的核心抓手。写实题材用火星雨、枪口焰、硝烟、水雾与刃风碎屑造质感；超凡、玄幻、动漫与科幻题材放开做武器附魔与技能奇观。好特效守三条：
   - **有材质与锋利轮廓**：落到具体物理载体与清晰几何形态（流火缠背、霜晶沿刃爬行、炽金新月斩弧、水墨飞白、高压白汽裹电弧、凝实冰棱／能量晶簇），斩出的刀痕或光轨可短暂悬留空中再消散，不做糊成一团的模糊光雾；
   - **双色分账与实时打光**：双方特效拉开主色极性（如炽金对幽蓝）写入全局光色；接触点爆出的高亮信号色（如炽白火花或相变白汽）只写在命中那一镜，避免静帧提前炸光。特效即实时光源，照亮脸庞、眼神、甲面与潮湿地面，大招展开时压暗天光放大明暗对比；
   - **招由身发、引动环境**：特效由身体发力或武器机关触发，接触环境时触发相变（高热刃光入雨蒸起白汽、寒气沿地面与甲缝结霜蔓延、冲击波压凹水面再掀成水墙；大招可写「向内坍缩聚能 → 停顿半拍 → 逐层绽放爆裂」的多级演化）。
2. **摄影机物理惯性与视角翻转**：完整身法走位用一条贴身连续跟拍一气呵成，高速对拼与重击冲击用多角度快切叠出压迫感。无论长镜还是快切，摄影机都是场内受力的实体——蓄势缓压、出招贴身急跟或顺势急甩、命中瞬间急停或被气浪撞退、收势带阻尼缓滑停稳。机位与构图随权力同步翻转：主角受压时用压顶俯拍、逼入画角或对手越肩压迫；反击破局那一镜立刻反抢低位仰拍或主导越肩。
3. **负空间、纵深与剪影**：打破双人居中塞满画框的呆板构图。突刺、冲锋或击飞前，把发力方压向出发侧，朝运动方向留出大片**运动负空间**承接轨迹与刀光；对峙与高潮用悬殊画幅占比（漫天风雪、巨物阴影或空旷天地占去大半画面，主角缩在一隅）写出**戏剧负空间**。前景放虚化掠过的肩背、兵刃或碎屑制造高速视差；关键瞬间借反射面（刃身、瞳孔、水面）映出对手，或将轮廓压在爆点与强逆光前形成锋利剪影。
4. **重量外溢与次级运动**：受击不止是人飞出去，让冲击同步外溢到身体次级运动与环境介质——长发衣袍蓄力反向吸紧、受击瞬间猛烈甩开，重击震落雨雪、炸起碎石泥水或把掩体撞出裂痕缺口。
5. **高潮视觉升华与破界标点**：决胜拍不必只是炸出更大的坑，按题材选用一种审美质变留下只属于这场戏的记忆画面：
   - **空间抽离**：借强逆光压黑、爆心过曝洗白或浓雾飞雪暂时抹去杂景，只留纯净底色、双方剪影与一道核心刃迹，收势后再显露战场。
   - **杀伐相变**：碎屑、余烬或刀风转化为贴合母题的意象（飞雪、红叶、冰花、上浮光尘、逆光中悬停发光的万千雨滴）。
   - **极盛归寂**：铺天盖地的声光推至顶点时骤然收束为无声的一线素刃或合鞘，停顿半拍后切口错位或天幕裂痕延迟落下。
   - **破界标点**（风格化题材按需）：在改变战局的致命瞬间，切入一闪而过的极高反差冲击帧（黑白剪影、负片反色或粗粝原画线稿），或让决胜整拍升格为水墨／炭笔等异质画风，写明落定后褪回原画风。

## 4. 输出结构

输出纯文本，用不到的行整行删去。画幅、时长、分辨率由入口参数控制；不支持秒级时间戳的入口改用「起初、随后、最后」；不出声音的入口删去声音描写。短切镜直接一镜一拍，长镜可分多拍。

```text
素材绑定（有图时写）
「[图名]」对应[视觉称呼]，锁定[外观／画风]；动作、站位与构图由下文决定。
（续段按接法写明「承接图」锁开场画面，或仅参考环境与战损现状）

主体
（已绑图时只写称呼与图中看不出的补充；未绑图时写足辨识特征）
[视觉称呼]：[特征或补充]。

基准
媒介：[画面媒介与质感]。
空间：[场景、地面材质与远景]。
光色：[开场天光、主光与双方形成反差的主色]。
声音：[配乐与环境基调]。

时间轴
SHOT 01｜0–[a]s
CAMERA：[稳镜蓄压：景别、角度与留白] → [极慢压近或稳持]。
[蓄压或起势，含仍在动的微物与武器／环境张力]。声音：[环境声或骤然抽空]。

SHOT 02｜[a]–[b]s
CAMERA：[快切切入：与上镜拉开景别／角度] → [随发力急跟或急甩]。
[起势突进或第一记交锋：武器／技能特效轨迹、主动接触、直接受力反馈与终态]。声音：[高频金属撞击或鼓点咬切]。

SHOT 03｜[b]–[c]s
CAMERA：[快切反打：视角或权力翻转] → [命中急停或被气浪撞退]。
[重击碰撞、特效实时打光与环境相变、受击终态]。声音：[命中重锤或配乐转向]。

SHOT 04｜[c]–[N]s
CAMERA：[切回稳镜或慢移] → [终幅构图]。
[高潮升华或残心收势，落在一个安静但仍在进行的细节上]。
```

单框入口省略负面提示，不混入正向代码块；仅在入口有独立负向字段时，在主代码块外另附负向块。

## 5. 交付前轻核与冷读

写完只查三件事，发现问题直接改顺原句：

1. **因果与接触**：每次关键打击（含武器与技能特效）的接触与首个受力反馈都在同一镜内拍实，且写出了主动接触；快切踩在动作交接或余波上，没有切在半空、白场或大幅甩镜里吞掉撞击。
2. **清晰与不重述**：时间片衔接合理，全局段只放常驻事实，已绑图的外观没重复抄写，无歧义称呼和拍不到的抽象词。
3. **节奏与表现力**：有疏密快切与声静反差（稳镜蓄压／收势与短镜快切交替，相邻快切拉开了景别或角度差），无位移拍写了活的微动，运镜随发力变速且有视角翻转，武器／技能特效轮廓清晰且与环境实时互动，有真实身体受击与让人记住的高潮画面。

随后做一轮**冷读**（有子 agent 时派发一个，只给 prompt 与素材清单；没有则自己读）：按时间复述每镜每拍看到了什么，标出看不到接触的破坏、断链的因果、同景别跳切或有两种读法的句子，修顺后交付。

交付时正向 prompt 放进单独代码块可直接整块粘贴；有独立负向字段时另附负向块；缺图或有代选设定时在代码块外简附清单。分段时标明每段对应时间区间与上传素材。
