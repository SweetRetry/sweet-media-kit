# Fight Prompt

## 1. 对齐需求，定生成粒度与素材职责

动笔前先从需求与素材推出下表各项。推不出、且不同答案会写出不同 prompt 的项，按表中顺序取最靠前的至多 4 项一次问完，每问给 2–4 个选项，按需求的倾向标出推荐项。用户已说明或素材已决定的项不问，全部推得出时直接动笔。没问到或用户没回答的项按最贴合需求的选项写。

| 对齐项 | 选项 | 决定什么 | 何时问 |
| --- | --- | --- | --- |
| **物理档** | 写实物理档／超凡与科幻档 | 打击锁定还是 VFX LOCK，光从哪来，场景是否带天象与发光粒子 | 题材按第 3 节两档都说得通（武侠带不带剑气）；「写实画风」只定画风，不定物理档 |
| **目标入口** | 常用视频模型若干／不确定（按通用写法，不写秒级时间戳） | 单次时长上限，能否写秒级时间戳与参考图语法 | 没说用哪个模型 |
| **对手** | 同量级单挑／悬殊体量／一打多 | 第 2 节的攻防语法与体量比 | 需求没给对手，或只给了身份没给体量与人数 |
| **胜负** | 主角胜且致命／主角胜不致命／胜负未分 | 结尾类型（胜负未分取悬停）、落败反应与最后一帧 | 没给结果 |
| **画风与媒介** | 写实电影摄影／三维 CG／赛璐璐动画／水墨等 | STYLE LOCK 与冲击帧可用的反差画法 | 没有参考图，需求也没说画风 |
| **粒度** | 单镜／多镜／多段组接 | 模板骨架与切分点 | 没说时长，也推不出要拍一招还是一整段交手 |
| **伤害尺度** | 只见护具、衣物与环境破坏／写实血肉 | 受击剥离物清单与破坏终态 | 人对人且没说明 |
| **冲击帧** | 用在决定性一击／全片不切画法 | 是否整幅切换画法 | 需求或参考图偏写实克制 |

每条 prompt 按第 6 节模板写，只保留本次实际出场并生效的素材、招式词条与执行行：

- **多镜（10–30s，4–10 镜）**：一次生成包含起承转合的完整交手段落，配齐模板各块，防止中后段设定漂移与战损吞没。
- **单镜（2–6s）**：一次生成只拍一个戏剧动作（蓄力微距、单招挥斩与残心、独立命中终爆）。只写一条 `SHOT`，以「最后一帧」收尾，描述密度集中在本镜的微距物理、全身发力链或爆裂层次上。
- **多段组接**：战斗超出单次时长上限，或包含跨尺度特写（微距压镡 → 稳机位挥斩 → 巨型刀痕终爆）时，拆成多条独立 prompt，每条按自身镜头数写成多镜或单镜。
  - 切分点只取蓄力顶点定姿（举刀指天白光炸开）、收招定姿（合鞘瞬间）、遮挡擦镜（碎鳞、刀光、浓烟铺满前景）或微距切全景的尺度跳变点；在挥刀中途切分时按动作匹配剪辑锁死首尾帧。
  - 具名色分账、双方不变量与永久地标方位各段一致。续段在 `环境` 行首句列出前段留下的具体战损（`左肩缺三块甲、胸前缺两块甲、画左冰沟全程保留`），`SHOT 01` 开场直接带着这些战损、站位与光线起拍。

动笔前先列参考图清单，绑定按清单写，不停下来等图。多镜与组接的战斗列人物、对手、武器、场景的身份图与核心特效图，质感图只作补充；用户已给的图直接绑定，缺的图随 prompt 交付清单由用户准备。明确每份素材的控制边界，防止互相污染：

- **身份素材或文生主体**（角色、对手、武器）：有参考图时用目标入口语法绑定，图中已锁定的外观不在正文重述；无参考图时把各自 3–6 项全段不变的可见几何特征（发式、疤痕、服饰或装甲结构、兵器部件与持握方式、瞳色、胸口核心）内联进开篇主体句。身份图里会在战斗中被毁、卸下或改形的部件（饰物、头盔、护甲、兵器），绑定时写明它只代表某个时间点之前的外观；之后该部位进入特写、被击中或被触碰的时间片正面写一次新状态（`[部位]空无一物／已断／已卸下`），`HANDOFF` 与最后一帧照列；它的碎片与残骸离开原位、不排成原形，否则模型会在下一个特写里按身份图把它画回来。
- **场景素材**：锁死 2–3 个永久地标及其在场景里的相对位置，画面方位到各镜 `CAMERA` 里写，区分不可毁地标与可改写介质（地面、海面、云海、植被）。
- **质感或关键帧素材**：只借材质、形态或特定画面构图（冰封质感图、劈天刀痕关键帧），写明人物或对手外观仍以对应身份素材为准。出招人物在终爆构图中占比极小时，撤下人物与随身武器素材，只绑定关键帧、受击目标与场景，省去人物动作锁。
- **色调与强度**：参考图只锁造型、材质与渲染精度；用户明确要求的饱和度、色调或强度档位覆盖参考图自身的色调与布光，STYLE LOCK 按用户要求写，不沿用参考图的底色。

## 2. 建攻防力学与动作锚点

先在草稿里定**这场戏**，不写进 prompt：用两三句写下主角此刻是什么样的人、处在什么处境、观众该感受到什么、战局在哪一下翻转。招式、视效与镜头都服务于它。多镜完整段落的设计与核验先过**成片四问**；单镜或分段属于更长的整场时只承担其中某几拍，四问对整场核，本条只核它承担的那几问；单镜本身就是整场时四问照核：

1. **主角被看见**：关键拍让观众读得出主角此刻的态度，靠脸与眼神特写，或画内看得清的姿态与动作。
2. **真交手**：双方都构成威胁，局势由主角自己的动作决定。有来回的交手里主角至少一次险些被击中或落入下风再翻转；一击定胜负的戏把威胁放在出手前的对峙与对手的起势里。
3. **节奏有反差**：快与慢、密与疏、声与静交替，不匀速推进。
4. **有一个记得住的画面**：至少一个画面只属于这场戏（一直藏住的东西在翻转时露出、一击的后果延迟落下、环境被一招改写）。

再按双方的**体量比、兵刃射程与人数**确定攻防语法，然后设计具体动作：

| 对抗类型 | 攻防力学语法 | 受击与环境反馈 |
| --- | --- | --- |
| **悬殊体量（以小搏大／巨物战）** | 小体型方的防御词表限定为斜架卸力、贴地侧滑、借力蹬踏、绕背攀爬；被迫硬接必写泄力代价（双膝下沉龟裂、被推出一道长犁沟）。巨物起手沉、落势快，靠体量横扫与压迫 | 巨物局部崩甲、碎鳞、断角、后仰踉跄或单膝跪地；落空攻击写明砸毁的柱段、礁石或地面深坑，兑现重量 |
| **同体量近身博弈（冷兵／拳脚）** | 重在距离切入（丈→尺→寸）、兵刃走势（粘、架、弹反、刮刃滑脱）与重心破坏（破防失衡、扣腕别肘、横扫跌扑）；每次交锋改变双方身位或攻守主导权 | 刃口火花、护具裂痕、衣袍撕裂、脚步滑行犁痕、震退撞碎掩体 |
| **远程与重火力交锋（法术／枪炮／机甲）** | 锁死发射源与后坐力 → 弹道或束流跨空间推进 → 拦截（立盾、斩开、掩体吃弹）或机动规避；两股持续力量对撞时写出推回位移与中点压缩咬死 | 护盾蛛网碎裂、反应装甲掀飞、过热白汽、焦黑弹孔群、后坐力踏陷地面 |
| **一打多群战（突围／冲杀）** | 主角沿明确动线切入，每拍只与前景最近 1–2 个目标发生实打实的物理接触，其余敌群承担围拢、受惊硬直或被余波扫飞 | 前景受击者甲碎倒飞撞翻后排，阵型被犁出缺口 |

体量比按想看的戏选：要看来回拆招、看清双方表情时，对手取与主角同一量级；巨物战里主角在画面中很小，用贴脸特写与反应镜头补回主角的戏。

再写**动作因果链**，招式、升级与分镜都从这条链上取：

- 用一串 `X → 所以 Y` 写完整段交手。每一步的起因是上一步留下的东西：受力转成下一招的起势，被改写的环境成为下一步的条件（遮蔽、掩体、落脚点、障碍），一方的处境逼出另一方的新手段；角色设定里的特质在链上某一步成为破局的原因。双方每一步都在回应对方。
- 双方相对位置与关键物体的数量在链里写定，用画面里看得出的关系表达（`一钺远`、`贴身`、`退到崖边`、`三钺`），不写米数；每一步都走得通（够得着、来得及、数得清）。
- 链上被下一步依赖的那一环由画面里大而清楚的动作或形变承担（扑空撞墙、被打退撞门、兵刃脱手），并独占一个时间片；细微的环境反应（灯晃、门回弹、涟漪）照写、照样丰富画面，只是不让后续动作依赖它。

为关键动作建立清晰的**姿态锚点**与**触发映射**：

- **起势 → 爆发 → 残心**：开场、蓄压拍与终局的招式钉死**起手定姿**（沉腰握刀、拇指压镡、双手举刀过顶、拉弓满弦）与**收势残心**（刀停身侧半秒、单膝插刀滑停、背身立定衣发顺刀势甩出），用两端定姿夹住中间的高速爆发。链中段的招式以上一步的反作用为起势，收势直接流进下一步。
- **身体动作唯一触发**：超凡招式或重火力在执行锁中建立 `身体动作 → 【招名】` 的触发表；每股能量都由身体发力起手或机关动作引出。
- **形态切换**：战斗中发生变身或装甲着装时，锁死**同一位置、同一姿势**，通过能量光柱、发光线稿闪切或装甲部件逐块扣合完成切换。

## 3. 实体化打击与视效

先定本段的**物理档位**：

- **写实物理档**（武侠、历史冷兵、拳脚、现代战术）：光只来自场景光源与刃面、水面、汗珠的反射，力量靠形变、颗粒物与环境受迫反应外化。字典写成「打击锁定」，只列核心重击与兵刃交互，每次重击写明接触点、形变与剥离物。
- **超凡与科幻档**（法术、剑气、机甲重武、异能）：字典写成 VFX LOCK，本段每个核心视效或特殊重击建立独立【招名】词条，攻守双方均列。场景与招式同档：天象、浮空或巨型结构与发光粒子写进场景锁，让环境本身成为光源与尺度标尺，不只锁地标。

每条词条按四步写齐：

1. **物理载体**：指定可见物质或光学现象作载体（墨滴与飞白残迹、空气透镜折射与压碎的石块、绷紧反光的金属细丝、电弧与高压白汽），替换「凌厉剑气」「强大魔法」这类抽象词。
2. **几何与数量**：写明形状、厚度与形制；外形易混的物件（矛与剑、枪与炮）用部件级描述锁定（头部形状、杆或柄、护手有无、长度比例）。唯一光核、裂口、巨浪写死 `1 颗／1 道`；离散连击、冰棱、花瓣写死 `七道／十二簇／三层`；尺寸用人体或画幅比例锚定（`宽过半个画面`、`高过人物五倍`、`一指厚`）。
3. **内外复合层**：`[主色 + 核心实体材质]`，内含 `[内部纹理／流束／碎晶]`，缠绕 `[外层伴生物：碎石／电弧／霜花／焦烟／浪沫]`，`[前缘／尖端／命中处]` 爆 `[全场唯一信号色]`。
4. **结构化蔓延与相变**：作用到躯体或环境时写明推进路径（沿甲缝五路爬开、沿裂纹冻结成壳再崩落、从膝甲螺旋爬上胸口、切口先滑开再崩散、海面先压凹成漩涡坑再拔起成巨墙）。两类介质接触时写出相变（冰火相撞炸出白汽与融水、高热刃入海蒸成细雾、气浪掠过水面压出凹槽、重击落石地先龟裂下陷再掀飞石块）。

**受击剥离物**按受击方材质锁死清单（碎甲、碎鳞、断角、碎岩、冰片、熔滴、电火花），清单就是画面里出现的全部碎物；写实血肉题材把血雾或破布列进清单。

**破坏写到终态**：重击后受击方仍存活时，在同一时间片写明身体完整留在原地、破坏只到哪一层（`甲背裂开一道缝、崩落几片甲片`）。只写喷涌、炸开、崩飞而不写剩下什么，模型会把整个人炸碎抹掉，下一镜再按 `HANDOFF` 画回来。

## 4. 排节奏与升级曲线

- **命中帧同步**：以下通道在接触点同时突变，视效的落点就是接触点：
  - **镜头**：沿攻击方向小幅重震并在 `0.2s` 内衰减，或急推、被冲击波推开。
  - **速度**：接触瞬间顿帧 `0.05–0.15s`，轻击短、重击长，身体与兵刃一顿而火花碎屑继续飞，再长会像卡顿；升格只放在出刃或接触瞬间，崩碎或滑脱时骤回全速。
  - **光**：超凡档接触点的招式光照亮双方，亮度只铺到接触点周围；写实档靠飞溅的汗水、水花、火星反光与灯具晃动。火花与高光顺受力方向散开。
  - **声、环境与身体**：重击或骤停；冲击环、碎石、气浪；震开、后滑、形变，击退距离与攻击轻重成正比，并打断受击方的下一个动作。
  - **毛发与布料（CFX）**：长发、衣袍、残布与挂件在蓄力时被反向吸紧，接触帧沿冲击方向猛烈甩开并撕下碎片；蓄压拍里它们与环境微物一起保持飘动。
- **冲击帧**：冲击帧是决定性受力的视觉标点，只放在改变战局的那一下（实质破防、终结技落到身上），全片通常 1 处、最多 2 处，按戏的分量放，不按间隔排。画面内容就是这一下的受力构图：被击中者的剪影、贯穿他的力线、指向接触点的集中线，整幅切成与 STYLE LOCK 反差最大的一种画法（黑白高反差、负片反色、红黑双色、粗铅笔原画线稿），一闪约 `0.1s`，在同一时间片内写明恢复原画风，形变与战损在恢复后继续存在。前面用顿帧与寂静蓄住，后面用物理余波释放。闪避、落空、砸地与普通接触在 prompt 里只正面写形变、碎屑、镜头震动与顿帧。大招展开整拍切画风（切水墨、切线稿）是另一种手段，写明触发动作、起止秒数与恢复点。
- **单向升级曲线**：多镜段落按每镜 `2–4s`（终爆可至 `5–6s`）排布，每拍兑现一次可见升级：**新机制首现、空间或尺度跃升、攻守易势或实质破防**，且这次升级由上一拍的结果逼出。拍名连起来即为动作链，烈度不回落。总时长由动作链长度与交手密度推出，在模型上限内按需取值。
- **变速与蓄压拍控制**：
  - **交手密度**：交锋以连击串为单位，串内接触间隔 `0.3–0.6s`，写成 `每 0.4s 一击，连续 N 击` 并逐击列出动作；一个时间片可以装下一整串，一串就是第 5 节的一组突发连切。慢只来自升格与蓄压拍：全段升格不超过 3 处、每处不超过 `0.3s`，蓄压拍留给开场、每串连击之前与之后、终爆前与收势，其余时间全速。任何超过 `0.6s` 的时间片都写一个正在进行的身体动作或镜头运动，只写氛围与情绪的时间片会被渲染成定格。
  - **极动前蓄压**：终结技释放或大对撞爆发前，留出 `0.3–0.8s` 的蓄压拍并写明起止秒数：速度压到最慢但不停，接触点持续角力（刀刃在咬合处颤抖着一寸寸推进、火花与白汽不断喷出、发梢被气流拉直、镜面刀身最后一寸滑入鞘口），镜头极慢推近；不写「静止」「定格」「死寂」这类让整幅冻结的词。
  - **痕迹悬留**：需要刀痕、残影或冰封瞬间留在画面里时，写成 `[刀痕／冰封物]悬在原处不散`，同一句写环境微物（雪片、浪沫、碎鳞、寒气、发梢）持续飘动或被牵引、镜头慢移。
- **多级终爆与余韵收势**：
  - 高潮打击拆成 **2–3 级几何演化**：先向内坍缩压成极亮一点（或海面／云海下凹成漩涡坑吸住目标），停顿半拍后反向膨胀、掀立成巨墙或逐层绽开炸裂，保留双方色彩分界与飞散的实体残骸，冲击环推平尘土或云海，炸开后余光悬留、碎块如雨坠落。
  - 先定结尾类型。**悬停**：停在全段张力最高的接触或揭示上（两股力咬死、对手新形态首现、角色隐藏的能力或状态首次显露），让下一段有处可接；段落属于更长战斗时优先悬停。**收势**：胜负落定，给落败反应与余韵留足时长，最后 `1.5–2s` 落在一个安静但仍在进行的动作上（缓步垂刀、闭目呼出白气、抬手擦去血迹）。**白场收束**：高潮的光逐级过曝，整幅洗成白，白场里只剩碎物下落，最后落在纯白或清场后的空景；用于终结技吞没全场，或下一段从白场起拍。悬停与收势都把全段累积的战损与地标保留在画内。

## 5. 锁色彩、场面调度、焦点与运镜交接

- **色彩分账与动态光影**：
  - **具名色互斥**：写成 `X 色管 Y`。对抗双方各管一组颜色；单一角色跨阶段升级变色（按招式阶段分用紫、淡青、深海蓝）时，各阶段主色明确切换，始终落在本方色组内。非接触区各保本色，接触界面才产生全场唯一的**命中信号色**（通常为炽白）与相变物（白汽、折射、分色交界）。环境固有色独立具名。对方色只以边缘反射进入己方身体（侧面反光、勾边），接触界面由命中信号色吞掉两色，不混出第三色。高速下人物糊成光带时，用光带的粗细、边缘形态与芯色区分两方。
  - **能量即光源与反射**：发光招式、熔核与爆心作为实时光源照亮面部、甲片与地面，或在大招出现时压暗天光；**反射面**（镜面刀身、竖瞳、冰瓣、水面）在特写中映出对手或巨型奇观；关键命中瞬间把双方轮廓压在爆点或背景亮源前形成清晰剪影。
- **三维场面调度与因果门控**：
  - **三层纵深**：前景放虚化的对手肩背、兵刃、飞掠碎甲或环境障碍框景并制造高速视差；中景放攻防交锋主体；背景锚定 2–3 个永久地标与天象尺度。用纵深走位（从远景贴地冲入近景挥斩，或被重击从近景砸向远景）在单镜内完成景别跃迁；用站位高低差、画幅占比反转与逼入死角外化攻守易势。天象级痕迹（劈开天空的刀痕、横贯天幕的光带）写明所在纵深与出现时刻，人物与地面在它前面；只写「横贯画面」会被渲染成贴在镜头上、穿过人物的光束。
  - **画面坐标与轴线**：每个运动物写明朝向、起点与去向（`[物体][朝向]，从[画面方位]向[画面方位][运动方式]`）；要对撞的两股力放在同一条轴上。主角朝目标前进的方向全片保持一致：侧面镜头里朝画面同一侧（如画右），对抗轴上的机位（身后跟拍、正面迎拍、贴地仰拍）里沿纵深冲出或迎向镜头；环绕保持在对抗轴同侧。墙、门、巨物这类大型布景写明它在本镜画面里的朝向（正对镜头的背景墙，或画面某一侧、朝向哪边的侧墙）。每一镜都按本镜的摄像机写出画面里能看到什么，不靠其他镜头或全局方位约定推断：画左画右只指本镜画面，切镜后不延续；后续动作依赖的相对关系（谁面对谁、谁在谁身前身后、接触面朝向）写成本镜的可见结果，即谁的哪一面朝镜头、谁被遮挡且露出什么，写进时间片与 `CAMERA`；`HANDOFF` 只负责交接，不能替代；没写到的关系模型按最常见构图补全。
  - **看点进画与剪影分离**：机位架在能直接拍清兵刃咬合面、受击形变部位与核心表情的一侧；主动作轮廓落在干净受光面、天空或亮源前。
  - **痕迹累积与门控**：战损痕迹（裂坑、犁沟、焦痕、霜迹、缺甲）随镜头**单向累积、只增不减**。按 `成形 → 逼近 → 接触 → 受力 → 破坏 → 留痕` 推进，倒地、碎裂与留痕都发生在接触帧之后；跨拍联动写死**门控事件**（`霜环触到钩爪后魔兽才睁眼`、`刀镡咔地合上鞘口那一刻冰莲才绽放`）。
- **焦点层级与移焦引导**：
  - **单拍唯一焦点**：每拍只留一个视觉焦点，按 `蓄力锁局部微距（手／眼／机关）→ 出招锁全身发力弧线 → 命中锁接触点形变与受击反应 → 余波锁环境崩解尺度` 移交。非焦点区域通过浅景深虚化、压暗或放慢动作主动让位。
  - **镜内移焦**：用移焦引导视线跳跃（前景刃口实焦映出敌影 → 挥斩瞬间移焦至中景对手崩甲）。
- **分镜时序与同拍双动**：
  - 镜内按 `0.5–2.0s` 切片推进。**同一时间片内攻守双方都有动作或受迫反馈**（即便被冻结或压制，也有红眼骤缩、熔核跳动、钩爪抽动）。攻击落在对手的附属物上（法器、坐骑、护盾、召唤物、手中兵器）时，持有者同拍先试图阻止（格挡、回拽、闪避），被击中时身体随之受力（偏头、后仰、踉跄）。
  - 【招名】的外观、触发动作与发出部位只在 VFX LOCK 或打击锁定里写一次，分镜里只写招名与本拍的形态变化。每个人物、物体与招式全片只用一个名字，不换同义词。
- **运镜动力学与镜间 HANDOFF**：
  - **摄影机物理惯性**：把摄影机当作场内受力的物理实体，运镜速度曲线与发力节奏耦合：蓄势时缓慢压近或下沉屏息，出招时随动势急甩或贴身加速跟拍，命中帧受冲击剧震、急停或被气浪撞退，残心收住时带阻尼缓滑停稳。焦段、景深与机位按下表的戏剧任务选。
  - **旋向解耦**：画面同时存在旋转特效与环绕运镜时，分别写死俯视旋向（风暴逆时针、镜头顺时针）并锁死人物朝向。
  - **剪辑节奏**：按 `定拍 → 突发连切 → 定拍` 组织，不匀速切。连切放在接触高潮，写在同一个 `SHOT` 的一个时间片里，不拆成独立 `SHOT`：`3–6` 切、每切 `0.25–0.5s`，对应一串连击，逐切写机位与这一击（`每 0.4s 一切，连续 4 切：①…；②…`），本镜 `CAMERA` 写连切的机位顺序；前后各留 `0.5–1.5s` 的第 4 节蓄压拍（蓄力、双方角力、环境呼吸；终结技或大对撞前按「极动前蓄压」取 `0.3–0.8s`），主体保持微动、镜头保持慢移，不做慢动作。连切内机位始终在运动，慢推慢摇只留给开场与收势。切在动作中途（挥到一半、飞到一半、跃到空中），下一镜从同一动作的下一瞬接上，切换前后画左画右关系、视线与运动方向不变。
  - **HANDOFF 与最后一帧**：多镜段落每镜结尾写明双方终态位置与姿态（站／跪／倒）、关键物体的存在与数量（消失的写 `不再存在`）、持续中的姿态与持物（`仍双手举钺过顶`，不用「维持原样」「同上」指代）、仍在运动的事物、累积战损与切镜／焦点引子（掠过前景的碎屑／刀光或下一拍起手）；末镜用「最后一帧」取代 `HANDOFF`，列全最终定姿、全部留存痕迹与原位地标。

## 7. 交付核验

逐项核验：

- **成片四问**：多镜完整段落按第 2 节的四问看完整条时间线，属于更长整场的单镜与分段只核它承担的那几问；不过关先改戏，再做下面的合规核验。
- **粒度与结构匹配**：单镜只有一条 `SHOT` 并以最后一帧收尾；多镜的锁与分镜齐全；跨段组接已对齐每段上传素材与继承战损。
- **实体与触发闭合**：超凡与重火力档每条【招名】写齐触发动作与发出部位、载体、几何与数量、复合层与蔓延路径，分镜只用招名引用；写实档的每处光都有场景光源或反射来源，每次重击写明接触点、形变与剥离物。
- **空间、调度与焦点守恒**：每条 `CAMERA` 写明前中后景调度、唯一视觉焦点（或移焦路径）与运镜速度变化，核心接触点在画内拍得清，永久地标（或微距光斑）保留在画内；战损只增不减并在最后一帧列全。
- **命中与同拍**：每个时间片双方都有动作或受力；每个命中片具备命中帧同步；冲击帧只落在改变战局的那一下，全片不超过 2 处，每处写明受力构图、画法、时长与恢复点；闪避、落空与普通接触没有闪白与闪切；全片没有米数与帧数。
- **精简不降看点**：压缩篇幅时只删空间记账、解释性从句与重复描述；【招名】词条的四步、命中帧同步、冲击帧与高潮前的蓄压拍不随篇幅压缩，精简后与精简前逐条对照仍然齐全。

自检后做一轮**冷读**：让没有本次设计上下文的读者只凭 prompt 走一遍时间线，暴露作者脑中默认、纸面缺失的信息。有子 agent 能力时派发一个，只给它 prompt 全文与素材职责，不给设计理由，要求它按时间顺序逐句列出问题，每条附原句：

1. **因果**：每个动作、招式与状态变化的起因都在更早的时间片里；门控事件不抢跑；相对位置、数量与时间走得通（够得着、来得及、数得清），物体在给定站位里摆得下。
2. **画面顺序**：时间片连续且相加等于总时长；`CAMERA` 的切镜时段与动作时段对齐；每条 `HANDOFF` 与下一镜开头的人物、持物、位置、朝向和数量一致；全局锁里写 `全片` 的状态与时间线上的事件不冲突，会变化的状态写成带时间范围的 `0–Ns`；每个镜头写到的画内元素在该焦段与机位下拍得到；已在场的人物与关键物在每个镜头里都写明画内位置，拉成全景或远景时也一样，没写到的会被删出画面。
3. **歧义**：每一处有两种以上读法的句子，写出各种读法。重点查左右指画面方位还是角色身体侧、朝向、姿态、物体存在与数量、同一对象换名。

没有子 agent 能力时，自己按这份清单冷读。每个问题改写原句关闭：删去冲突或改写歧义，补缺的起因只补一个可见动作或状态，不为闭合追加米数、帧数与解释性从句；改动后派新的子 agent 重跑冷读。完成标准：冷读输出中没有未处理的问题；同一问题修两轮仍未关闭时停止修补，在 prompt 后写明卡点。

只输出可直接粘贴的 prompt，和需要用户准备的参考图清单（每张写明图名、画面内容、要看清的部件与用途，各图同一画风）；对齐时未经用户确认、由你选定的项，在 prompt 后逐条列出；冷读改动了用户给定的尺寸、数量、造型或时间点时，在 prompt 后逐条列出。拆分为多段时按成片顺序逐份输出，在每份 prompt 之外标明它对应的成片时间段与上传素材。
