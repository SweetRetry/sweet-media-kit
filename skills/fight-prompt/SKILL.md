# Fight Prompt

## 1. 模型怎样读 prompt

后面所有写法规则都从这六条推出；规则没覆盖的情况按这六条判断。

1. **全局即每帧**：模型生成每一帧时都读整段 prompt，时间词约束很弱。主体句、STYLE LOCK、场景锁定与执行锁定只写每一帧都成立的常驻事实；初始站位、招式、阶段变色、命中信号色、碰撞相变物、受击剥离物、高潮相变物、战损痕迹、冲击帧、媒介升格、旋向与天象天光变化只写进发生它的时间片，写在全局段的会从第一帧就出现。写进时间片只是减弱：整件兵器变色、形态切换这类大面积的状态变化仍可能提前到全段，必须到某一刻才出现的状态放进下一段。
2. **缺省按最常见画面补**：每个镜头只按本镜文字成像，不继承其他镜头或全局方位约定，没写到的按最常见构图补全。没写颜色的物件被附近的词染色；动作模式相同的两招（都从上方砸落、都直线突刺）只写招名时，后一招会画成前一招的样子；只写喷涌、炸开、崩飞而不写剩下什么，会把整个人抹掉、下一镜再画回来；已在场却没写画内位置的人物与关键物会被删出画面。
3. **写下的词都会入画**：抽象词（「凌厉剑气」「强大魔法」）换成可见物质与可见动作；要表达某处没有某物时，写出那里实际是什么，不写它的名字；不写「静止」「定格」「死寂」这类让整幅冻结的词；每个人物、物体与招式全片只用一个名字，不换同义词；描述写法的规则句（防御词表、每招定姿、因果顺序）落实在分镜里，不抄进 prompt。
4. **每个机位都是一次切镜，每次切镜重画一次**：prompt 里写下的每个焦段与机位都成为成片里的一个切点。模型在切点后按身份图重新画人、重新摆位，上一镜的站位、持物、战损与朝向不自动延续。连贯只存在于镜头内部，要连着看的一串动作写在一个机位里。
5. **时间片会被填满**：模型把时间片的秒数用完才进入下一片，分给动作的秒数多于动作本身时，多出的部分是原地不动或悬空不动。
6. **细节有预算**：一个时间片里写下的事越多，每件事兑现得越差，先丢的是受力方的反应。动作本身（谁用什么打向哪里、对方怎样应、留下什么）是底；载体分层、光、声、衣发与微物是加在底上的修饰，按这一下在戏里的分量分配，不平均铺到每一击。

prompt 只写要模型画出新画面的东西：动作、接触、形变、光与材质、机位。连切的节奏、命中处的镜头震动、顿帧、提速、调色与颗粒都加在成片的现成帧上，写进 prompt 只占预算、把素材切碎，一律不写。升格慢镜与冲击帧要模型画出常速里没有的帧，照写。

## 2. 对齐需求，定生成粒度与素材职责

动笔前先从需求与素材推出下表各项。推不出、且不同答案会写出不同 prompt 的项，按表中顺序取最靠前的至多 4 项一次问完，每问给 2–4 个选项，按需求的倾向标出推荐项。用户已说明或素材已决定的项不问，全部推得出时直接动笔。没问到或用户没回答的项按最贴合需求的选项写。

| 对齐项 | 选项 | 决定什么 | 何时问 |
| --- | --- | --- | --- |
| **物理档** | 写实物理档／超凡与科幻档 | 出招句写特效载体还是写形变与剥离物，光从哪来，场景是否带天象与发光粒子 | 题材按第 4 节两档都说得通（武侠带不带剑气）；「写实画风」只定画风，不定物理档 |
| **目标入口** | 常用视频模型若干／待定（默认按单段 10–15s、秒级时间片与 `@主体` 绑定写） | 单次时长上限与参考图引用语法 | 没说用哪个模型 |
| **对手** | 同量级单挑／悬殊体量／一打多 | 第 3 节的攻防语法与体量比 | 需求没给对手，或只给了身份没给体量与人数 |
| **胜负** | 主角胜且致命／主角胜不致命／胜负未分 | 结尾类型（胜负未分取悬停）、落败反应与最后一帧 | 没给结果 |
| **画风与媒介** | 写实电影摄影／三维 CG／赛璐璐动画／水墨等 | STYLE LOCK 与冲击帧可用的反差画法 | 没有参考图，需求也没说画风 |
| **粒度** | 单镜／多镜／多段组接 | 模板骨架与切分点 | 没说时长，也推不出要拍一招还是一整段交手 |
| **伤害尺度** | 只见护具、衣物与环境破坏／写实血肉 | 受击剥离物清单与破坏终态 | 人对人且没说明 |
| **高潮与画法升格** | 冲击帧或高潮整拍切画法／不切画法（靠留白、光影与意象升华） | 决胜处用异质画法破界，还是在原画风内做视觉升华 | 需求或参考图偏写实克制，或没定高潮表现方式 |

每条 prompt 按第 7 节模板写，只保留本次实际出场并生效的素材、招式与执行行：

- **多镜（10–30s，4–10 镜）**：一次生成包含起承转合的完整交手段落，配齐模板各块，防止中后段设定漂移与战损吞没。
- **单镜（2–6s）**：一次生成只拍一个戏剧动作（蓄力微距、单招挥斩与残心、独立命中终爆）。只写一条 `SHOT`，以「最后一帧」收尾，描述密度集中在本镜的微距物理、全身发力链或爆裂层次上。
- **多段组接**：战斗超出单次时长上限，或包含跨尺度特写（微距压镡 → 稳机位挥斩 → 巨型刀痕终爆）时，拆成多条独立 prompt，每条按自身镜头数写成多镜或单镜。
  - 切分点只取蓄力顶点定姿（举刀指天白光炸开）、收招定姿（合鞘瞬间）、遮挡擦镜（碎鳞、刀光、浓烟铺满前景）、微距切全景的尺度跳变点，或身份图上的部件受损的那一下；在挥刀中途切分时按动作匹配剪辑锁死首尾帧。
  - 具名色分账、双方不变量与永久地标方位各段一致。续段在 `环境` 行首句列出前段留下的具体战损（`胸甲多一道横裂、画左冰沟全程保留`），身份图部件的损毁由后段改绑的受损图承担，`SHOT 01` 开场直接带着这些战损、站位与光线起拍。

动笔前先列参考图清单，不停下来等图。多镜与组接的战斗列人物、对手、武器、场景的身份图与核心特效图，质感图只作补充；用户已给的图直接用目标入口语法绑定，未给的图随 prompt 交付准备清单。明确每份素材的控制边界，防止互相污染：

- **身份素材或文生主体**（角色、对手、武器）：已提供参考图时用 `@图名` 绑定，图中已锁定的静态外观不在正文重述；未提供参考图时把各自 3–6 项全段不变的可见几何特征（发式、疤痕、服饰或装甲结构、兵器部件与持握方式、瞳色、胸口核心）内联进开篇主体句，保证 prompt 可直接运行（也可同时写 `@图名` 与内联特征，方便用户补图后直接用）。模型每换一个镜头都按身份图或内联的主体锁定句重画人物：身份图上的部件（饰物、头盔、护甲、兵器）在片中被毁、卸下或改形后，后面的镜头会把它画回来，在绑定句里注明有效时段也挡不住。战局的转折与结局因此落在身份图里没有的东西上（环境破坏、剥离物、新添的裂痕与缺口、姿态与站位）；剧情必须毁掉这类部件时，在它受损的那一下切段，后段改绑受损后的身份图。镜头会拍到人物的背面或侧面时，身份图含那个视角，缺的视角按最常见的样子补全。
- **场景素材**：锁死 2–3 个永久地标及其在场景里的相对位置，画面方位到各镜时间片里写，区分不可毁地标与可改写介质（地面、海面、云海、植被）。
- **质感或关键帧素材**：只借材质、形态或特定画面构图（冰封质感图、劈天刀痕关键帧），写明人物或对手外观仍以对应身份素材为准。质感图只含孤立的特效或材质、底为纯色；图里带环境时，特效铺满画面的那个时间片会把场景换成图里的环境，这样的图不绑定，在准备清单里换成纯色底的。出招人物在终爆构图中占比极小时，撤下人物与随身武器素材，只绑定关键帧、受击目标与场景，省去人物动作锁。
- **色调与强度**：参考图只锁造型、材质与渲染精度；用户明确要求的饱和度、色调或强度档位覆盖参考图自身的色调与布光，STYLE LOCK 按用户要求写，不沿用参考图的底色。

## 3. 设计这场戏与攻防力学

先在草稿里定**这场戏**，不写进 prompt：用两三句写下主角此刻是什么样的人、处在什么处境、观众该感受到什么、战局在哪一下翻转。招式、视效与镜头都服务于它。多镜完整段落的设计与核验先过**成片四问**；单镜或分段属于更长的整场时只承担其中某几拍，四问对整场核，本条只核它承担的那几问；单镜本身就是整场时四问照核：

1. **主角被看见**：关键拍让观众读得出主角此刻的态度，靠脸与眼神特写，或画内看得清的姿态与动作。
2. **真交手**：双方都构成威胁，局势由主角自己的动作决定。有来回的交手里主角至少一次险些被击中或落入下风再翻转；一击定胜负的戏把威胁放在出手前的对峙与对手的起势里。
3. **节奏有反差**：快与慢、密与疏、声与静交替，不匀速推进。
4. **高潮有视觉升华**：决胜拍跳出单纯的物理加码（炸更大坑、飞更多碎甲），完成一次审美质变并留下只属于这场戏的记忆画面（抽离杂景只留剪影与一线的留白构图、杀伐化作飞雪／落叶／光尘的唯美相变、狂暴声光骤归无声一击的延迟兑现，或环境与天象被一招彻底改写）。

再按双方的**体量比、兵刃射程与人数**确定攻防语法：

| 对抗类型 | 攻防力学语法 | 受击与环境反馈 |
| --- | --- | --- |
| **悬殊体量（以小搏大／巨物战）** | 小体型方的防御词表限定为斜架卸力、贴地侧滑、借力蹬踏、绕背攀爬；被迫硬接必写泄力代价（双膝下沉龟裂、被推出一道长犁沟）。巨物起手沉、落势快，靠体量横扫与压迫 | 巨物局部崩甲、碎鳞、断角、后仰踉跄或单膝跪地；落空攻击写明砸毁的柱段、礁石或地面深坑，兑现重量 |
| **同体量近身博弈（冷兵／拳脚）** | 重在距离切入（丈→尺→寸）、兵刃走势（粘、架、弹反、刮刃滑脱）与重心破坏（破防失衡、扣腕别肘、横扫跌扑）；每次交锋改变双方身位或攻守主导权 | 刃口火花、护具裂痕、衣袍撕裂、脚步滑行犁痕、震退撞碎掩体 |
| **远程与重火力交锋（法术／枪炮／机甲）** | 锁死发射源与后坐力 → 弹道或束流跨空间推进 → 拦截（立盾、斩开、掩体吃弹）或机动规避；两股持续力量对撞时写出推回位移与中点压缩咬死 | 护盾蛛网碎裂、反应装甲掀飞、过热白汽、焦黑弹孔群、后坐力踏陷地面 |
| **一打多群战（突围／冲杀）** | 主角沿明确动线切入，每拍只与前景最近 1–2 个目标发生实打实的物理接触，其余敌群承担围拢、受惊硬直或被余波扫飞 | 前景受击者甲碎倒飞撞翻后排，阵型被犁出缺口 |

体量比按想看的戏选：要看来回拆招、看清双方表情时，对手取与主角同一量级；巨物战里主角在画面中很小，用贴脸特写与反应镜头补回主角的戏。

再写**动作因果链**，招式、升级与分镜都从这条链上取：

- 用一串 `X → 所以 Y` 写完整段交手。每一步的起因是上一步留下的东西：受力转成下一招的起势，被改写的环境成为下一步的条件（遮蔽、掩体、落脚点、障碍），一方的处境逼出另一方的新手段；角色设定里的特质在链上某一步成为破局的原因。双方每一步都在回应对方。
- 双方相对位置与关键物体的数量在链里写定，用画面里看得出的关系表达（`一钺远`、`贴身`、`退到崖边`、`三钺`），不写米数；每一步都走得通（够得着、来得及、数得清）。
- 链上被下一步依赖的那一环由画面里大而清楚的动作或形变承担（扑空撞墙、被打退撞门、兵刃脱手），并独占一个时间片；细微的环境反应（灯晃、门回弹、涟漪）照写、照样丰富画面，只是不让后续动作依赖它。
- 每次命中按 `成形 → 逼近 → 接触 → 受力 → 破坏 → 留痕` 推进，倒地、碎裂与留痕都发生在接触帧之后；跨拍联动写死**门控事件**（`霜环触到钩爪后魔兽才睁眼`、`刀镡咔地合上鞘口那一刻冰莲才绽放`）。

为关键动作建立**姿态锚点**与**触发映射**：

- **起势 → 爆发 → 残心**：开场、蓄压拍与终局的招式钉死**起手定姿**（沉腰握刀、拇指压镡、双手举刀过顶、拉弓满弦）与**收势残心**（刀停身侧半秒、单膝插刀滑停、背身立定衣发顺刀势甩出），用两端定姿夹住中间的高速爆发；发力曲线按兵器重量区分，重兵与巨力写出反向拖拽蓄势、加速下砸与挥空后的惯性过冲，轻兵与寸劲写出无预兆骤发与点到急停，防匀速挥舞。链中段的招式以上一步的反作用为起势，收势直接流进下一步。
- **身体动作唯一触发**：超凡招式或重火力的出招句以触发它的身体动作开头（`身体动作 → 【招名】`）；每股能量都由身体发力起手或机关动作引出。
- **形态切换**：战斗中发生变身或装甲着装时，锁死**同一位置、同一姿势**，通过能量光柱、发光线稿闪切或装甲部件逐块扣合完成切换。

## 4. 打击、视效与光色

先定本段的**物理档位**：

- **写实物理档**（武侠、历史冷兵、拳脚、现代战术）：光只来自场景光源与刃面、水面、汗珠的反射，力量靠形变、颗粒物与环境受迫反应外化。每次重击在发生它的时间片里写明接触点、形变与剥离物。
- **超凡与科幻档**（法术、剑气、机甲重武、异能）：本段每个核心视效或特殊重击起一个【招名】，攻守双方都有。【招名】只作标签，外观写在出招的时间片里。场景与招式同档：天象、浮空或巨型结构与发光粒子写进场景锁，让环境本身成为光源与尺度标尺，不只锁地标。

招式与特效物第一次出现按下面四步写齐，之后每次出现至少用一个短语写明主色、载体与形态：

1. **物理载体**：指定可见物质或光学现象作载体（墨滴与飞白残迹、空气透镜折射与压碎的石块、绷紧反光的金属细丝、电弧与高压白汽）。
2. **几何与数量**：写明形状、厚度与形制；外形易混的物件（矛与剑、枪与炮）用部件级描述锁定（头部形状、杆或柄、护手有无、长度比例）。唯一光核、裂口、巨浪写死 `1 颗／1 道`；离散连击、冰棱、花瓣写死 `七道／十二簇／三层`；尺寸用人体或画幅比例锚定（`宽过半个画面`、`高过人物五倍`、`一指厚`）。
3. **内外复合层**：`[主色 + 核心实体材质]`，内含 `[内部纹理／流束／碎晶]`，缠绕 `[外层伴生物：碎石／电弧／霜花／焦烟／浪沫]`，`[前缘／尖端／命中处]` 爆 `[全场唯一信号色]`。
4. **结构化蔓延与相变**：作用到躯体或环境时写明推进路径（沿甲缝五路爬开、沿裂纹冻结成壳再崩落、从膝甲螺旋爬上胸口、切口先滑开再崩散、海面先压凹成漩涡坑再拔起成巨墙）。两类介质接触时写出相变（冰火相撞炸出白汽与融水、高热刃入海蒸成细雾、气浪掠过水面压出凹槽、重击落石地先龟裂下陷再掀飞石块）。

**受击剥离物**按受击方材质在设计时锁死常规交击的掉落清单（碎甲、碎鳞、断角、碎岩、冰片、熔滴、电火花；写实血肉题材把血雾或破布列进清单），高潮拍可按第 5 节发生唯美相变（余烬化雪、碎冰成花、刀风卷叶、能量化光尘）。

**破坏写到终态**：重击后受击方仍存活时，在同一时间片写明身体完整留在原地、破坏只到哪一层（`甲背裂开一道缝、崩落几片甲片`）。战损在受损的时间片末尾写一次 `自此[部位][新状态]`；之后拍到它的镜头在开头用一个短语带到（`柱面带着凹坑`），不重述经过，最后一帧列全。战损痕迹（裂坑、犁沟、焦痕、霜迹、缺甲）随镜头**单向累积、只增不减**。

**色彩分账**：对抗双方各管一组颜色，`STYLE LOCK` 只列全片常驻归属色（`X 色管 Y`）与环境固有色。单一角色跨阶段解封变色（如二阶段从淡青切为深海蓝）、接触界面爆出的全场唯一**命中信号色**（通常为炽白）与相变物（白汽、折射、火花、分色交界）只写进发生它的时间片。非接触区各保本色，对方色只以边缘反射进入己方身体（侧面反光、勾边），接触界面由命中信号色吞掉两色，不混出第三色。高速下人物糊成光带时，用光带的粗细、边缘形态与芯色区分两方。

**能量即光源与反射**：发光招式、熔核与爆心在出现的时间片作为实时光源照亮面部、甲片与地面，或在大招出现时压暗天光；**反射面**（镜面刀身、竖瞳、冰瓣、水面）在特写中映出对手或巨型奇观；关键命中片把双方轮廓压在爆点或背景亮源前形成清晰剪影。

## 5. 时间轴与节奏

**时间网格**：`SHOT` 区间与时间片都用全片绝对秒数，首尾相接。多镜段落每镜 `2–5s`，一个镜头拍完一条动作链，镜内切片，每片不超过 `3s`，一个时间片是一条机位不变的连续动作（一招、一串连击、一次往返）；总时长由动作链长度与交手密度推出，在模型上限内按需取值。时间片的时长取动作实际做完的时长：接触、咬合、起跳到落地都是一瞬，一串连击按击数乘间隔算。

- **同拍双动**：同一时间片内攻守双方都有动作或受迫反馈（即便被冻结或压制，也有红眼骤缩、熔核跳动、钩爪抽动）。攻击落在对手的附属物上（法器、坐骑、护盾、召唤物、手中兵器）时，持有者同拍先试图阻止（格挡、回拽、闪避），被击中时身体随之受力（偏头、后仰、踉跄）。
- **长片必有运动**：任何超过 `0.6s` 的时间片都写一个正在进行的身体动作、微观漂浮运动或镜头运动，只写氛围与情绪的时间片会被渲染成定格。双方相抵、滞空、定姿这类没有位移的状态超过 `0.6s` 时，写出正在变化的量（被一寸寸推后、刀刃滑向护手、身体下坠）。

**命中分两档**，细节按分量给：

- **普通命中**（连击串里的每一击、试探、格挡）：一击一个短句，只写攻方动作、接触点与守方的反应。
- **关键命中**（改变战局的那一下：破防、击飞、攻守易手、终结；一个镜头至多一处）：独占一个时间片，写接触点、受力方的反应与剥离物，再从下列通道里取与这一击最相称的一两项，视效的落点就是接触点。

- **光**：超凡档接触点的招式光照亮双方，亮度只铺到接触点周围；写实档靠飞溅的汗水、水花、火星反光与灯具晃动。火花与高光顺受力方向散开。
- **声、环境与身体**：重击或骤停；冲击环、碎石、气浪；震开、后滑、形变，击退距离与攻击轻重成正比，并打断受击方的下一个动作。
- **毛发与布料（CFX）**：长发、衣袍、残布与挂件在蓄力时被反向吸紧，接触帧沿冲击方向猛烈甩开并撕下碎片；蓄压拍里它们与环境微物一起保持飘动。

**两种慢法**：全片以全速为底，慢只来自这两者，不写全程匀速慢动作。

- **蓄压拍**（`0.5–1.5s`）：管爆发前后的常速屏息，留给开场、每串连击之前与之后、高潮前与收势。写蓄力、双方角力或环境呼吸，主体保持微动、镜头保持慢移，不做慢动作。
  - **极动前蓄压**：终结技释放或大对撞爆发前的蓄压拍取 `0.3–0.8s` 并写明起止秒数。速度压住但不停，接触点持续角力（刀刃在咬合处颤抖着一寸寸推进、火花与白汽不断喷出、发梢被气流拉直、镜面刀身最后一寸滑入鞘口），镜头极慢推近。
- **升格慢镜**（成片 `0.8–2.0s`）：高帧率摄影的时间膨胀，把现实中 `0.1–0.3s` 的转瞬动作拉长放大，管毫厘惊险与微观物理美感。全段只放 `1–2` 处（长段至多 `3` 处），留给**毫厘擦身**（刃锋贴瞳孔或发丝掠过）、**破局出刃／机关击发**、**交错对视**或**高潮升华展开**；普通位移与常规拆招不放慢。prompt 正文不裸写「升格」二字，把时间膨胀拆成三步可见变化写进时间片：先从全速突进**骤压入极慢动作**（或由蓄压滑入极慢动作）；再写**主体大动作逐寸慢移 + 常速看不见的微观悬浮细节**（刃口劈开半空水珠、汗滴／火星／碎甲缓慢自转漂浮、气浪波纹逐层推开衣褶、瞳孔倒影放大）；最后在精确的物理门控点（切过、崩甲、入鞘、踏地）**骤然切回全速**释放动能。

**痕迹悬留**：需要刀痕、残影或冰封瞬间留在画面里时，写成 `[刀痕／冰封物]悬在原处不散`，同一句写环境微物（雪片、浪沫、碎鳞、寒气、发梢）持续飘动或被牵引、镜头慢移。兵刃留下的痕迹悬留时，同一句写明兵刃已离开痕迹、此刻在哪里，否则痕迹被画成第二把兵刃。

**连击串**：交锋以连击串为单位，串内平均间隔 `0.3–0.6s`，按「快连逼防 → 半拍拧腰沉蓄 → 重击破防」排出轻重顿挫（如前两击各 `0.3s` 快刺逼退、第三击拧身蓄半拍后重劈破甲），逐击列出动作，不写成等距同力的机械互砍。一串连击写在一个镜头的一个时间片里，由一条跟拍连续带过，逐击按普通命中写；串尾破防的重击按关键命中另起一片。前后各接一个蓄压拍；相邻两串共用中间那一个，串后紧接新动作时，蓄压并进那个动作的起势，不另占一片。

**单向升级**：前中段每拍兑现一次战术或演出规格升格：**新机制首现、空间维度跃升（从地面拆招打穿掩体到破空立体交锋或改写天象）、形态解封变色或实质破防**，且每次升格由上一拍的结果逼出；推至决胜拍时从物理当量加码跃迁为视觉升华，画面可由繁入简、由噪入静。拍名连起来即为动作链。

**冲击帧**：决定性受力的 `0.1s` 视觉标点，只放在改变战局的那一下（实质破防、终结技落到身上），全片通常 1 处、最多 2 处，按戏的分量放，不按间隔排。画面内容就是这一下的受力构图：被击中者的剪影、贯穿他的力线、指向接触点的集中线，整幅切成与 STYLE LOCK 反差最大的一种画法（黑白高反差、负片反色、红黑双色、粗铅笔原画线稿），一闪约 `0.1s`，在同一时间片内写明恢复原画风，形变与战损在恢复后继续存在。前面用寂静蓄住，后面用物理余波释放。闪避、落空、砸地与普通接触只写形变与碎屑，不闪白、不闪切。

**高潮视觉升华**：前中段靠形变与碎物立住重量，决胜拍不再堆砌更多碎石与黑烟，按题材与画风选用 `1–2` 种机制把物理搏杀提纯为审美高潮（可单独作终局，也可接在多级终爆的坍缩或余波段）：

1. **空间抽离与留白**：借强逆光压黑全场、爆心过曝洗白、浓雾飞雪吞没远景、水面镜化或单色天幕，暂时抹去杂乱战场背景，画面只留纯净底色、双方剪影与唯一核心刃迹／光轨；写明背景地标被压黑、洗白或留白隐没，待收势拍光雾散落后再显露原位永久地标。
2. **杀伐的唯美相变**：决胜一击的能量、剥离物或崩解过程跳出粗糙泥石焦烟，发生贴合母题的审美转化。超凡档化为寂静盛放的冰花、漫天上浮的金色光尘／流萤、水墨飞白或琉璃碎光；写实档调动天地介质与光场共振（刀风卷起漫天红叶或飞雪与血雾同舞、刃锋震落万千雨滴在逆光中悬停发光、阴云裂开一束天光打亮刃尖水滴）。
3. **极盛归寂（做减法与延迟兑现）**：铺满画面的连击、巨浪或弹幕推至顶点时骤然做减法，万千声光尽数敛入无声的一线素刃、一滴落水或一次合鞘，抽空环境杂音并配升格慢镜掠过对手；停顿半拍至一秒后，天幕裂痕、切口错位或躯体崩解才延迟落下。
4. **整拍媒介升格**（用于允许破界的风格化题材，全片至多 1 处）：在觉醒、必杀展开或生死交错的整拍（`1–3s`）内，整幅画面升格为高张力异质媒介（狂草水墨飞白、粗粝炭笔原画线稿、高饱和平涂色块剪影），在异质画法中走完核心发力与轨迹，同一拍或下一拍开头写明落定／收刀时褪回 STYLE LOCK 原画风。

**多级几何终爆**（高潮走大当量摧毁或双波对撞时）：拆成 **2–3 级几何演化**，先向内坍缩压成极亮一点（或海面／云海下凹成漩涡坑吸住目标），停顿半拍后反向膨胀、掀立成巨墙或逐层绽开炸裂，保留双方色彩分界与飞散残骸（或转化为漫天唯美相变物），冲击环推平尘土或云海，炸开后余光悬留、碎物坠落。

**结尾类型**先定：

- **悬停**：停在全段张力最高的接触或揭示上（两股力咬死、对手新形态首现、角色隐藏的能力或状态首次显露），让下一段有处可接；段落属于更长战斗时优先悬停。没有决胜拍时，视觉升华落在悬停的这一拍上，在原画风内做。
- **收势**：胜负落定，给落败反应与余韵留足时长，最后 `1.5–2s` 落在一个安静但仍在进行的动作上（缓步垂刀、闭目呼出白气、抬手擦去血迹）。
- **白场收束**：高潮的光逐级过曝，整幅洗成白，白场里只剩碎物下落，最后落在纯白或清场后的空景；用于终结技吞没全场，或下一段从白场起拍。

悬停与收势都把全段累积的战损与地标保留在画内。

## 6. 空间、焦点与运镜

**场面调度**：

- **三层纵深与负空间**：前景放虚化的对手肩背、兵刃、飞掠碎甲或环境障碍框景并制造高速视差；中景放攻防交锋主体；背景锚定 2–3 个永久地标与天象尺度（高潮空间抽离拍可借压黑、洗白或留白暂时隐没背景地标，收势再显露）。用纵深走位（从远景贴地冲入近景挥斩，或被重击从近景砸向远景）在单镜内完成景别跃迁。破除双人居中塞满画框的默认构图，主动留出两类**负空间**：**运动负空间**在突刺、冲锋或重击击飞前把发力方压在出发侧（如画左 `1/4`），朝运动方向留出大片空旷画幅承接位移轨迹与刀光；**戏剧负空间**在对峙蓄压或高潮升华拍写死悬殊画幅占比（如漫天风雪、巨物阴影或空旷死地占去 `3/4` 画幅，主角缩在底角），用大块留白兑现孤绝感与压迫感。天象级痕迹（劈开天空的刀痕、横贯天幕的光带）写明所在纵深与出现时刻，人物与地面在它前面；只写「横贯画面」会被渲染成贴在镜头上、穿过人物的光束。
- **画面坐标与轴线**：每个运动物写明朝向、起点与去向（`[物体][朝向]，从[画面方位]向[画面方位][运动方式]`）；要对撞的两股力放在同一条轴上。主角朝目标前进的方向全片保持一致：侧面镜头里朝画面同一侧（如画右），对抗轴上的机位（身后跟拍、正面迎拍、贴地仰拍）里沿纵深冲出或迎向镜头；环绕保持在对抗轴同侧。墙、门、巨物这类大型布景写明它在本镜画面里的朝向（正对镜头的背景墙，或画面某一侧、朝向哪边的侧墙）。画左画右只指本镜画面，切镜后不延续；后续动作依赖的相对关系（谁面对谁、谁在谁身前身后、接触面朝向）写成本镜的可见结果，即谁的哪一面朝镜头、谁被遮挡且露出什么，写进时间片。已在场的人物与关键物在每个镜头里都写明画内位置，拉成全景或远景时也一样（空间抽离拍写明隐没方式）。
- **看点进画与剪影分离**：机位架在能直接拍清兵刃咬合面、受击形变部位与核心表情的一侧；主动作轮廓落在干净受光面、天空或亮源前。

**焦点**：

- **单拍唯一焦点**：每拍只留一个视觉焦点，按 `蓄力锁局部微距（手／眼／机关）→ 出招锁全身发力弧线（升格慢镜锁毫厘擦身与悬浮微物）→ 命中锁接触点形变与受击反应 → 余波锁环境崩解尺度或升华意象` 移交。非焦点区域通过浅景深虚化、压暗或放慢动作主动让位。
- **镜内移焦**：用移焦引导视线跳跃（前景刃口实焦映出敌影 → 挥斩瞬间移焦至中景对手崩甲），写进发生它的时间片。

**运镜**：

- **摄影机物理惯性与攻守视角反转**：把摄影机当作场内受力的物理实体，运镜速度曲线与发力节奏耦合：蓄势时缓慢压近或下沉屏息，出招时随动势急甩或贴身加速跟拍，命中时急停或被气浪撞退，残心收住时带阻尼缓滑停稳。机位与构图随攻守权力同步翻转：主角受制落入下风时切压顶俯拍、逼入画框死角、对手越肩压迫或险境微斜构图；破局反击那一拍同步反转机位高低、越肩主导权与画幅占比。焦段、景深与机位按下表的戏剧任务选。
- **旋向解耦**：同一镜头或时间片内同时存在旋转特效与环绕运镜时，在该时间片分别写死俯视旋向（风暴逆时针、镜头顺时针）并锁死人物朝向。
- **少切**：镜头数取动作链的段数，一个镜头拍完一串连击或一次往返交手。确需换机位时切在动作中途（挥到一半、飞到一半、跃到空中），下一镜从同一动作的下一瞬接上，开头写明双方的画内位置与持物，切换前后画左画右关系、视线与运动方向不变。
- **一镜一个运镜**：每个镜头只写一个焦段与一种机位运动，这一种运动可以带快慢（慢起、急甩、急停），景别变化靠跟拍、环绕与纵深走位在镜内完成，不在镜头头里串联转镜。
- **镜头头与最后一帧**：每个 `SHOT` 的标题行只写焦段与运镜（`16mm 低位越肩仰拍急摇`）；前景框景物只在它参与动作时写进时间片。镜尾不重写状态：下一镜开头的站位、持物与数量写成可见动作结果，不用「维持原样」「同上」指代。末镜以「最后一帧」收尾，列全最终定姿、全部留存痕迹与原位地标。

## 8. 交付核验

逐项核验：

- **成片四问**：多镜完整段落按第 3 节的四问看完整条时间线，属于更长整场的单镜与分段只核它承担的那几问；不过关先改戏，再做下面的合规核验。
- **粒度与结构**：单镜只有一条 `SHOT` 并以最后一帧收尾；多镜的锁与分镜齐全；跨段组接已对齐每段上传素材与继承战损；全局段里没有初始站位、招式、特效物、剥离物、痕迹与带时刻的事件；prompt 里没有规则句、米数与帧数，同一事实只出现一处。
- **实体闭合**：超凡与重火力档每个【招名】第一次出现的那句写齐触发动作与发出部位和第 4 节四步，之后每次出现仍带主色、载体与形态；写实档的每处光都有场景光源或反射来源，每次重击在命中片写明接触点、形变与剥离物；每处战损只在受损当场写一次 `自此`，之后拍到它的镜头开头带到，最后一帧列全。
- **素材与成像**：质感图是纯色底的孤立特效；没有哪一拍依赖身份图上的部件在后续镜头里保持损毁；人物被拍到的视角身份图里都有。
- **时间与镜头**：每个时间片是一条机位不变的连续动作、双方都有动作或受力，时长不超过动作本身，没有位移的状态写了变化量；关键命中独占一片并写齐接触点、反应与剥离物，普通命中每击一个短句；每个镜头头只有一个焦段与一种运镜，镜头数等于动作链的段数，prompt 里没有连切、镜头震动、顿帧与提速；移焦写在发生它的时间片里，核心接触点在画内拍得清；升格慢镜不超过 3 处、每处 `0.8–2.0s` 且三步展开、未裸写「升格」；冲击帧不超过 2 处、整拍媒介升格不超过 1 处，只落在破局或决胜处，均写明画法、起止与恢复原画风的时刻；闪避、落空与普通接触没有闪白与闪切。
- **预算**：一个时间片写不下或全段超篇幅时，先删修饰（招式再次出现时的载体分层、普通命中上的光声衣发、空间记账与解释性从句），再把镜头并少，最后才减招式；每一击的守方反应、关键命中的三项、招式首现的四步、高潮前的蓄压拍与决胜视觉升华不删。

自检后做一轮**冷读**：让没有本次设计上下文的读者只凭 prompt 走一遍时间线，暴露作者脑中默认、纸面缺失的信息。有子 agent 能力时派发一个，只给它 prompt 全文与素材职责，不给设计理由，要求它按时间顺序逐句列出问题，每条附原句：

1. **因果**：每个动作、招式与状态变化的起因都在更早的时间片里；门控事件不抢跑；相对位置、数量与时间走得通（够得着、来得及、数得清），物体在给定站位里摆得下。
2. **画面顺序**：时间片连续且相加等于总时长；每镜开头的人物、持物、位置、朝向和数量与上一镜结尾的动作结果一致；全局段写的状态在每一帧都成立，会变化的状态写在它变化的时间片里；每个镜头写到的画内元素在该焦段与机位下拍得到；已在场的人物与关键物在每个镜头里都写明画内位置（微距虚化或高潮空间抽离拍写明背景地标如何隐没，收势与最后一帧再显露）。
3. **歧义**：每一处有两种以上读法的句子，写出各种读法。重点查左右指画面方位还是角色身体侧、朝向、姿态、物体存在与数量、同一对象换名。

没有子 agent 能力时，自己按这份清单冷读。每个问题改写原句关闭：删去冲突或改写歧义，补缺的起因只补一个可见动作或状态，不为闭合追加米数、帧数与解释性从句；改动后派新的子 agent 重跑冷读。完成标准：冷读输出中没有未处理的问题；同一问题修两轮仍未关闭时停止修补，在 prompt 后写明卡点。

只输出可直接粘贴的 prompt，和需要用户准备的参考图清单（每张写明图名、画面内容、要看清的部件与用途，各图同一画风）；对齐时未经用户确认、由你选定的项，在 prompt 后逐条列出；冷读改动了用户给定的尺寸、数量、造型或时间点时，在 prompt 后逐条列出。拆分为多段时按成片顺序逐份输出，在每份 prompt 之外标明它对应的成片时间段与上传素材。
