# Fight Prompt

战斗戏的复杂度留在草稿里，prompt 只写模型能兑现的部分。先设计（第 2 节），再按模型的粒度改写成 prompt（第 3、4 节），最后核验（第 5 节）。

## 1. 三条原则

后面的写法都从这三条推出，没覆盖的情况按这三条判断。

1. **粒度对齐**：模型对时间、空间与数量各有一个能兑现的最小粒度。写得比它细的部分不会被执行，只会变成互相争抢的约束，先被挤掉的是动作的流畅。时间的最小粒度是**拍**：一次做得完、看得清的攻防往返（一方出手、对方应对、一个结果），约 2–4 秒。拍以下的快慢、轻重与先后用话说，由模型排时值。空间与数量同理：方位、占比、道数只在后面的动作依赖它或它本身是看点时写。
2. **接缝**：连贯是模型的默认输出。切镜、时间片分界、画风切换、变速、要记住的状态变更，每一条边界都要模型在那一刻重新对齐一次，是一道**接缝**。每道接缝都由戏里的一次转折来换，换不来的并掉。
3. **只选不搭**：模型自带动作、物理、特效与运镜的先验。prompt 在这些先验里**选**出要哪一种，写观众看到的结果（谁用什么打向谁、对方怎样了、留下什么）。成像的过程（载体分层、相变路径、发力链、触发顺序）由模型自己搭。

由此得一条推论，**状态在像素里**：身份、造型、战损与站位靠参考图和上一段的尾帧携带，文字只写这一段里新发生的变化。

## 2. 草稿：设计这场戏

草稿只用于推导，不进 prompt。

**这场戏**：两三句写下主角此刻是什么人、处在什么处境、观众该感受到什么、战局在哪一下翻转。招式、视效与镜头都服务于它。

**成片四问**：

1. **主角被看见**：关键拍读得出主角的态度，靠脸与眼神，或画内看得清的姿态。
2. **真交手**：双方都构成威胁，局势由主角自己的动作决定。有来回的戏里主角至少一次落入下风再翻转；一击定胜负的戏把威胁放在出手前的对峙里。
3. **节奏有反差**：快与慢、密与疏、声与静交替。
4. **高潮有升华**：决胜拍留下一个只属于这场戏的画面，不只是更大的爆炸。留白剪影、杀伐化成贴合母题的美物、极盛后归于一击、环境或天象被一招改写，取一种，在原画风内完成。

**攻防语法**按体量比、射程与人数定：

| 对抗 | 打法 | 重量靠什么兑现 |
| --- | --- | --- |
| 悬殊体量 | 小的一方卸力、侧滑、蹬踏、攀爬，硬接必付代价；大的一方起手沉、落势快 | 落空砸毁的地面与布景，巨物局部崩落与失衡 |
| 同体量近身 | 距离的进退、兵刃的粘架弹滑、重心的破坏；每次交锋改变身位或攻守 | 击退、滑行、撞碎掩体 |
| 远程与重火力 | 发射与后坐、弹道跨越空间、拦截或规避 | 掩体与护盾的破坏、地面的灼痕与弹坑 |
| 一打多 | 主角沿一条动线切入，每拍只与最近的一两个目标接触，其余围拢或被余波扫开 | 被击者撞翻后排，阵型被犁出缺口 |

要看来回拆招与双方表情时对手取同量级；巨物战里主角在画面中很小，用脸部特写补回主角的戏。

**因果链**：用一串 `X → 所以 Y` 写完整场交手，要分段时先写整场再切。每一步的起因是上一步留下的东西：受力成为下一招的起势，被改写的环境成为下一步的条件，一方的处境逼出另一方的新手段。被后一步依赖的环节由大而清楚的动作或形变承担。升级沿链单向推进，每次升级由上一步的结果逼出。

**结尾**取一种：

- **悬停**：停在张力最高的接触或揭示上，段落属于更长战斗时取这种。
- **收势**：胜负落定，给落败反应与余韵留足时长，落在一个安静但仍在进行的动作上。
- **白场**：高潮的光洗白全幅，用于终结技吞没全场。

**素材**：用户已给的参考图直接绑定。未给的不停下来等图：主体特征写足，使 prompt 不带图也能直接运行，另附一份准备清单供用户补图后加绑。身份图上的部件在片中被毁或卸下后，模型在后面的镜头里会把它画回来，所以转折与结局落在身份图里没有的东西上（环境破坏、对手的崩解、姿态与站位）；剧情必须毁掉这类部件时，在那一下分段，后段改绑受损后的图。

需求没给的项（物理档、对手体量、胜负、画风、伤害尺度、结尾类型）按最贴合需求的取值写定，交付时列为代选。

## 3. 从草稿到 prompt：按模型的粒度改写

草稿的细度是设计用的，照搬进 prompt 会超出模型的粒度。下面每一步都把草稿里的一类细节压粗到模型能兑现的程度。

**分段**：超出入口单次时长时拆成多份自包含 prompt。分段点取蓄力顶点、遮挡擦镜、尺度跳变或身份部件受损的那一下，段尾停在一个仍在进行的动作上。续段绑定上一段的尾帧作承接图，由它决定开场画面、对手造型与环境现状，第一拍直接从图里的动作接着演。

**分拍**：把因果链切成拍，一拍一个时间片。

- 一拍写一次往返与它的可见结果，一两句。开场第一拍写明双方的站位与朝向。动作本身占不满这一拍时，把起势与余波写进来；一拍写不下时拆成两拍，不压缩成更短的时间片。
- 连击、拆招与快慢顿挫写在一拍之内，用话说出次序与轻重（两下快刺逼退，第三下拧身重劈），不为每一击标秒数。
- 双方在同一拍里都有动作或反应。
- 结果写到终态：被击者在哪里、成了什么样、还剩什么。只写炸开或崩飞会把整个人抹掉。
- 没有位移的拍（对峙、蓄力、收势）写出此刻仍在动的东西（衣发、粒子、光、镜头缓移）。全片最后一句写画面结束在哪个仍在进行的动作上。

**分镜**：一个镜头装下一串相连的拍。镜头数等于戏里需要换视点或换尺度的次数（脸部特写、尺度揭示、高潮），其余的景别变化靠镜内的跟拍、环绕与纵深走位完成。每镜一行 `CAMERA`，写成一条连续路径：起幅景别与角度，随动作怎样运动，落在什么构图。用景别、角度与运动描述，不标焦段。

**接缝清点**：冲击帧、整拍换画法、慢动作、形态切换各算一道接缝，只放在草稿标出的转折上，各用一句写明画面变成什么、何时变回。镜头震动、顿帧、提速、调色加在成片上，不写进 prompt。

**用词**：

- 每个人物、物体与招式全片只用一个名字。
- 特效用一个短语写清颜色、形状与像什么（一道桃红与青色的新月形刀光），招名与抽象词（凌厉剑气、强大魔法）换成这样的短语。
- 写下的词都会入画。某处没有某物时写那里实际是什么；想要克制时写出克制的画面，不写「静止」「定格」。
- 方位用画面坐标，只在本镜之内有效。
- 形制与存在状态先在正文正面写定，负面提示只补充本段真实的退化风险。

**全局段只放常驻事实**：模型生成每一帧都读整段 prompt，主体、基准里写的东西从第一帧就在。只在某一刻出现的东西（招式、特效、变色、破坏、天光变化）写在它发生的那一拍。

## 4. 输出模板

纯文本，方括号按当前设定填写，用不到的行整行删去。画幅、时长与分辨率由入口参数控制。入口不支持秒级时间戳时，时间片改写成起初、随后、最后，结构不变。入口不生成声音时删去声音；生成声音时，只在出现新声源或配乐转向的拍写声音。

```text
素材绑定（只绑已有的图）
「[图名]」决定[它锁定的东西：脸、造型、配色、画风]。[姿势、站位与构图]由下文决定。
（续段）「承接图」是上一段的最后一帧，决定[对手造型、环境现状与开场画面]。之后的动作、光色与构图由下文决定。

主体
[称呼]：[3–6 项全片不变的可见特征]。
[武器]：[形制、相对人体的尺寸、材质与颜色]。
[对手]：[体型尺度、材质、核心特征]。

基准
媒介：[画面媒介与质感]。
空间：[场景、地面材质、远景]。
光色：[开场的天光与主光、角色身上的主色]。
声音：[配乐的乐器与走向]。

时间轴
SHOT 01｜[镜名]｜0–[N]s
0–[a]s：[谁做什么]。[对方同时怎样]。[可见结果]。声音：[声源与时机]。
[a]–[b]s：[下一拍]。
CAMERA：[起幅景别与角度] → [随动作的运动] → [终幅构图]。

SHOT 02｜[镜名]｜[N]–[M]s
…

负面提示
[本段真实存在的退化风险]
```

## 5. 核验与交付

逐项核验，发现问题时删或改写原句，不靠追加从句、数值与锁定行来修：

1. **拍**：每个时间片是一个动作加一个结果，时长落在一拍之内，首尾相接等于总时长。
2. **接缝**：列出全部切镜、换画法、变速与形态切换，每一道对得上草稿里的一次转折，对不上的并掉。
3. **只选不搭**：每句都是观众看到的画面或听到的声音。写过程、机制与规则的句子改成结果或删去。
4. **精度**：每个方位、占比与数量，要么后面的动作依赖它，要么它本身是看点，否则删去。
5. **状态**：没有哪一拍依赖模型记住前面镜头里的文字状态；跨段的状态由承接图携带。
6. **全局段**：主体与基准里只有每一帧都成立的事实。
7. **成片四问**：按第 2 节看完整条时间轴；属于更长整场的分段只核它承担的那几问。不过关先改戏。

自检后做一轮**冷读**：有子 agent 能力时派发一个，只给它 prompt 全文与素材清单，要求它按时间顺序复述每一拍画面里发生了什么，并列出有两种以上读法的句子与找不到起因的变化，每条附原句。复述与草稿不符处即问题。没有子 agent 能力时自己冷读。同一问题改两轮仍未关闭时停止修补，在 prompt 后写明卡点。

交付三样，依次输出：prompt、参考图准备清单（每张写明图名、画面内容与用途，各图同一画风）、代选列表（每条一行）。prompt 单独放在一个代码块里，从「素材绑定」到「负面提示」，可整块粘贴；清单、代选与分段标注都在代码块之外。分段时按成片顺序逐份输出，每份代码块前标明对应的成片时间段与上传素材。
