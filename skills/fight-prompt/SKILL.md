# Fight Prompt

## 1. 定生成粒度与素材职责

每条 prompt 按第 6 节模板写，只保留本次实际出场并生效的素材、招式词条与执行行：

- **多镜（10–30s，4–10 镜）**：一次生成包含起承转合的完整交手段落，配齐模板各块，防止中后段设定漂移与战损吞没。
- **单镜（2–6s）**：一次生成只拍一个戏剧动作（蓄力微距、单招挥斩与残心、独立命中终爆）。只写一条 `SHOT`，删去 `SEGMENT`、`衔接` 与 `节奏` 行，描述密度集中在本镜的微距物理、全身发力链或爆裂层次上。
- **多段组接**：战斗超出单次时长上限，或包含跨尺度特写（微距压镡 → 稳机位挥斩 → 巨型刀痕终爆）时，拆成多条独立 prompt，每条按自身镜头数写成多镜或单镜。
  - 切分点只取蓄力顶点定姿（举刀指天白光炸开）、收招死寂拍（合鞘瞬间）、遮挡擦镜（碎鳞、刀光、浓烟铺满前景）或微距切全景的尺度跳变点；在挥刀中途切分时按动作匹配剪辑锁死首尾帧。
  - 每条顶行写 `用在：[成片时间区间]` 与 `上传：[本段实际用到的素材名]`。
  - 具名色分账、双方不变量与永久地标方位各段一致。续段在 `环境` 行首句列出前段留下的具体战损（`左肩缺三块甲、胸前缺两块甲、画左冰沟全程保留`），`SHOT 01` 开场直接带着这些战损、站位与光线起拍。

动笔前先定参考图清单。多镜与组接的战斗向用户要人物、对手、武器、场景的身份图与核心特效图，质感图只作补充；用户已给的图直接绑定，缺的图由用户准备。明确每份素材的控制边界，防止互相污染：

- **身份素材或文生主体**（角色、对手、武器）：有参考图时用目标入口语法绑定，无参考图时直接内联进开篇主体句；各自锁死 3–6 项全段不变的可见几何特征（发式、疤痕、服饰或装甲结构、兵器部件与持握方式、瞳色、胸口核心）。身份图里会在战斗中被毁、卸下或改形的部件（饰物、头盔、护甲、兵器），绑定时写明它只代表某个时间点之前的外观；之后该角色出场的每个时间片都正面写一次新状态（`[部位]空无一物／已断／已卸下`），它的碎片与残骸离开原位、不排成原形，否则模型会在下一个特写里按身份图把它画回来。
- **场景素材**：锁死 2–3 个永久地标及其画面方位，区分不可毁地标与可改写介质（地面、海面、云海、植被）。
- **质感或关键帧素材**：只借材质、形态或特定画面构图（冰封质感图、劈天刀痕关键帧），写明人物或对手外观仍以对应身份素材为准。出招人物在终爆构图中占比极小时，撤下人物与随身武器素材，只绑定关键帧、受击目标与场景，省去人物动作锁。

## 2. 建攻防力学与动作锚点

先按双方的**体量比、兵刃射程与人数**确定攻防语法，再设计具体动作：

| 对抗类型 | 攻防力学语法 | 受击与环境反馈 |
| --- | --- | --- |
| **悬殊体量（以小搏大／巨物战）** | 小体型方的防御词表限定为斜架卸力、贴地侧滑、借力蹬踏、绕背攀爬；被迫硬接必写泄力代价（双膝下沉龟裂、被推出十米犁沟）。巨物起手沉、落势快，靠体量横扫与压迫 | 巨物局部崩甲、碎鳞、断角、后仰踉跄或单膝跪地；落空攻击写明砸毁的柱段、礁石或地面深坑，兑现重量 |
| **同体量近身博弈（冷兵／拳脚）** | 重在距离切入（丈→尺→寸）、兵刃走势（粘、架、弹反、刮刃滑脱）与重心破坏（破防失衡、扣腕别肘、横扫跌扑）；每次交锋改变双方身位或攻守主导权 | 刃口火花、护具裂痕、衣袍撕裂、脚步滑行犁痕、震退撞碎掩体 |
| **远程与重火力交锋（法术／枪炮／机甲）** | 锁死发射源与后坐力 → 弹道或束流跨空间推进 → 拦截（立盾、斩开、掩体吃弹）或机动规避；两股持续力量对撞时写出推回位移与中点压缩咬死 | 护盾蛛网碎裂、反应装甲掀飞、过热白汽、焦黑弹孔群、后坐力踏陷地面 |
| **一打多群战（突围／冲杀）** | 主角沿明确动线切入，每拍只与前景最近 1–2 个目标发生实打实的物理接触，其余敌群承担围拢、受惊硬直或被余波扫飞 | 前景受击者甲碎倒飞撞翻后排，阵型被犁出缺口 |

再写**动作因果链**，招式、升级与分镜都从这条链上取：

- 用一串 `X → 所以 Y` 写完整段交手。每一步的起因是上一步留下的东西：受力转成下一招的起势，被改写的环境成为下一步的条件（遮蔽、掩体、落脚点、障碍），一方的处境逼出另一方的新手段；角色设定里的特质在链上某一步成为破局的原因。双方每一步都在回应对方。
- 双方距离、关键物体的尺寸与数量在链里写定并逐步记账；每一步都能用这些数值走通（够得着、来得及、数得清）。

为关键动作建立清晰的**姿态锚点**与**触发映射**：

- **起势 → 爆发 → 残心**：开场、静拍与终局的招式钉死**起手定姿**（沉腰握刀、拇指压镡、双手举刀过顶、拉弓满弦）与**收势残心**（刀停身侧半秒、单膝插刀滑停、背身静立衣发顺刀势甩出），用两端静止姿态夹住中间的高速爆发。链中段的招式以上一步的反作用为起势，收势直接流进下一步。
- **身体动作唯一触发**：超凡招式或重火力在执行锁中建立 `身体动作 → 【招名】` 的触发表；每股能量都由身体发力起手或机关动作引出。
- **形态切换**：战斗中发生变身或装甲着装时，锁死**同一位置、同一姿势**，通过能量光柱、发光线稿闪切或装甲部件逐块扣合完成切换。

## 3. 实体化打击与视效

先定本段的**物理档位**：

- **写实物理档**（武侠、历史冷兵、拳脚、现代战术）：光只来自场景光源与刃面、水面、汗珠的反射，力量靠形变、颗粒物与环境受迫反应外化。字典写成「打击锁定」，只列核心重击与兵刃交互，每次重击写明接触点、形变与剥离物。
- **超凡与科幻档**（法术、剑气、机甲重武、异能）：字典写成 VFX LOCK，本段每个核心视效或特殊重击建立独立【招名】词条，攻守双方均列。

每条词条按四步写齐：

1. **物理载体**：指定可见物质或光学现象作载体（墨滴与飞白残迹、空气透镜折射与压碎的石块、绷紧反光的金属细丝、电弧与高压白汽），替换「凌厉剑气」「强大魔法」这类抽象词。
2. **几何与数量**：写明形状、厚度与形制；外形易混的物件（矛与剑、枪与炮）用部件级描述锁定（头部形状、杆或柄、护手有无、长度比例）。唯一光核、裂口、巨浪写死 `1 颗／1 道`；离散连击、冰棱、花瓣写死 `七道／十二簇／三层`；尺寸用人体或画幅比例锚定（`宽过半个画面`、`高过人物五倍`、`一指厚`）。
3. **内外复合层**：`[主色 + 核心实体材质]`，内含 `[内部纹理／流束／碎晶]`，缠绕 `[外层伴生物：碎石／电弧／霜花／焦烟／浪沫]`，`[前缘／尖端／命中处]` 爆 `[全场唯一信号色]`。
4. **结构化蔓延与相变**：作用到躯体或环境时写明推进路径（沿甲缝五路爬开、沿裂纹冻结成壳再崩落、从膝甲螺旋爬上胸口、切口先滑开再崩散、海面先压凹成漩涡坑再拔起成巨墙）。两类介质接触时写出相变（冰火相撞炸出白汽与融水、高热刃入海蒸成细雾、气浪掠过水面压出凹槽、重击落石地先龟裂下陷再掀飞石块）。

**受击剥离物**按受击方材质锁死清单（碎甲、碎鳞、断角、碎岩、冰片、熔滴、电火花），清单就是画面里出现的全部碎物；写实血肉题材把血雾或破布列进清单。

## 4. 排节奏与升级曲线

- **命中帧同步**：命中帧上镜头（重震、急推或被冲击波推开）、速度（升格只放在出刃或接触瞬间，崩碎或滑脱时骤回全速）、光（超凡档接触点闪亮并照亮双方；写实档靠飞溅的汗水、水花、火星反光与灯具晃动）、声（重击或骤停）、环境（冲击环、碎石、气浪）与身体（震开、后滑、形变）在接触点同时突变。视效的落点就是接触点。
- **单向升级曲线**：多镜段落按每镜 `2–4s`（终爆可至 `5–6s`）排布，每拍兑现一次可见升级：**新机制首现、空间或尺度跃升、攻守易势或实质破防**，且这次升级由上一拍的结果逼出。拍名连起来即为动作链，烈度不回落。总时长由动作链长度与交手密度推出，在模型上限内按需取值。
- **变速与静拍控制**：
  - **交手密度**：交锋以连击串为单位，串内接触间隔 `0.3–0.6s`，写成 `每 0.4s 一击，连续 N 击` 并逐击列出动作；一个时间片可以装下一整串。慢只来自升格与静拍：全段升格不超过 3 处、每处不超过 `0.3s`，静拍只留给开场、终爆前与收势，其余时间全速。
  - **极动前极静**：终结技释放或大对撞爆发前，留出 `0.5–1.5s` 的静拍（四周死寂芒草垂落、两股力在正中咬住静止、镜面刀身最后一寸滑入鞘口）。
  - **局部静止**：需要定格刀痕、残影或冰封瞬间时，写成**核心刀痕／姿态静止 + 环境微物（雪片、浪沫、碎鳞、寒气、发梢）持续飘动或被牵引**。
- **多级终爆与余韵收势**：
  - 高潮打击拆成 **2–3 级几何演化**：先向内坍缩压成极亮一点（或海面／云海下凹成漩涡坑吸住目标），停顿半拍后反向膨胀、掀立成巨墙或逐层绽开炸裂，保留双方色彩分界与飞散的实体残骸，冲击环推平尘土或云海，炸开后余光悬留、碎块如雨坠落。
  - 先定结尾类型。**悬停**：停在全段张力最高的接触或揭示上（两股力咬死、对手新形态首现、角色隐藏的能力或状态首次显露），让下一段有处可接；段落属于更长战斗时优先悬停。**收势**：胜负落定，给落败反应与余韵留足时长，最后 `1.5–2s` 落在一个安静的可见细节（缓步垂刀、闭目呼出白气、余焰渐暗）。两类结尾都把全段累积的战损与地标定格在画内。

## 5. 锁色彩、场面调度、焦点与运镜交接

- **色彩分账与动态光影**：
  - **具名色互斥**：写成 `X 色管 Y`。对抗双方各管一组颜色；单一角色跨阶段升级变色（按招式阶段分用紫、淡青、深海蓝）时，各阶段主色明确切换，始终落在本方色组内。非接触区各保本色，接触界面才产生全场唯一的**命中信号色**（通常为炽白）与相变物（白汽、折射、分色交界）。环境固有色独立具名。
  - **能量即光源与反射**：发光招式、熔核与爆心作为实时光源照亮面部、甲片与地面，或在大招出现时压暗天光；**反射面**（镜面刀身、竖瞳、冰瓣、水面）在特写中映出对手或巨型奇观；关键命中瞬间把双方轮廓压在爆点或背景亮源前形成清晰剪影。
- **三维场面调度与因果门控**：
  - **三层纵深**：前景放虚化的对手肩背、兵刃、飞掠碎甲或环境障碍框景并制造高速视差；中景放攻防交锋主体；背景锚定 2–3 个永久地标与天象尺度。用纵深走位（从远景贴地冲入近景挥斩，或被重击从近景砸向远景）在单镜内完成景别跃迁；用站位高低差、画幅占比反转与逼入死角外化攻守易势。
  - **画面坐标与轴线**：每个运动物写明朝向、起点与去向（`[物体][朝向]，从[画面方位]向[画面方位][运动方式]`）；要对撞的两股力放在同一条轴上。主角朝目标前进的方向全片只呈现为两种：侧面镜头里朝画面一侧（如画右），身后镜头里冲向纵深；交锋镜头只从这两类机位拍，环绕保持在对抗轴同侧。每一镜都按本镜的摄像机写出画面里能看到什么，不靠其他镜头或全局方位约定推断：画左画右只指本镜画面，切镜后不延续；后续动作依赖的相对关系（谁面对谁、谁在谁身前身后、接触面朝向）写成本镜的可见结果，即谁的哪一面朝镜头、谁被遮挡且露出什么，写进时间片与 `CAMERA`；`HANDOFF` 只负责交接，不能替代；没写到的关系模型按最常见构图补全。
  - **看点进画与剪影分离**：机位架在能直接拍清兵刃咬合面、受击形变部位与核心表情的一侧；主动作轮廓落在干净受光面、天空或亮源前。
  - **痕迹累积与门控**：战损痕迹（裂坑、犁沟、焦痕、霜迹、缺甲）随镜头**单向累积、只增不减**。按 `成形 → 逼近 → 接触 → 受力 → 破坏 → 留痕` 推进，倒地、碎裂与留痕都发生在接触帧之后；跨拍联动写死**门控事件**（`霜环触到钩爪后魔兽才睁眼`、`刀镡咔地合上鞘口那一刻冰莲才绽放`）。
- **焦点层级与移焦引导**：
  - **单拍唯一焦点**：每拍只留一个视觉焦点，按 `蓄力锁局部微距（手／眼／机关）→ 出招锁全身发力弧线 → 命中锁接触点形变与受击反应 → 余波锁环境崩解尺度` 移交。非焦点区域通过浅景深虚化、压暗或相对静止主动让位。
  - **镜内移焦**：用移焦引导视线跳跃（前景刃口实焦映出敌影 → 挥斩瞬间移焦至中景对手崩甲）。
- **分镜时序与同拍双动**：
  - 镜内按 `0.5–2.0s` 切片推进。**同一时间片内攻守双方都有动作或受迫反馈**（即便被冻结或压制，也有红眼骤缩、熔核跳动、钩爪抽动）。攻击落在对手的附属物上（法器、坐骑、护盾、召唤物、手中兵器）时，持有者同拍先试图阻止（格挡、回拽、闪避），被击中时身体随之受力（偏头、后仰、踉跄）。
  - 招式首次出现写 `【招名】首现：` 并用一句复述主色、实体材质与信号色位置；后续镜头只写招名。每个人物、物体与招式全片只用一个名字，不换同义词。
- **运镜动力学与镜间 HANDOFF**：
  - **摄影机物理惯性**：把摄影机当作场内受力的物理实体，运镜速度曲线与发力节奏耦合：蓄势时缓慢压近或下沉屏息，出招时随动势急甩或贴身加速跟拍，命中帧受冲击剧震、急停或被气浪撞退，残心定格时带阻尼缓滑停稳。焦段、景深与机位按下表的戏剧任务选。
  - **旋向解耦**：画面同时存在旋转特效与环绕运镜时，分别写死俯视旋向（风暴逆时针、镜头顺时针）并锁死人物朝向。
  - **剪辑节奏**：交锋段约每 `0.8–1.5s` 切一个镜头，机位始终在运动，慢推慢摇只留给开场与收势。切在动作中途（挥到一半、飞到一半、跃到空中），下一镜从同一动作的下一瞬接上，切换前后画左画右关系、视线与运动方向不变。
  - **HANDOFF 与最后一帧**：多镜段落每镜结尾写明双方终态位置与姿态（站／跪／倒）、关键物体的存在与数量（消失的写 `不再存在`）、仍在运动的事物、累积战损与切镜／焦点引子（掠过前景的碎屑／刀光或下一拍起手）；末镜用「最后一帧」取代 `HANDOFF`，列全最终定姿、全部留存痕迹与原位地标。

## 7. 交付核验

逐项核验：

- **粒度与结构匹配**：单镜已删去无关全局行；多镜的锁与分镜齐全；跨段组接已对齐每段上传素材与继承战损。
- **实体与触发闭合**：超凡与重火力档每条【招名】写齐载体、几何与数量、复合层与蔓延路径，在分镜里首现一次并绑定触发动作；写实档的每处光都有场景光源或反射来源，每次重击写明接触点、形变与剥离物。
- **空间、调度与焦点守恒**：每条 `CAMERA` 写明前中后景调度、唯一视觉焦点（或移焦路径）与运镜速度变化，核心接触点在画内拍得清，永久地标（或微距光斑）保留在画内；战损只增不减并在最后一帧列全。
- **命中与同拍**：每个时间片双方都有动作或受力；每个命中片具备命中帧同步。

自检后做一轮**冷读**：让没有本次设计上下文的读者只凭 prompt 走一遍时间线，暴露作者脑中默认、纸面缺失的信息。有子 agent 能力时派发一个，只给它 prompt 全文与素材职责，不给设计理由，要求它按时间顺序逐句列出问题，每条附原句：

1. **因果**：每个动作、招式与状态变化的起因都在更早的时间片里；门控事件不抢跑；距离、尺寸、数量与时间逐步记账走通（够得着、来得及、数得清），物体几何在给定站位里摆得下。
2. **画面顺序**：时间片连续且相加等于总时长；`CAMERA` 的切镜时段与动作时段对齐；每条 `HANDOFF` 与下一镜开头的人物、持物、位置、朝向和数量一致；全局锁里写 `全片` 的状态与时间线上的事件不冲突，会变化的状态写成带时间范围的 `0–Ns`；每个镜头写到的画内元素在该焦段与机位下拍得到。
3. **歧义**：每一处有两种以上读法的句子，写出各种读法。重点查左右指画面方位还是角色身体侧、朝向、姿态、物体存在与数量、同一对象换名。

没有子 agent 能力时，自己按这份清单冷读。每个问题改写正文关闭；改动后派新的子 agent 重跑冷读。完成标准：冷读输出中没有未处理的问题；同一问题修两轮仍未关闭时停止修补，在 prompt 后写明卡点。

只输出可直接粘贴的 prompt，和需要用户准备的参考图清单（每张写明图名、画面内容、要看清的部件与用途，各图同一画风）；冷读改动了用户给定的尺寸、数量、造型或时间点时，在 prompt 后逐条列出。拆分为多段时按成片顺序逐份输出，并标明每份对应的成片时间段与上传素材。
