# Image Prompt

一张好图的关键是**先立住唯一的第一视觉焦点，再让媒介、构图、光影与材质共同服务它**。顺着生图模型的推理能力写，只锁真正会推偏的部分，其余空间放开给画面自然生长。

## 1. 五层透镜

| 层 | 关注什么 |
| --- | --- |
| ① 主体与内容 | 核心主体特征、道具状态、姿态神情或决定性瞬间；需要时借眼神、局部入画或阴影带出画外故事 |
| ② 构图与空间 | 景别、视点高度、透视感、前中后景层次、主体位置与占比、视线引导、景深及轮廓分离 |
| ③ 色彩与光影 | 明暗基调、光源来源与方向、光比反差、主辅色比例与冷暖关系，把最强反差或点缀色留给焦点 |
| ④ 材质与肌理 | 表面光学响应（高光、漫反射、透明折射等）、材质对比与真实使用痕迹，细节预算集中在焦点处 |
| ⑤ 风格与美学 | 视觉媒介形式、艺术流派或作品锚点、整体氛围与渲染气质 |

## 2. 四条原则

1. **先锁媒介，用对语言**。⑤ 的媒介决定 ③④ 的表达方式：摄影用焦段、布光与胶片质感，绘画用色块与笔触，像素画用像素尺度与调色板，3D 用着色与渲染。混合媒介时写清各自负责哪部分。
2. **只补会推偏的层，让模型自己推理其余**。模型能从媒介与题材自动推导出协调的配光、背景和材质。用户未指定的层，只在模型默认会与意图冲突（如只要特效光时写明暗底）或交付物有硬要求（如三视图平光纯色底）时明确补写，补得越细反而越容易被放大成刻板装饰。次要区域主动做减法，烘托第一焦点。
3. **留意锚点带出的整套气质**。作者、作品或流派名（以及「电影感」这类笼统词）会附带一整套默认特征。全部贴合意图时直接用；有冲突的部分（如带出黑边或字幕）拆成具体可见特征写，或换掉锚点。
4. **参考图锁定的层不重述**。多张参考图各自写明职责（身份、构图、风格），图里已锁定的层不在正文重抄，把注意力留给新变化。编辑图时只写发生变化的层，不变的内容写进「保留」。

## 3. 输出结构

词序决定权重，越靠前注意力越多，因此把 ⑤ 拆成两头（媒介定性放最前，流派与氛围放最后）。每段标题单独一行不带序号，内容写自然短句，用不到的附加段整段删除；画幅、尺寸与张数由入口参数控制。

```text
媒介定性
（⑤ 的媒介形式）

主体与内容

构图与空间

色彩与光影

材质与肌理

风格与美学
（⑤ 的流派、氛围与渲染引擎）

参考
（各参考图的职责）

保留
（编辑时不变的内容）

文字
（图中逐字出现的文本、层级与位置）
```

单框入口省略负面提示，不混入正向代码块；仅在入口有独立负向字段时，在主代码块外另附负向块，只写本图真实的退化风险。目标模型自带 prompt 指南时以指南为准，要求短 prompt 时从前往后截取。

## 4. 交付前轻核

1. 画面有清晰的第一视觉中心，轮廓与背景分离，次要区域没有抢戏。
2. ③④ 的用词与 ⑤ 的媒介一致，锚点没有带出与意图冲突的默认效果。
3. 同一信息不跨层重复，参考图已锁定的内容没有重述。
