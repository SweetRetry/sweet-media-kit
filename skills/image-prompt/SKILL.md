# Image Prompt

一张图由五层构成，由内向外、由底层到表层。prompt 的任务是让每一层都有确定的取值。

## 五层

### ① 主体与内容 Subject & Narrative

决定画里有什么、讲什么故事。它是画面的灵魂与第一视觉落点。

写核心主体（人物、物体或场景）的识别特征、姿态与动作瞬间、环境道具，以及情绪故事感。情绪落到可见的表情、姿态和道具状态上。角色设定类交付锁定复用不变量；成片抓取当前瞬间。

### ② 构图与空间 Composition & Space

决定元素怎么摆、视线怎么走。它是画面的骨架。

写景别、视点高度、构图法则、前中后景层次与留白。构图法则要落到主体在画面中的具体位置，并写清视线从哪进入、停在哪。多主体时写清相对位置与遮挡。

### ③ 色彩与光影 Color & Lighting

决定情绪基调与体积感。它是画面的情绪荷尔蒙。

写色相冷暖、饱和度、明度组织，配色比例与主次色，以及光源方向、软硬与光效。配色名称和比例要附具体色相。

### ④ 材质与肌理 Texture & Medium

决定质感与细节是否耐看。

写物理表面（反光、折射、次表面散射）、媒介笔触或成像痕迹，以及微观真实痕迹。只写当前景别下看得见的特征。

### ⑤ 风格与美学 Style & Aesthetics

决定顶层艺术语言与审美哲学。

写视觉媒介形式、艺术流派或作品锚点，以及整体审美氛围。交付时 ⑤ 拆成两处：媒介定性放在最前，流派、氛围与渲染引擎放在最后。

## 写法

1. **把需求归层。** 把用户的描述和参考图逐条放进五层，信息只放在一层。“史诗”“高级”“电影感”这类笼统词拆到具体层：比例和姿态归 ①，视角和景别归 ②，反差和色温归 ③。
2. **先锁媒介。** ⑤ 的媒介形式决定 ③④ 用哪套语言：摄影写焦段、布光和胶片颗粒，绘画写色块和笔触，像素画写像素尺度和调色板，3D 写着色与渲染。扁平画面不补物理微纹理，摄影不补笔触。混合媒介时在 ⑤ 写明每种媒介负责哪部分。
3. **补齐空层。** 用户没指定的层，按交付物和 ⑤ 补一个明确选择。空着的层由模型随机决定。
4. **落地锚点。** ⑤ 里的流派、作者、作品或游戏名，要先拆成 ①–④ 中可见的特征。锚点只起压缩作用，不能代替下层约束。

## 参考图与编辑

- 参考图按层分工：身份参考锁定 ①，结构参考锁定 ②，风格参考锁定 ③④⑤。多张参考各自写明职责，风格图不得替换主体身份。
- 编辑只写发生变化的层，不变的内容逐项写进「保留」。换媒介时按新媒介重写 ③④。

## 交付

交付前检查：

1. 五层都有确定取值，同一信息不跨层重复。
2. ③④ 的用词属于 ⑤ 的媒介。
3. ⑤ 的锚点已在 ①–④ 落地。
4. 每个专业术语都能说出它改变了什么可见结果。

词序决定权重，越靠前的内容模型分配的注意力越多。交付按以下顺序排列，语言用用户指定的或目标入口适用的。每个 section 标题单独一行，不带序号；内容另起一行写成完整短句，不要堆标签；section 之间空一行。画幅、尺寸、张数等由 API 参数控制，不写进 prompt。附加 section 用不到就整段删除。

```text
媒介定性
（⑤ 的媒介形式）

主体与内容

构图与空间

色彩与光影

材质与肌理

风格与美学
（⑤ 的流派、氛围与渲染引擎）

参考
（各参考图的职责）

保留
（编辑时不变的内容）

文字
（图中逐字出现的文本、层级与位置）

负面提示
```

入口有单独负向字段时，负面提示放进该字段。
