# Image Prompt

一张图由五层构成，由内向外、由底层到表层。prompt 不仅要让每一层有确定取值，还要建立全图的视觉统治力：把最高的明暗反差、色彩纯度、焦点锐度与肌理密度集中在唯一的第一视觉落点上，其余区域主动做减法让位。

## 五层

### ① 主体与内容 Subject & Narrative

决定画里有什么、讲什么故事。它是画面的灵魂与第一视觉落点。

- **识别与非对称细节**：写核心主体（人物、物体或场景）的几何识别特征与道具状态，用 1–2 处非对称细节（微偏的视线、单侧磨损、斜向衣褶）打破机械感。角色设定类交付锁定复用不变量；成片抓取当前瞬间。
- **决定性瞬间与重心**：拒绝静态立正摆拍。抓取动作刚发生、将停未停或被打断的临界瞬间，写出重心偏移、发力或松弛体态，以及滞后半拍的次级动态（扬起的衣角、将落未落的水珠、未散的烟尘）。情绪外化为视线落点、呼吸姿态与手部抓握力度。
- **画外空间**：需要叙事张力时，用看向画外的眼神、伸入画框边缘的局部物体或投在主体身上的画外阴影，把故事延伸到画框之外。

### ② 构图与空间 Composition & Space

决定元素怎么摆、视线怎么走。它是画面的骨架。

- **视点与透视性格**：写景别、视点高度与焦段透视（或绘画透视法）。平视建立对等凝视，低机位仰拍放大体量与压迫感，高机位俯拍凸显孤立或全局秩序；广角贴近拉开前中后景比例制造临场张力，长焦压缩空间强化平面几何感与疏离感。
- **三层纵深与视线引导**：建立前、中、后三层纵深（如前景遮挡物框景、中景核心主体、背景环境锚点与负空间留白）。把构图法则落到主体在画幅中的具体位置与占比，写清引导线（光束、建筑线条、视线、肢体延伸）如何把观众目光引向第一焦点。多主体时写清高低远近、朝向对比与遮挡关系。
- **焦点、景深与剪影分离**：写明焦平面位置与景深深浅（浅景深剥离背景杂讯，深焦交代人与环境关系）。主体的关键姿态轮廓必须与背景形成清晰的明暗或色相分离，避免叠在同色同亮度的杂乱背景上。

### ③ 色彩与光影 Color & Lighting

决定情绪基调与体积感。它是画面的情绪荷尔蒙。

- **光比雕塑与光源动机**：拒绝全场均匀平光。先定明暗基调与光比反差，再写主光、辅光或轮廓光的场景来源、方向与软硬。用受限光源（窗格切光、逆光轮廓、局部器物发光）或环境遮挡切割明暗，把最亮高光或最强明暗交界钉在第一视觉焦点上，次要区域压入暗部或柔和半影。
- **色彩主次与冷暖对抗**：写配色比例与具体色相。用大面积低饱和或统一色调铺底，把小面积高纯度点缀色（信号色）留给视觉中心；交代受光面与背光面、主体与环境之间的冷暖对比。

### ④ 材质与肌理 Texture & Medium

决定质感与细节是否耐看。

- **材质反差与光学响应**：写表面光学特性（高光锐度、漫反射、透明折射、次表面散射）与成对的材质对比（如粗粝风化表面衬托高反光金属、湿重织物贴合温润皮肤），避免全图材质软硬与反光率趋同。
- **破除均质与细节预算**：加入真实的使用痕迹或媒介痕迹（边缘磨损、局部水渍、布料折痕、笔触飞白或胶片颗粒），打破均质塑料感。微观肌理只密集写在第一焦点、明暗交界线与当前景别看得见的部位，暗部与远景主动概括。

### ⑤ 风格与美学 Style & Aesthetics

决定顶层艺术语言与审美哲学。

写视觉媒介形式、艺术流派或作品锚点，以及整体审美氛围。交付时 ⑤ 拆成两处：媒介定性放在最前，流派、氛围与渲染引擎放在最后。

## 写法

1. **把需求归层。** 把用户的描述和参考图逐条放进五层，信息只放在一层。“史诗”“高级”“电影感”这类笼统词拆到具体层：比例和姿态归 ①，视角和景别归 ②，反差和色温归 ③。
2. **先锁媒介。** ⑤ 的媒介形式决定 ③④ 用哪套语言：摄影写焦段、布光和胶片颗粒，绘画写色块和笔触，像素画写像素尺度和调色板，3D 写着色与渲染。扁平画面不补物理微纹理，摄影不补笔触。混合媒介时在 ⑤ 写明每种媒介负责哪部分。
3. **立焦点并补齐空层。** 先锁定全图唯一的第一视觉焦点，再为用户没指定的层按交付物和 ⑤ 补一个明确选择。补出的背景、光影与材质必须服务于突出第一焦点（通过失焦、压暗、低饱和或留白让位），不添加抢戏的次要元素。空着的层由模型随机决定。
4. **落地锚点。** ⑤ 里的流派、作者、作品或游戏名，要先拆成 ①–④ 中可见的特征。锚点只起压缩作用，不能代替下层约束。

## 参考图与编辑

- 参考图按层分工：身份参考锁定 ①，结构参考锁定 ②，风格参考锁定 ③④⑤。多张参考各自写明职责，风格图不得替换主体身份。
- 参考图锁定的层不在 prompt 里重述，只写参考给不了的取值。有风格参考时 prompt 只写 ①②，主体的固有色作为身份特征留在 ①。
- 编辑只写发生变化的层，不变的内容逐项写进「保留」。换媒介时按新媒介重写 ③④。

## 交付

交付前检查：

1. 五层都由 prompt 或参考图给出确定取值，同一信息不跨层重复。
2. 全图有唯一的第一视觉中心，主体轮廓与背景清晰分离，次要区域已做虚化、压暗或留白减法。
3. ③④ 的用词属于 ⑤ 的媒介。
4. ⑤ 的锚点已在 ①–④ 落地。
5. 每个专业术语都能说出它改变了什么可见结果。

词序决定权重，越靠前的内容模型分配的注意力越多。交付按以下顺序排列，语言用用户指定的或目标入口适用的。每个 section 标题单独一行，不带序号；内容另起一行写成完整短句，不要堆标签；section 之间空一行。画幅、尺寸、张数等由 API 参数控制，不写进 prompt。附加 section 用不到就整段删除。

```text
媒介定性
（⑤ 的媒介形式）

主体与内容

构图与空间

色彩与光影

材质与肌理

风格与美学
（⑤ 的流派、氛围与渲染引擎）

参考
（各参考图的职责）

保留
（编辑时不变的内容）

文字
（图中逐字出现的文本、层级与位置）

负面提示
```

入口有单独负向字段时，负面提示放进该字段。
