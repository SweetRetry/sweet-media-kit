# Video Prompt

图片在二维平面里安排元素，视频再加上时间轴。每一层都从“某一刻的取值”升维为“沿时间的变化”，即起始状态、变化过程与结束状态。prompt 的任务是让每一层在每个时段都有确定且唯一的读法。

每份 Prompt 对应一次生成，可含长单镜或连续多镜。只引用已确定素材与媒介，不捏造输入。

## 1. 六层

### ① 主体动作与演变 Subject Action & Morphing

静态姿态升维为带力学节奏与先后微时序的动作链。写主体识别特征、起始姿态、动作演进与结束状态。拒绝全身部位同时匀速起动：按“视线或呼吸先动 → 头肩带动躯干与四肢发力 → 落定时的重心缓冲与停顿”写出先后层次，动作标明身体部位、方向、幅度和加减速变化。情绪转折优先落在大幅动作停住后的微动作上（指节收紧、眼神躲闪、屏息或松手）。形变（变身、生长、融化、组装）写起始形态、中间过程、终态，以及变化从哪个部位开始、沿什么路径扩散。

### ② 运镜与调度 Camera, Staging & Focus

静态构图升维为机位路径、三维场面调度与焦点转移：

- **视点与机位几何**：机位架在能直接拍清本拍核心看点（关键表情、手部动作或受力面）的一侧，避免主体自身或无关前景遮挡核心动作。按叙事关系选高度与透视：平视建立对等观察，仰拍放大威压或高耸感，俯拍凸显渺小或受困，越肩或主观视点（POV）代入角色感知；广角贴近强化空间纵深与动态临场感，长焦压缩空间制造凝视或疏离。
- **纵深与场面调度**：拒绝所有主体排在同一平面左右平移。组织前、中、后三层纵深：用前景遮挡物（门框、肩背、器物掠过）框景并制造运动视差；让主体沿纵深轴（朝向或远离镜头）走位，靠人物逼近或远去自然改变景别；多人同框时用站位远近、高低差、身体朝向与画幅占比的变化外化关系转折。
- **焦点与视觉层级**：同一时间片只设一个视觉主焦点。写明焦平面落在谁身上、景深深浅（浅景深虚化背景以隔离情绪，深焦同时交代前中后景的因果关系），以及镜内移焦过程（随视线、转头或突发事件从前景移焦到背景，或反之）。非焦点区域通过失焦、压暗或保持静止主动让位。
- **运镜动机与速度曲线**：写起幅景别与机位、运动路径与加减速变化、终幅构图。每次运镜绑定一个可见动机：跟随主体动势、推近加压、拉开揭示环境真相、摇移连接因果两端，或用固定机位凝视让画内调度自己说话；运镜的起动、加速与停稳贴合人物动作的起势与停顿。同一机位与连续调度能交代清楚时保留长镜；视点、时空或叙事重心改变时明确切镜。

### ③ 光影色彩流转 Dynamic Lighting

静态布光升维为光与人在空间中的交互变化。先锁定基准，即主光方向、软硬、色温与主色。光影变化来自两类触发：一是光源自身改变（云遮日、开灯、爆闪、火光摇曳），二是光源不动而主体穿过空间明暗区或受前景遮挡切光（从暗廊迈入窗光、转头让高光滑过鼻梁切为逆光轮廓、车窗外掠过的路灯影扫过脸庞）。每次变化写明触发源、扫过部位、速度与终态；无触发时保持基准不变。

### ④ 物理流体与交互 Physics & Fluid Dynamics

材质升维为材质在受力下的反应。接触写触发、施力方向与接触点、受力反馈和终态。写出重量与惯性，以及布料、头发、水、烟、尘、碎片如何被带动、何时落定。次级运动滞后于主动作并逐渐衰减。

### ⑤ 视觉风格与时间节奏 Style & Temporal Pacing

风格升维为风格加疏密呼吸。媒介与画面质感全片锁定。节奏写时长分配、动静疏密对比、慢动作或变速所在时段，以及剪辑密度：在关键动作发生前或情绪转折处留出 `0.5–1s` 的蓄势停顿（屏息定格），在爆发后留出余韵留白，避免全片匀速推进成流水账。新道具、地点或动作留足“看清 → 发生 → 反馈”的时间；时长不足先删次要动作。

### ⑥ 声音与多模态视听 Audio & Soundscape

图片没有的新层。对白写说话人、原文、语气与时机；音效写声源和对应的动作点；环境底噪与音乐写起止和情绪。每个声音都绑定画面动作或时段；善用画外音先行（未见其人先闻其声以触发画内转头）或高潮瞬间的抽空静默（环境音骤停只剩呼吸或单音）强化张力。入口不生成声音时删去整层。

## 2. 时间轴三原则

### 因果

每个变化都有画面内可见的原因，且原因出现在更早或同一时间片。光变、物理反应、声音和表情都挂在触发它的动作上，写成“动作 → 受力 → 反馈”的链。外部突发事件（停电、来车、闯入者）本身可作起因，写出它的可见形态或前兆。无因的变化会被模型随机生成或忽略；不需要的变化就不写。

### 连续

- 上一时间片的终态就是下一时间片的起始态，承接身份、持物、位置、朝向、运动方向、主光与声音基调。
- 切镜保持 180° 轴线、视线方向与进出画方向一致（前镜朝画右看或从画右出画，后镜对应目标与入口在画左承接），除非用连续运镜划过中轴显式越轴。切在动作中途时，下一镜从同一动作的下一瞬接上。
- 连续动作的尾帧保留惯性，不提前减速定格。

### 无歧义

- 每个主体首次出现时定一个称呼，之后始终沿用；多主体时不用代词。
- 方向用画面坐标（画左、画右、朝向镜头、远离镜头）；需要角色自身方位时写明“她的左手”。
- 同一时间片同一主体只做一个主动作；并行动作逐一写清归属。
- 程度写成可见量，例如步数、转身角度、距离或相对速度；会被复制或稀释的物体写死数量。
- 比喻会被字面执行。“像一阵风冲过去”可能生成风，改写成可拍到的速度与姿态。

## 3. 写法

1. **定粒度。** 单镜（一个动作或瞬间）只写一个 SHOT，删去交接行。多镜写多个 SHOT 与镜间 HANDOFF。超出入口单次时长时，在动作停顿、遮挡擦镜或场景切换处拆成多段，每段一份自包含 prompt。
2. **把需求归层。** 把用户描述与素材逐条放进六层，信息只放在一层。“紧张”“史诗”“电影感”这类笼统词拆到具体层：动作幅度归 ①，机位与运镜归 ②，反差与色温归 ③，剪辑密度归 ⑤。
3. **先锁基准。** 全片不变的取值只写一次，包括主体识别特征、媒介、空间锚点、主光与声音基调；素材已锁定的层视为已有取值，不在主体与基准里重述；用户对这些层的描述与素材一致时只用于核对，不写进 prompt。补齐空层：用户没指定、素材也未覆盖，但会被看见或听见的层，补一个明确选择，空着的层由模型随机决定。补层只填空位，不改写用户已给的取值。
4. **先写动作链，再排调度与时间片。** 用一串 `X → 所以 Y` 写完全片事件，每一步的起因是上一步留下的结果；动作链只用于推导，不进交付。为每镜定好前中后景站位、机位视点与唯一视觉焦点，再把链切成 `0.5–3s` 的时间片；每片围绕当前焦点只写发生变化的层，不变的层与主体不写进时间片与 CAMERA，也不写「保持」「一致」「不变」类声明，起幅或终幅由首尾帧锁定时 CAMERA 只写运动；仅当画内触发可能诱发不想要的连带变化时，在该时间片正面写一次其状态。
5. **写交接与终帧。** 每镜结尾写 HANDOFF，列出位置、姿态、朝向、持物、仍在运动的事物与留下的痕迹。末镜的最后一个时间片写到最终定姿、留存痕迹与光色终态为止，不另写汇总。

## 4. 素材、编辑与延长

素材用目标入口的引用语法绑定，并按层标注控制范围。仅在实际冲突处添加隔离说明：

| 素材 | 锁定的层 | 保持自由或由当前剧本决定 |
| --- | --- | --- |
| 角色 | ① 五官、体型、固定服饰 | ① 动作与表情，② 站位与位移 |
| 场景 | ② 空间结构与透视，③ 主光 | ② 运镜带来的透视，④ 天气微动，① 人物固有色与动作 |
| 风格 | ⑤ 质感与画面媒介，③ 色彩 | ① 人物或道具几何与动作路线 |
| 动作／运镜 | ① 动作路线，② 机位，⑤ 节奏 | ① 主体身份、五官、发型与服饰 |
| 音频 | ⑥ 音色、旋律、对白或底噪 | ⑤ 画面既定节拍；⑥ 按情绪调整音量 |
| 首帧／尾帧 | 开场或结尾画面的全部层 | 两帧之间的变化；正文不重述锚点的静态外观、媒介与色调 |

身份素材里会在片中被毁、卸下或改形的部件，写明它只代表某个时间点之前的外观；之后的时间片正面写新状态，例如“左肩甲已卸下”。

- **编辑**：时间轴只写发生变化的对象、时段和新状态，不变的内容逐项写进「保留」。
- **延长**：第一个时间片的起始态等于原视频的终态，先承接身份、运动方向、主光与声音，再写新变化。

## 5. 输出结构

按以下结构输出纯文本，方括号按当前设定填写。素材已锁定或用不到的行和 section 整段删除。

```text
[素材绑定：每份素材的编号与锁定的层；无素材时删去]

主体
[称呼]：[3–6 项全片不变的可见特征]。（多主体逐个列出）

基准
媒介：[画面媒介、质感与整体风格]。
空间：[前中后景结构，永久地标及其画面方位]；[主体初始站位、高低远近关系与朝向]。
光色：[主光方向、软硬、色温]；[主色归属]。
声音：[环境底噪与音乐基调]。

时间轴
SHOT 01｜[拍名]｜0–[N]s
0–[a]s：[① 主体起始状态与动作，纵深或横向走位]；[④ 受力或流体反馈]；[③ 光色变化及其触发]；[⑥ 对白或音效]。
[a]–[N]s：[下一刻的变化，⑤ 变速写在所在时间片]。
CAMERA：[起幅景别、机位角度与焦段/景深] → [带速度变化的运镜路径与移焦过程] → [终幅构图、前中后景关系与焦点落点]。
HANDOFF：[主体位置、姿态、朝向、视线与持物]；[仍在运动的事物]；[光与声音状态]；[下一镜的切镜或焦点引子]。

SHOT 02｜[拍名]｜[N]–[M]s
…

保留
[编辑时不变的内容]

负面提示
[本段真实存在的退化风险]
```

- 时间片内按因果先后写句，层号只提示要覆盖的内容，不决定语序。
- 时间片连续且首尾相接，相加等于总时长。入口不支持秒级时间戳时，改写为镜内的先后顺序（起初、随后、最后），结构不变。
- 分段时每段顶行写 `用在：成片 [区间]；素材：[本段实际出场的素材]`，并重述交接所需的身份、持物、位置、方向、主光与声音基调；第一个时间片直接带着前段留下的痕迹开拍。
- 画幅、时长、分辨率等由入口参数控制时不写进 prompt。入口有单独负向字段时，负面提示放进该字段。
- 形制、存在状态与机位先在正文用正面描述锁定；只写“不要 X”会把 X 带进画面，负面提示只作补充。

## 6. 核验与交付

交付前检查：

1. 每个变化都能在更早或同一时间片找到触发原因。
2. 多镜时，每条 HANDOFF 与下一镜开头的人物、持物、位置、朝向、视线和数量一致；`CAMERA` 的切镜时段与动作时段对齐。
3. 每镜有唯一的视觉焦点、明确的前中后景纵深层次与可见的运镜动机，核心看点未被无意遮挡。
4. 每个主体只有一个称呼；方向、数量与程度没有第二种读法。
5. 六层都有取值、由素材锁定或已按任务删去，同一信息不跨层重复。
6. 删去空泛修饰和无法拍到或录到的文学描述。

自检后做一轮冷读，暴露作者脑中默认、纸面缺失的信息。有子 agent 能力时派发一个，只给它 prompt 全文与素材职责，不给设计理由，要求它按时间顺序逐句列出因果缺口、前后不接与有两种以上读法的句子，每条附原句。没有子 agent 能力时自己按这三类冷读。每个问题改写正文关闭；同一问题修两轮仍未关闭时停止修补，在 prompt 后写明卡点。

只输出可直接粘贴的 Prompt。分段时按成片顺序逐份输出。冲突按用户最新要求处理；仍需取舍时再询问。
