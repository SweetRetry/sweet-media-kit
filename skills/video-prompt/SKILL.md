# Video Prompt

视频比图片多了一条时间轴，每一层都从「某一刻的取值」变成「沿时间的变化」。把画面写成视频模型能连贯兑现的因果与节奏，其余发挥空间留给创作与模型先验。

每份 Prompt 对应一次生成（长单镜或连续多镜），只引用已有素材，不捏造输入。

## 1. 六层透镜

按需覆盖会改变画面的层，不用每层硬填：

| 层 | 沿时间关注什么 |
| --- | --- |
| ① 主体动作与演变 | 起始姿态、重心与节奏变化、微表情或形变终态；替换过程非看点时可用前景遮蔽自然过渡 |
| ② 运镜与调度 | 视点高度、前中后景纵深走位、唯一视觉焦点与移焦、带清晰动机的连续运镜路径 |
| ③ 光影色彩流转 | 基准主光与主色；光源自身变化或主体穿过明暗区产生的可见光影扫过 |
| ④ 物理流体与交互 | 接触后的重量、惯性，以及布料、头发、水烟尘碎片的滞后响应与落定 |
| ⑤ 视觉风格与节奏 | 媒介质感锁定，配合蓄势、爆发与余韵的疏密对比（停顿拍写出衣发、光或缓推等仍在动的元素） |
| ⑥ 声音与视听 | 对白、关键音效、环境底噪与音乐走向，善用画外音先行或骤停静默（入口不出声时删去） |

## 2. 五条底层原则

1. **因果同框，写出接触**。每个变化在画内都有可见起因，且关键的「触发 → 接触 → 首个可见反馈」留在同一镜、同一拍内同框完成。涉及碰撞或物理改变时以主动接触起句，让变化从落点生发，不跳过过程直接画被动终态。
2. **按「拍」写，只选结果不拆过程**。时间片按模型能兑现的拍划分（通常 1.5–4 秒一拍，完成一次清晰动作与结果），拍内快慢与先后用自然语言表达，发力链与细节物理交给模型先验去补。能用连续运镜讲清时保持长镜，只在视点或时空需要切换时切镜。
3. **R2V 优先，状态在像素里**。参考素材已锁定的外观、空间或风格不在正文里重抄，只写绑定指代、图中看不出的补充和本段新变化。身份素材上已有的固定部件被毁或卸下后模型常会画回来，剧情必须永久毁损时在该处分段改绑受损图（不毁造型的正常受力反应照常放开写）。
4. **只写拍得到、听得到的画面**。每句落到摄像机所见（画面坐标、朝向、遮挡与终态），用带视觉锚词的称呼贯穿全片（如「雨衣女孩」「灰大衣男子」）。常驻事实放全局段，临时变化放对应时间拍。
5. **分段按接法分两类**。超出单次时长时，连续动作接力停在蓄力点或微停顿等清晰帧，用尾帧锁下段开场；切镜或换景分段直接用 R2V 资产图开新镜，上段尾帧仅作环境与状态参考。

编辑模式只写发生变化的对象、时段与新状态，不变部分放进「保留」；延长模式从原视频终态接着演。

## 3. 输出结构

输出纯文本，用不到的行和 section 整段删去。画幅、时长、分辨率由入口参数控制；不支持秒级时间戳时改用「起初、随后、最后」。

```text
素材绑定（有素材时写）
「[素材名]」对应[视觉称呼]，锁定[层与内容]；[保持自由的部分]由下文决定。

主体
（已绑图时只写称呼与图中看不出的补充；未绑图时写足辨识特征）
[视觉称呼]：[特征或补充]。

基准
媒介：[画面媒介、质感与风格]。
空间：[前中后景结构、地标与初始站位]。
光色：[主光方向、色温与主色]。
声音：[环境底噪与音乐基调]。

时间轴
SHOT 01｜0–[N]s
CAMERA：[起幅景别与角度] → [连续运镜与移焦路径] → [终幅构图]。
0–[a]s：[画内动作、主动接触与可见结果]；[光色或物理反馈]；[声音]。
[a]–[N]s：[下一拍变化]。

保留（仅编辑模式）
[编辑时不变的内容]
```

单框入口省略负面提示，不混入正向代码块；仅在入口有独立负向字段时，在主代码块外另附负向块。

## 4. 轻核与冷读

交付前重点查三件事，发现问题直接改顺原句：

1. **因果与连贯**：每个变化在画内有可见起因，关键接触与反馈同框完成，切镜前后轴线与状态衔接自然。
2. **清晰与不重述**：每句都是拍得到、听得到的画面，主体称呼无歧义，已绑图的外观没重复抄写，全局段只含常驻事实。
3. **焦点与节奏**：每镜视觉主焦点清晰，动静疏密有呼吸感。

随后做一轮**冷读**（有子 agent 时派发一个，只给 prompt 全文与素材职责；没有则自己读）：按时间复述每拍看到了什么，列出因果缺口、前后不接或有两种读法的句子，改顺后交付。同一问题修两轮仍未关闭时停止修补并写明卡点。

交付时正向 prompt 单独放在一个代码块里可直接粘贴；有独立负向字段时另附负向块；分段时标明每段对应成片区间与上传素材；有代选取值时在代码块外逐条简列。
