# Video Prompt

图片在二维平面里安排元素，视频再加上时间轴。每一层都从「某一刻的取值」升维为「沿时间的变化」，即起始状态、变化过程与结束状态。prompt 按模型能兑现的粒度写出可见结果，让每一拍在摄像机下只有唯一读法。

每份 Prompt 对应一次生成，可含长单镜或连续多镜。只引用已确定素材与媒介，不捏造输入。

## 1. 六层

### ① 主体动作与演变 Subject Action & Morphing

静态姿态升维为带节奏和重心的可见动作。写主体起始姿态、动作演进与可见终态，标明关键方向、幅度与快慢顿挫；细节发力链交由模型先验完成，不逐关节拆解。情绪转折优先落在大幅动作收住后的微动作上（指节收紧、眼神躲闪、屏息或松手）。形变写起始形态、扩散路径与终态；替换过程不是看点时改写遮蔽转换，让主体没入前景或烟尘后由终态露出，并用一道延续元素贯穿前后。

### ② 运镜与调度 Camera, Staging & Focus

静态构图升维为机位路径、三维场面调度与焦点转移：

- **视点与机位几何**：机位架在能拍清本拍核心看点（关键表情、手部动作或受力面）的一侧。按叙事关系选高度与透视：平视对等，仰拍放大威压，俯拍凸显孤立，越肩或主观视点代入角色感知。
- **纵深与场面调度**：拒绝所有主体排在同一平面左右平移。组织前、中、后三层纵深，用前景遮挡物框景并制造运动视差，让主体沿纵深走位自然改变景别；多人同框时用远近、高低与朝向变化外化关系。
- **焦点与视觉层级**：同一时间片只设一个视觉主焦点。写明焦平面与景深深浅，需要时写清镜内移焦。非焦点区域通过失焦、压暗或保持静止主动让位。
- **运镜动机与路径**：每镜一条连续路径，写清起幅景别与角度、随动作的运动与速度变化、终幅构图。同一机位与连续调度能交代清楚时保留长镜；视点或时空改变时才切镜，避免无必要接缝。

### ③ 光影色彩流转 Dynamic Lighting

先锁定基准（主光方向、软硬、色温与主色）。光影变化只由两类可见触发引起：光源自身改变（开灯、云遮日、火光摇曳），或主体穿过明暗区与前景切光（迈入窗光、掠过路灯影）。写明触发源、扫过部位与终态；无触发时保持基准不变。

### ④ 物理流体与交互 Physics & Fluid Dynamics

材质升维为受力后的可见结果。接触写触发、施力方向、受力反馈与终态。写出重量、惯性，以及布料、头发、水、烟、尘、碎片被带动后的滞后运动与落定状态。

### ⑤ 视觉风格与时间节奏 Style & Temporal Pacing

媒介与画面质感全片锁定。节奏写动静疏密对比、蓄势与余韵：在关键动作前留蓄势，在爆发后留余韵，避免全片匀速流水账。蓄势与余韵里写出此刻仍在动的东西（呼吸、衣发、光线、镜头缓移）；只写静止或定格会生成冻结画面。新道具或动作留足「看清 → 发生 → 反馈」的时间，时长不够先删次要动作。

### ⑥ 声音与多模态视听 Audio & Soundscape

对白写说话人、原文、语气与时机；音效写声源与动作点；环境底噪与音乐写起止与情绪。善用画外音先行（先闻其声触发转头）或高潮前的抽空静默强化张力。入口不生成声音时删去整层；生成声音时只在出现新声源或配乐转向的拍写声音。

## 2. 最高原则

因果、连续、无歧义、粒度对齐高于六层和后文一切写法。冲突时保住这四条，删改另一边。

四条都靠摄像机落地。每句只写本镜摄像机此刻拍得到的画面或录得到的声音：主体在画面哪个位置、哪一面朝镜头、被什么遮挡、正在怎样动、留下什么结果。拍不到的内心、前史与全局方位改写成可见结果，改写不了就删。

### 因果与只选不搭

每个变化都有画内可见的起因，且起因出现在更早或同一时间片。要变化的事物先在更早处以变化前的状态出现。写观众看到的结果，不写模型自己能推出来的物理成像过程。

### 连续与接缝

- 上一时间片的终态就是下一时间片的起始态，承接身份、持物、位置、朝向、运动方向、主光与声音基调。
- 切镜保持 180° 轴线、视线方向与进出画方向一致，除非用连续运镜划过中轴显式越轴。每道切镜、变速或画风切换都是接缝，必须由戏里的转折换取。
- 连续动作的尾帧保留清晰姿态；需要跨段承接时停在蓄力点或微停顿等清晰帧，避免高速运动模糊。

### 无歧义与粒度对齐

- 每个主体定一个带视觉锚词的称呼贯穿全片（如「雨衣女孩」「灰大衣男子」），不用无视觉指向的纯人名或多主体代词。
- 方向用画面坐标（画左、画右、朝向镜头、远离镜头），只在本镜内有效；后续动作依赖的相对关系（谁面对谁、谁被谁遮挡）直接写成本镜可见构图。
- 同一时间片同一主体只做一个主动作；会被复制或稀释的物体写死数量；比喻改写成可拍到的可见状态。
- 时间片按模型可兑现的拍划分，通常 1.5–4 秒一拍（单次完整动作加结果）；拍内快慢与先后用自然语言说清，不强切 0.5 秒碎拍。

## 3. 写法

1. **定粒度与分段**。单镜只写一个 SHOT；多镜写多个 SHOT。超出入口单次时长时在动作微停顿、遮挡擦镜或场景切换处拆成多份自包含 prompt。连续动作接力用上段清晰尾帧锁开场；切镜或换景分段直接用 R2V 资产图开新镜，上段尾帧仅作环境与状态参考。
2. **把需求归层**。把用户描述与素材逐条放进六层，信息只放在一层。「紧张」「史诗」「电影感」拆到具体层的可见取值。
3. **全局段只放常驻事实**。主体与基准里只写从第一帧起就成立的常驻取值；只在某一刻出现的变化写在发生的那一拍。**状态在像素里**：素材已锁定的层不在主体与基准里重述。仅当模型默认会与意图冲突或需跨镜保持一致时补一个明确选择，且补层不改写用户已给取值。
4. **先写动作链，再排调度与时间片**。草稿里用 `X → 所以 Y` 写完事件链（只用于推导，不进交付）。每镜定好纵深站位、机位路径与唯一视觉焦点，再把链切成 1.5–4 秒的拍；每拍只写发生变化的层，不写「保持」「一致」「不变」类声明。

## 4. 素材、编辑与延长（R2V 优先）

默认优先使用 R2V 参考素材绑定。用目标入口的引用语法绑定，并按层写明控制范围；仅在实际冲突处加隔离说明：

| 素材 | 锁定的层 | 保持自由或由当前剧本决定 |
| --- | --- | --- |
| 角色 | ① 五官、体型、固定服饰 | ① 动作与表情，② 站位与位移 |
| 场景 | ② 空间结构与透视，③ 主光 | ② 运镜透视，④ 天气微动，① 人物固有色与动作 |
| 风格 | ⑤ 质感与媒介，③ 色彩 | ① 几何与动作路线，② 机位与运镜，⑤ 节奏 |
| 动作／运镜 | ① 动作路线，② 机位，⑤ 节奏 | ① 主体身份、五官、发型与服饰 |
| 音频 | ⑥ 音色、旋律、对白或底噪 | ⑤ 画面既定节拍，⑥ 音量起伏 |
| 首帧／尾帧 | 开场或结尾画面的全部层 | 两帧之间的变化；正文不重述静态外观、媒介与色调 |

身份素材上已有的部件在片中被毁或卸下后，模型在后续镜头往往会把它画回来。尽量把可见变化落在绑定图之外的东西上（环境、姿态、站位）；剧情必须毁损这类部件时，在那一下分段，后段改绑受损后的图。

- **编辑**：时间轴只写发生变化的对象、时段和新状态，不变的内容逐项写进「保留」。
- **延长**：第一拍的起始态等于原视频终态，直接接着演新变化。

## 5. 输出结构

输出纯文本，方括号按当前设定填写。素材已锁定或用不到的行与 section 整段删除。

```text
素材绑定（有素材时写，无素材删去）
「[素材名]」对应[视觉称呼]，锁定[层与内容]；[保持自由的部分]由下文决定。

主体
（已绑图时只写称呼与图里看不出的补充；未绑图时写足 3–6 项不变的可见特征）
[视觉称呼]：[补充特征或 3–6 项不变特征]。

基准
媒介：[画面媒介、质感与整体风格]。
空间：[前中后景结构、永久地标及其画面方位]；[初始站位与朝向]。
光色：[主光方向、软硬、色温与主色归属]。
声音：[环境底噪与音乐基调]。

时间轴
SHOT 01｜0–[N]s
CAMERA：[起幅景别、角度与景深] → [带速度变化的运镜路径与移焦] → [终幅构图与焦点落点]。
0–[a]s：[画内主体位置、朝向、动作与可见结果]；[受力反馈或光色变化]；[声音]。
[a]–[N]s：[下一拍变化，变速写在所在拍]。

SHOT 02｜[N]–[M]s
CAMERA：…

保留（仅编辑模式）
[编辑时不变的内容]
```

- 时间片按因果先后写句，连续且首尾相接等于总时长。入口不支持秒级时间戳时改写为起初、随后、最后。
- 画幅、时长、分辨率由入口参数控制，不写进 prompt。
- 单框入口省略负面提示，绝不混入正向代码块。仅当目标入口有独立负向字段时，在主代码块外另附负向块，只写本段真实的退化风险。

## 6. 核验与交付

交付前检查：

1. 每个变化在更早或同一拍有画内起因，被改写的事物此前已出现。
2. 切镜前后轴线、视线、持物与状态连贯，切镜与动作时段对齐，无无意义的碎拍与多余接缝。
3. 每镜有唯一视觉焦点、三层纵深与可见运镜动机，核心看点未被遮挡。
4. 每个主体使用唯一带视觉锚词的称呼；方向、数量与程度无第二种读法。
5. 已绑图的外观不重复抄写，全局段只含每帧常驻事实，信息不跨层重复。
6. 每句都是本镜拍得到的画面或录得到的声音；无空泛修饰与拍不到的文学描写。

自检后做一轮**冷读**：有子 agent 能力时派发一个，只给它 prompt 全文与素材职责，不给设计理由，要求按时间顺序逐句列出因果缺口（含距离、尺寸、数量与时长走不通）、前后不接（含该机位下拍不到的画内元素）与有两种以上读法的句子，每条附原句。没有子 agent 能力时自己按这三类冷读。改写正文关闭问题；同一问题修两轮仍未关闭时停止修补，在 prompt 后写明卡点。

交付时，正向 prompt 单独放在一个代码块里可直接粘贴；有独立负向字段时另附负向块。分段时按成片顺序逐份输出，每份代码块前标明对应成片区间与上传素材。有代选取值时在代码块外逐条列出，每条一行，不等确认。
