# 场景

适用于室内外空间、建筑与地貌。场景设计同时交两样东西：一个有主张的画面，和一个人物能在里面活动的空间。

## 1. 简报

- **一句话身份**：什么地方 + 它正在经历或刚经历过什么（`停摆三十年、被拾荒者改成集市的船坞`）。
- **冲突**：空间里看得见的两股对立（`船台的钢梁按厘米对齐，梁下的棚屋没有一条直线`）。
- **核心**：这里最要紧的事发生在哪个位置，那里立一个**地标**。地标是全场的视觉焦点，也是观众在不同角度里认方位的依据。
- 约束里加一项：要在这里发生的动作需要什么（几个人、从哪进出、要用到哪些物件）。

## 2. 参考板五栏

空间结构、材质、陈设、光线与天气、氛围。

## 3. 探索：明度缩略图

变化轴：

- 尺度对比：人与空间、地标与周围的大小比。
- 纵深：前景、中景、远景各放什么，层与层之间隔多远。
- 主形与外轮廓：建筑或地貌顶部那条轮廓线的形状。
- 视点：俯视、平视、仰视，以及离地标多远。
- 光的来路与明暗占比：亮部和暗部各占画面多少，地标落在亮处还是暗处。
- 地标位置：居中、偏置、被遮挡一部分。

候选画成三到四级灰阶的小图，只有大块明暗，不画细节与颜色；每张里放一个人形作比例尺。分格出图时排成多行网格，每格同一画幅。

关卡的缩略图大小取拇指盖大小：明暗块面仍分得开，地标仍找得到。

## 4. 细化

每个方向的设计稿：一张上色的主视角概念图，同一张稿上排地标特写、材质与色板。次焦点是出入口或人物主要活动的区域。按下面的顺序定：

1. **形状层级**：大形是空间骨架与外轮廓，中形是结构构件、家具与大件陈设，小形是表面痕迹与零碎物件。
2. **地标**：形状单独画出来也认得出这个地方，在任何视角都至少露出一部分。
3. **动线**：出入口、通道与人物主要活动区；动作要用到的物件放在够得着的位置。
4. **使用痕迹**：磨损、修补、堆放与改建讲出谁在这里做过什么。
5. **材质**：主表面 2–3 种，彼此形成反差。
6. **光与颜色**：主光来路与色温，点缀色只给地标或核心位置。

类型专项：

- **空间布局**：主体结构、地标与出入口的相对方位；人物动作要用到的物件写明彼此距离与是否伸手可及；多人场景附站位平面图。
- **时段与天气变体**：简报里列出的每个时段与天气下的光线基调。
- 状态变体写可见结果（`东墙倒塌，碎砖堆在门口，露出外面的街道`）。

## 5. 主视觉

一个建立全貌的视角：地标在焦点上，画面里有人形交代尺度，光线让核心位置最先被看到。

## 6. 验证

- **平面图**：顶视、正交，标出地标、出入口与主要陈设。
- **反打视角**：从主视角的对面看回来，再加一个人物视线高度的近处视角。
- **变体**：简报里的时段、天气与状态各出一张，机位沿用主视角。
- **入画测试**：放入一到两个人物，站在主要活动区。

**关卡**：

- 各视角里地标、出入口与大件陈设的相对方位和平面图一致。模型常把空间左右镜像，逐个核对。
- 变体之间只有光线与写明的状态改变，结构与陈设不动。
- 人物入画后尺度对得上，主要活动区容得下简报要求的动作，人没有被背景吞掉。
