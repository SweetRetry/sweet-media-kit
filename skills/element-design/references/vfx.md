# 特效

适用于法术、能量、爆炸、天气等有时间过程的现象。特效是一段过程，不是一张图：形态承担主张，时间曲线承担辨识，与世界的相互作用承担说服力，三样都要设计。声音特征是规格的一部分。

## 1. 简报

- **一句话身份**：什么力量或现象 + 谁在用、要付出什么（`她用自己的体温换来的霜，用一次手就僵一分`）。
- **冲突**：两种看得见的对立物质性质（`像液体一样漫开，停下的瞬间像玻璃一样裂`）。
- **核心**：从谁的哪个部位或哪个物体发出，借什么介质，打到东西上会怎样。发出点是视觉焦点。
- 主张写在形态或节奏上。「能量」「力量」「魔力」不是形态，落到具体物质：火、液体、气体、碎片、光、电弧或别的。
- 约束里加三项：可用的色相（套组留给特效的色相；没有套组时取宿主配色里没占用的色相）、相对人物身高的尺度、要不要分强度级别。没有现成宿主时，先代定一个发出者和一个落点，只定到轮廓与主色。状态一项写分级，不另列状态。

## 2. 参考板五栏

物质与形态、运动方式、色与光、残留痕迹、声音。现实来源优先：流体、燃烧、放电、结晶、生物发光、工业过程、天气。

## 3. 探索：爆发段形状

变化轴：

- 物质：火、液体、气体、碎片、光、电弧，或两种的组合。
- 主形：圆、方、三角，线状、片状或团状。
- 边缘：硬边、软边、撕裂、拉丝。
- 密度分布：核心实边缘虚、核心空边缘实、均匀。
- 运动轨迹：直射、螺旋、扩散、塌缩、沿表面蔓延。
- 节奏：起势与爆发的长短比。

候选画成爆发瞬间的纯黑形状，白底，发出者画成人形剪影兼作比例尺，轨迹要靠落点才读得出时把落点也画成剪影，内部不画细节与颜色。每个候选另写一行时间曲线（起势多长、爆发多快、怎么散）。分格出图时排成多行网格。

关卡的缩略图大小取约 64 像素高。撞形的对象是同类特效的常见样子：只看形状认不出它和普通火球、光束、冲击波有什么不同的淘汰。再加一条：起势能让观众预判接下来要发生什么。

## 4. 细化

每个方向的设计稿：起势、爆发、持续、消散四格关键帧排成一行，同一张稿上排色板与人形比例尺。次焦点是落点，也就是它打到东西的位置。按下面的顺序定：

1. **形状层级**：大形是整体轮廓与轨迹，中形是内部的层与流向，小形是粒子、火星与碎屑。
2. **颜色**：只用简报约束里的色相。写明核心与边缘的颜色和亮度差；亮度不压过宿主的脸与动作焦点，除非主体就是特效。
3. **时间曲线**：四段各自形态怎么变、各占整个过程的多少比例。只写相对比例，不写秒数。
4. **物理作用**：作用到环境与角色时的受力方向与位移、破坏方式、投在地面和脸上的光色、二次粒子（溅起的碎石、被吹动的头发和衣摆）。
5. **残留**：消散后留下什么（焦痕、残烟、结霜）。
6. **声音特征**：起势、爆发、消散各自的声音质感与空间感，材质感与形态一致。
7. **分级**：同一能力的不同强度（试探、全力、失控）在尺度、亮度与破坏上的差别，写成同一份规格的分级。

规格的外观不变量写形态事实（`主体是三到五条贴地蔓延的片状霜，前缘硬边，尾部碎成粉`）。类型专项是上面的来源、时间曲线、物理作用、残留、声音特征与分级。状态变体通常不需要，强度差别走分级。

## 5. 主视觉

爆发瞬间的一帧：特效从宿主的发出点出来、正作用在环境上，宿主与落点同框，看得出尺度与照明。

## 6. 验证

- **序列帧**：4–6 帧排成一行，同一机位、同一比例尺，覆盖起势到残留。
- **分级对比**：各级并排，同一比例尺。
- **明暗背景**：同一帧分别放在亮背景与暗背景上。
- 环境里有视频生成工具时，用序列帧与设计规格出一段短测试。

**关卡**：

- 相邻帧之间形态连续，看得出是同一种物质在变化，没有换成另一种特效。
- 时间曲线的四段在序列帧里分得开，各段比例与规格一致。
- 各级之间一眼分得出强弱，又认得出是同一能力。
- 亮背景与暗背景上都读得出形状；没有占用宿主的配色。
