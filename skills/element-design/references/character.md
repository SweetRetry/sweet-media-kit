# 角色

适用于人物、生物、道具、载具等有独立轮廓的实体。伙伴动物、坐骑与可分离道具各自单列规格条目，另出自己的多视图。

## 1. 简报

- **一句话身份**：职业或种族 + 处境（`被逐出骑士团、靠赏金活下去的前圣殿骑士`）。
- **冲突**：身上看得见的两股对立（`誓约铠甲擦得锃亮，右臂却被诅咒腐蚀成黑晶`）。「内心挣扎」「亦正亦邪」改写到画得出来为止。
- **核心**：能力从身体哪个部位、借什么介质发生（`左手掌心喷出冷白火焰`）。道具与载具写它被使用的那个部位。

## 2. 参考板五栏

轮廓、材质、服装、武器与道具、氛围。

## 3. 探索：剪影

变化轴：

- 比例：头身比、肩宽与胯宽之比、四肢长短。
- 质量分布：上重、下重或均匀。
- 主形：圆、方、三角，或它们的组合。
- 外挑物与负空间：披风、长武器、角、尾、背负物，以及它们和身体之间露出的空隙。
- 对称性：对称，或单侧重装、单侧外挑。

候选都画成白底纯黑剪影：全身、同一比例尺、一个从简报处境推出的站姿、内部不画任何细节。分格出图时排成多行网格，每格一个候选并占满格高，格宽容得下它最宽的外挑物；排成单行长条会把每个候选压小，轮廓差异看不清。

关卡的缩略图大小取约 64 像素高。

## 4. 细化

每个方向的设计稿：全身正面上色立绘，同一张稿上排头部变体、材质与色板。次焦点是头部，简报冲突的两端落在核心部位与头部之一。按下面的顺序定：

1. **形状层级**：中形是装甲分片、衣物结构、背负物，小形是铆钉、纹饰、磨损。
2. **头部**：出 3–5 个变体（发型、面部特征、头盔或面具），在同一身体上比较，并核对它不妨碍能力的发动方式。
3. **装甲与服装**：每件都要说得通：关节处留出活动空间，看得出怎么穿上、护住哪里，磨损与修补讲出角色经历过什么。
4. **材质**：主材质 2–3 种，彼此形成反差（硬对软、亮对哑、新对旧）。
5. **颜色**：点缀色只给能力或签名符号。
6. **武器**：尺寸与握法匹配手与身高，形制延续主形，与能力同一介质或同一色系。
7. **签名符号**：一个单独画出来也认得出角色的图形，在全身重复 2–3 处（盾面、披风扣、武器柄），不超过 3 处。

规格条目写法：`左肩单侧大肩甲，三层叠片向外翻`、`右臂自肘以下为黑晶，裂纹透冷白光`、`签名符号为断裂的环，出现在盾面与披风扣`。栖停或起飞、持握或收鞘属于姿势，不算新部件。类型专项加一条**气质线索**：站姿、视线倾向、惯用小动作。

## 5. 主视觉

姿势让能力正在发生；姿势外轮廓保留剪影的辨识特征。仰拍显威压，平视显亲近；主光打在脸与能力部位。

## 6. 验证

- **三视图**：正面、侧面、背面画在同一张图里（3D 用途可加四分之三侧），同高并排、正交无透视、平光、无背景；3D 用途用 A-pose，其余用中性站姿。
- **装备细节**：签名符号、武器、结构复杂的部件各出一张局部特写，标注材质与结构。
- **动作测试**：3–5 个覆盖极限活动范围的姿势（满幅挥击、深蹲伏低、跃起或冲刺、受击后仰），各出一张。

**关卡**：

- 各视图的头顶、肩、腰、膝、脚底在同一水平线上。
- 不对称部件在侧视与背视里落在正确的一侧。模型常把单侧部件镜像到另一侧，逐个核对。
- 动作中剪影仍可读；装甲与披风在关节弯到极限时不穿插，结构真的允许这个动作；握法与签名符号前后一致。
