# 特效与声音

## 开场钩子（0–1 秒）

第一帧就要动。慢慢逐字浮现的标题会让观众在第一秒划走。

- 第一帧满屏闪白，0.3 秒内褪去，同时镜头从 1.25 倍推回 1.0。
- 标题逐字以十六分音符间隔砸下（每字 0.05 秒错开，0.3 秒落定，回弹 ease-out-back），全部落定时：冲击波环 + 闪白 0.6 + 色散 + 镜头猛推 + 低频 slam 音。
- 落定后 0.2 秒，一道斜向高光扫过标题。

## 撞击的四路反馈

每次踩怪、击中、落地都叠满四路，强度按段落加码（小怪 < Boss 落地 < 最后一击）：

| 路 | 做法 | 参考值 |
| --- | --- | --- |
| 画面 | 冲击波环（地面撞击压成椭圆）、碎片四溅（取被击物主色）、+100 飘字 | 环 0.35 秒，碎片 14–16 片 |
| 镜头 | 猛推（zoom punch）+ 震屏 | 推 6–12%，指数衰减 0.1 秒 |
| 时间 | 卡帧（hit-stop）后追回 | 冻结 0.08 秒，0.25 秒内追回 |
| 声音 | 下扫方波 + 噪声爆 | 起音对准事件时间 |

被击物同时闪白（向白色混合 0.8，0.3 秒衰减）并压扁。色散（红蓝通道错开 10–12px）0.15–0.4 秒，只用在撞击上，常驻会脏。

## 预警与高潮

- **预警。** Boss 出场前 1–2 拍：红色脉冲叠层（每半拍一次）、上下滚动的警示条纹、闪烁的 WARNING 大字、警报音。
- **电影黑边。** 预警到 Boss 站定、以及最后一击，上下各约 110px，0.2 秒滑入。
- **冲击帧（impact frame）。** Boss 落地、最后一击、爆炸各插两帧：第一帧黑白二值，第二帧反相。二值阈值取该帧亮度的 45% 分位数，并且从闪白和后期之前的干净画面计算，否则整帧发白看不出主体。
- **最后一击。** 镜头推到 1.35 倍对准 Boss，半速慢放，蓄力上扬音在击中前 0.5 秒起，到下一拍冲击帧 + 闪白 + 爆炸 + 巨大的 K.O.。

## 大字弹出（callout）

- 像素字体放大，竖向渐变填充，粗深色描边加投影，倾斜约 6°。
- 动画：2.3 倍砸到 1.0 倍并回弹（0.2 秒），结束前 0.18 秒放大淡出。
- 按段落递进用词（COMBO、NICE、GREAT、HIT、K.O.、VICTORY 之类），每个配一声 whoosh。
- 同一时刻屏幕上只留一个大字：后一个出现前，前一个的显示时长要结束。
- 大字画在闪白之后，否则高潮那一下正好被洗掉。

## 持续氛围

- **速度线。** 推进段屏幕空间的白色细线，沿卷轴方向逆向高速划过（横版从右向左，纵版从上向下），透明度约 0.4，段落首尾淡入淡出。
- **残影。** 角色腾空时，身后画前 3 个时刻的同色剪影（青色，透明度 0.3 → 0.1）。
- **节拍脉动。** 每个底鼓拍镜头放大约 1.8%，0.12 秒衰减；预警和慢动作段停用。
- **暗角。** 常驻，边角透明度约 0.6。

## 庆祝与收尾

- 开箱或胜利：闪白 0.7、旋转光芒（放射楔形加径向衰减，每秒约 30°）、彩纸从此刻持续到片尾（宽度随 |cos| 变化，模拟翻转）。
- 片尾标题落回时再来一次冲击波环、闪白和高光扫过，最后一个和弦持续到结束，最后 0.4 秒音频淡出。

## 屏幕后期的叠加顺序

1. 世界层：背景层、角色、怪物、粒子、冲击波环、对白气泡、标题层（含高光扫过）。
2. 速度线。
3. 镜头缩放（以焦点裁切后放大），此刻的画面留作 `clean`，供冲击帧使用。
4. 色散。
5. 暗角。
6. 黑边、警示条纹、红色脉冲、WARNING。
7. 彩纸。
8. 闪白。
9. 大字弹出。
10. 冲击帧（从 `clean` 计算，覆盖以上全部）。
11. HUD（计数器等，不随镜头缩放和震动）。

## 声音

本地合成 8-bit 配乐和音效即可，不依赖音频模型：方波主旋律、三角波贝斯、噪声鼓，按同一 BPM 分段（开场琶音、推进主题、Boss 小调快琶音、胜利号角、尾和弦）。

| 事件 | 音色 |
| --- | --- |
| 拾取 | 两音上行方波（B5 → E6） |
| 起跳 | 方波上扫 260 → 760Hz |
| 踩踏、击中 | 方波下扫 + 噪声爆 |
| 巨物落地、冲击帧 | 三角波 95 → 28Hz 长下扫 + 长噪声 |
| 开箱 | 三角波琶音上行 + 高音闪烁 |
| 对白逐字 | 极短方波，音高按字轮换 |
| 大字 | 高通噪声的钟形 whoosh |
| 预警 | 880/660Hz 交替方波 |
| 高潮前 | 方波上扫叠噪声，音量平方上升 |

用生成的整首曲子当配乐时，先测速度和首拍。速度和节拍网格一致时，按小节切段、对到分镜的拍号上：段间偏移取 4 拍的整数倍，切点放在转场，Boss 配全曲最响的段，原曲的终止音对到片尾。

音效音量相对配乐来定，不写死增益，换配乐就重算：每个音效起音后 0.15 秒的 RMS，最多比同一时段的配乐高 2dB，重击高 4dB；同时出现的音效叠加后再整体限一次。配乐编曲越满，方波音效越刺耳，混音前先低通到 6kHz 左右。

不同长度的信号先补零再相加。总线过一个 tanh 软限幅，峰值归一到约 -1dB。
