# Character Design

角色设计的目标是**一眼可读**：观众只看一眼，就读出这个人是谁、能做什么、卡在什么冲突里。每个阶段都按这一点筛选，好看但读不出简报的方案淘汰。

六个阶段依次推进，每个阶段结束于一道**关卡**。前一阶段定下的东西是后一阶段的硬约束：剪影定了就不在细化里改轮廓，设计规格定了就不在主视觉里加新部件。后面阶段发现前面的问题时，回到出问题的阶段改，再把改动传到它之后的产出。

美术观感优先于与上一阶段的吻合。一张图偏离了锁定内容却明显更好看时，不替用户淘汰它：把它和吻合的版本一起给用户看，用户选了它，就把它立为新的锁定图，并更新被它推翻的阶段。

## 0. 工作方式

- 在工作目录建 `character-[角色英文名或拼音]/`，用户没给名字时先起一个暂名。设计档案写在 `character.md`，图片放在 `images/`，文件名以阶段号开头（`3-silhouette-a.png`、`6-action-leap.png`）。档案随阶段累积：简报、参考板、剪影候选与选择理由、设计规格、图片清单。
- **出图**：环境里有图片生成工具时直接生成，生成后亲自看图，逐条对照本阶段关卡，不过关的改 prompt 重生。没有工具时，每张图交付 prompt 与关卡条目，等用户回传图片后再验收、进入下一步。
- **按图的任务选模型**：版式与逐格内容必须照写的图（剪影阵列、三视图、局部特写）交给 gpt-image-2.6；设计稿与主视觉交给 Midjourney，它的图是设计母版。环境里没有其中一个时，按指令服从最强与审美最强各找替代。Midjourney 不保证结构准确，精度由 gpt-image-2.6 在母版上补：改数量与位置、去掉冲突部件、派生多视图，精修 prompt 先写唯一的改动，再逐项点名要保留的内容（角色、姿势、材质、纹理、笔触、画风、光线、构图），并写明不平滑、不重绘、不换风格。只写「其余不变」时，模型会滑回自己的默认画风。不拿锁定图和文字从头重画母版，重画会丢掉母版的美术质量。用户指定了某阶段的模型时照用，这个指定只管那一类图，不沿用到另一类图的阶段。
- **每次出图都提交已锁定的图作参考**：选定的剪影、定稿设计稿都算。只靠文字复述锁不住轮廓。锁定内容在一张多格图里时，写明取哪一格。
- 模型带有 prompt 指南时，prompt 长度、语法与参数以指南为准，只对该模型生效。指南要求短 prompt 时，按视觉重要性从前往后截取已锁定内容，放不下的条目留给后续阶段的模型落实。
- 一次只提交一个生成任务，看图验收后再提交下一个。调用超时先查任务状态，仍在运行就等待，不重复提交。
- 部件按几何写：形状、两端、边缘、厚薄、是否完整可见。不用整物名词或比喻指代局部，模型会把整物画出来（写「某物的碎片」会带出那件东西的完整特征，写「像某物」会直接画出某物）。
- 出图 prompt 用目标图片模型最擅长的语言，写齐这张图的用途与版式（剪影阵列、设计稿、主视觉、三视图）、背景，以及到这一阶段为止已经锁定的内容：剪影阶段只写形状，第 4 阶段起加媒介与画风，第 5 阶段起加完整设计规格。已有定稿图时作为参考图一起提交，并写明它只锁外观。
- **选择权**：简报、剪影选型与最终方向由用户决定。你给出推荐与理由，用户确认后进入下一阶段。用户要求一次做完时，这三处都按推荐执行，交付时列为「代选」。
- **无图又不停**：没有生图工具且用户要求一次做完时，需要看图的关卡改为两步：先用文字能核的部分做选择（剪影按变化轴的差异与简报落点选，设计按规格是否自洽选），再把只有看图才能判的条目（64 像素可辨、撞形、视图对齐、镜像）列进交付的「待看图验收」清单，写明它们会推翻哪个选择。

## 1. Concept Brief（概念简报）

写成四项，每项都要能被画出来：

- **一句话身份**：职业或种族 + 处境，带出时代与技术水平（`被逐出骑士团、靠赏金活下去的前圣殿骑士`）。
- **角色冲突**：写成身上看得见的两股对立，设计会让它们同框（`誓约铠甲擦得锃亮，右臂却被诅咒腐蚀成黑晶`）。「内心挣扎」「亦正亦邪」这类画不出来的冲突改写到画得出来为止。
- **核心能力**：写明能力从身体哪个部位、借什么介质发生（`左手掌心喷出冷白火焰`）。这个部位就是后面全部设计的视觉焦点。
- **情绪关键词**：3 个能对应到形状与明暗的词（沉重、锋利、轻盈、阴冷、张扬），不用「酷」「帅」「有气质」。

再从需求推出三项约束：媒介与画风、用途（游戏可玩角色要给 3D 建模用、插画、视频生成要跨镜头保持一致）、所属世界的时代与技术水平。推不出且不同答案会导向不同设计的项，一次问完，至多 4 问，每问 2–4 个选项并标出推荐项。

推不出的其余项按最贴合需求的选项写，记为代选。

**关卡**：四项都能直接对应到画面元素；用户确认简报。

## 2. Moodboard（参考板）

收 15–30 张参考，分进五栏：**轮廓、材质、服装、武器与道具、氛围**。每张参考只借一个具体属性，写成 `[来源] → 借[属性]`（`十六世纪哥特板甲 → 借甲面竖向凹槽的光棱`），不整体照搬任何一个完整角色。

- **跨域取材**：每栏至少来自两个领域。取自虚构作品（游戏、动画、影视美术）的参考不超过全板四分之一，其余取自现实（历史服饰、动植物与矿物、工业器物、建筑、宗教器具）。主要从同类作品取材的设计会长成那个类型的平均脸。
- 已知作品的角色只能作单项属性参考；用户给的参考也按此拆开借用。
- 拿不到图片时，把参考写成文字条目（来源 + 具体属性），效果相同。
- 收齐后提炼 3–5 条**设计规则**，写进档案（`主形为倒三角`、`冷硬金属对暖色旧皮革`、`全身竖向线条，只有能力部位打破`）。后面每个阶段都对照这几条。

**关卡**：五栏都有参考；每条参考写明借了什么；设计规则能追溯到具体参考与简报。

## 3. Silhouette Exploration（剪影探索）

先定**变化轴**，再出候选：

- 比例：头身比、肩宽与胯宽之比、四肢长短。
- 质量分布：上重、下重或均匀。
- 主形：圆、方、三角，或它们的组合。
- 外挑物与负空间：披风、长武器、角、尾、背负物，以及它们和身体之间露出的空隙。
- 对称性：对称，或单侧重装、单侧外挑。

做 6–12 个候选，每个用一行写清它在各轴上的取值，任意两个候选至少在两条轴上不同。候选都画成白底纯黑剪影：全身、同一比例尺、一个能体现性格的站姿、内部不画任何细节。分格出图时排成多行网格，每格一个候选并占满格高，格宽容得下它最宽的外挑物；排成单行长条会把每个候选压小，轮廓差异看不清。每个候选单独写描述，分格出图时每格各写一次；只写「一排不同的剪影」时，模型会把一排画成同一个人的微调变体。

**关卡**：缩到约 64 像素高仍能互相区分；每个入选候选都能看出简报的冲突或能力落在哪里；和知名角色撞形的淘汰。推荐 2–3 个并逐个写理由，用户选定后进入细化。

## 4. Design Exploration（设计细化）

每个选定的剪影是一个方向，在它的轮廓里细化，轮廓保持不变。每个方向出一张设计稿：全身正面上色立绘，同一张稿上排头部变体、材质与色板。按下面的顺序定：

1. **形状层级**：大形定气质，中形定功能（装甲分片、衣物结构、背负物），小形定质感（铆钉、纹饰、磨损）。细节密度按约 `70 / 20 / 10` 分区：最密的集中在**主焦点**（能力部位）与**次焦点**（头部），简报冲突的两端落在这两处之一，其余留出大片安静区让焦点成立。
2. **头部**：出 3–5 个变体（发型、面部特征、头盔或面具），在同一身体上比较，并核对它不妨碍能力的发动方式。
3. **装甲与服装**：每件都要说得通：关节处留出活动空间，看得出怎么穿上、护住哪里，磨损与修补讲出角色经历过什么。
4. **材质**：主材质 2–3 种，彼此形成反差（硬对软、亮对哑、新对旧）。
5. **颜色**：先定明度结构，转成灰阶后主体、能力部位与背景仍分得开；再定色相。主色、辅色、点缀色约按 `60 / 30 / 10` 分配，点缀色只给能力或签名符号。
6. **武器**：尺寸与握法匹配手与身高，形制延续主形，与能力同一介质或同一色系。
7. **签名符号**：一个单独画出来也认得出角色的图形，在全身重复 2–3 处（盾面、披风扣、武器柄），不超过 3 处。

**关卡**：用户选定一个方向后，写出**设计规格**：8–15 条全程不变的可见事实，每条写到部位、形状与数量（`左肩单侧大肩甲，三层叠片向外翻`、`右臂自肘以下为黑晶，裂纹透冷白光`、`签名符号为断裂的环，出现在盾面与披风扣`），不对称部件写明左右，按视觉重要性排序，prompt 照此顺序写，长 prompt 里靠后的条目最容易丢。伙伴动物、坐骑与可分离道具各自单列规格条目，另出自己的三视图。设计规格只锁外观；栖停或起飞、持握或收鞘属于姿势，按需变化，不算新部件。设计规格是后面所有出图的唯一外观依据。

## 5. Character Key Art（角色主视觉）

一张图同时交代气质、形体与能力：

- 姿势让能力正在发生，焦点落在能力部位；姿势外轮廓仍保留剪影阶段的辨识特征。
- 机位与光线服务情绪关键词：仰拍显威压，平视显亲近；主光打在脸与能力部位，明暗结构沿用设计稿。
- 以定稿设计稿为参考图，prompt 写入完整设计规格。

**关卡**：逐条对照设计规格，每条在图里都看得到且没有改变；画面里没有规格外的新部件。想到更好的部件时，先改设计规格并回到第 4 阶段确认，再出图。

## 6. Turnaround & Action Test（多视图与动作验证）

- **三视图**：正面、侧面、背面画在同一张图里（3D 用途可加四分之三侧），同高并排、正交无透视、平光、无背景；3D 用途用 A-pose，其余用中性站姿。
- **装备细节**：签名符号、武器、结构复杂的部件各出一张局部特写，标注材质与结构。
- **动作测试**：3–5 个覆盖极限活动范围的姿势（满幅挥击、深蹲伏低、跃起或冲刺、受击后仰），各出一张。

**关卡**：

- 各视图的头顶、肩、腰、膝、脚底在同一水平线上。
- 不对称部件在侧视与背视里落在正确的一侧。模型常把单侧部件镜像到另一侧，逐个核对。
- 动作中剪影仍可读；装甲与披风在关节弯到极限时不穿插，结构真的允许这个动作；握法与签名符号前后一致。

动作测试暴露结构问题时，改设计规格，再重出受影响的三视图与主视觉。

## 交付

`character.md` 写全简报、参考板与设计规则、剪影候选与选择理由、设计规格、各阶段图片清单（文件名与用途）。回复列出产出文件、代选的项，以及仍未解决的问题与它们所在的阶段。
